- 요청 부서: Development / Convention Team

- 연관 작업: DEV-002
- 근거: HQ_OPERATING_RULES.md v0.1 DRAFT의 승인된 PM-001 원칙, AGENTS.md, Owner의 2026-10-31 본 채팅 지시

## 현황과 문제

Owner가 코드/Git 규칙 선정 및 강제 프로세스 구축을 지시했다. 로컬 검사·훅·CI·CODEOWNERS를 준비했으나 원격 미반영이며 GitHub 관리 접근·보호 설정·요금제는 미확인이다. 로컬 훅과 지침만으로 고의적인 우회를 막을 수 없다. DEV-001의 commit/push 승인은 해당 작업에 한정된다.

## 제안

ENFORCEMENT.md의 구체 사양대로 main 보호와 squash-only를 활성화한다. Project Leader는 별도 제한 계정으로 작업 브랜치에 push하고 Owner는 독립 리뷰/병합을 담당한다. 원격이 동일 관리자 계정만 사용한다면 독립 승인 구조가 성립하지 않으므로 계정/권한 분리가 필요하다.

## 영향도

- 일정: 최초 CI 업로드 및 서버 규칙 검증 전까지 원격 강제 적용 완료 불가.
- 개발: 작업 브랜치·PR·정형 메시지 필요. 게임 기획/디자인 영향 없음.
- 테스트·세이브 호환: 변화 없음.
- 비용: 플랜 제한 확인 필요, 임의 구매/업그레이드 없음.

## 답변 / 결론

- 개발 의견: 로컬 구현과 검증을 먼저 제출하고, DEV-002의 commit/push 및 원격 적용에 필요한 접근을 확보한 뒤 서버 검증한다.
- HQ 조정: 미요청.
- Owner 결정 필요: DEV-002 반영 승인 및 향후 Project Leader 권한 위임 여부/범위. 권한 위임이 없으면 기존 건별 승인 유지.
- 반영 대상: ENFORCEMENT.md, 필요한 실제 권한 위임 결정 기록. HQ 운영 규정의 승인 표기는 수정하지 않는다.
