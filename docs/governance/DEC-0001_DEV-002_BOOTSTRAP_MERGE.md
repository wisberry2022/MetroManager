# DEC-0001: DEV-002 초기 설정 main 직접 반영

- 결정 일시: 2026-10-31
- 결정권자: Owner
- 상태: APPROVED
- 연관 작업/RFC: DEV-002 / RFC-0001
- 승인 원문: Convention Team 채팅에서 “해당 사항은 원격 main에 바로 merge해주세요. 현재 프로젝트 초기 세팅 단계이니까요”

## 결정 내용

검수 제출한 DEV-002 변경을 커밋하고 main에 통합한 뒤 origin/main에 일반 푸시한다. 초기 설정에 한하여 PR/squash 절차를 생략한다. 단일 작업 커밋을 만들고 main을 fast-forward하여 선형 이력을 유지한다.

신규 pre-push 훅은 main 직접 푸시를 의도적으로 차단하므로, 이 승인 작업의 `git push --no-verify origin main:main` 한 번에만 로컬 pre-push 예외를 적용한다. 커밋 전 검사와 메시지 검사는 정상 실행하고, 검사·테스트·원격 선행 관계는 별도 확인한다. 영구 훅 설정이나 서버 보호는 변경하지 않는다. 강제 푸시는 하지 않는다.

## 선택 근거와 기각한 대안

Owner가 초기 설정 단계의 직접 main 반영을 명시 지시했다. PR 절차를 다시 요구하지 않으며, 임의 merge commit이나 기존 이력 재작성을 하지 않는다. 원격이 변경되어 fast-forward가 불가능하면 최신 변경을 보존하며 재검토한다.

## 영향 및 반영 조치

- 적용 기준: 기존 HEAD `0705d144b75142859d22b4322150d756f797d6de`, 결과 SHA는 실행 후 채팅 보고.
- DEV-002_RESULT와 운영 문서에 이번 일회성 예외를 연결한다.
- 향후 작업의 직접 main 푸시, 권한 포괄 위임, 릴리스·배포 승인으로 확대하지 않는다.
- RFC-0001의 원격 보호 활성화·독립 인증 주체 확인은 남는다. 코드 반영과 원격 강제 적용 완료는 별개다.
