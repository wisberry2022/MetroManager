1. [C v0.7](../../planning/PLN-001-C.md)·[D v0.9](../../planning/PLN-001-D.md)·[DATA v1.4](../../planning/PLN-001_GATE2_DATA_v1_DRAFT.md)의 W04B·AC-04/05·VP-01·PAR/SEM/CLOSE 규칙을 DEV가 소비할 짧은 대응표로 연결한다. 기존 승인 값·R01~03·PLN-005는 확정 상태로 유지한다.
2. 시청 비음수/음수와 정부3분기/설득1회, 감액/반올림·대기/효력, 사업 슬롯 동일성·수정/revision, E01 발생·관련성·판정 이후·미사용·접수 성공 소비/실패 미소비의 기대 행동과 정본 위치를 제시한다. 정상 RNG·강제 분기 fixture·실제 성공 경로의 의미를 구별한다.
3. 공통 계약·정부 지급·R/K/B·기성·시범/안전/운행·첫 보고는 Stage 2 승인 의미를 재사용한다. DEV 실제 계약과 차이가 드러나는 쟁점만 검토한다. 수익성 음수 반례를 만들기 위해 승인 제품 DATA를 임의 수정하지 않는다.
4. 신규 UI의 '시청 거부 후 수정 가능'과 '정부 부적합/설득 실패 후 신규 사실 필요', 정상0/없음/실패·기간/사업비 안내를 Track A와 대조한다. 디자인 배치·엔진 구조는 대신 확정하지 않는다.
5. DEV-026은 Stage 3 공식 개발 범위다. 지역 미수신/오류를 게임 실패·금액0·전역 시간 정지로 바꾸지 않는 경계, S01 직전일과 P07 FIXED_DAY의 보고 문맥 차이를 실제 의미 충돌이 있을 때만 확인한다. 기술 계약 전체나 이미 승인된 게임 규칙을 다시 승인받도록 요구하지 않는다.
