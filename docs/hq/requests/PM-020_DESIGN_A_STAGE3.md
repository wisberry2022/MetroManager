## 먼저 준비할 일

1. 자체 제안 편집/예측→제출/잠금→시청 승인·거부→정부 적합·보류·부적합→설득/감액→신규 사실/재접수→사업 인계의 상태·행동·사유·복귀 표를 준비한다. 기존 S01/P05/P06/P07에서 재사용하는 화면과 새로 바뀌는 행을 분리한다.
2. DEV가 공급한 실제 payload·revision·허용 명령/비활성 사유·ID·효력시각을 기준으로 L2를 대조한다. 없는 실제 모델 경로를 표시 fixture만으로 제품 인수하지 않는다. Planning은 모호한 의미가 있을 때 해당 쟁점만 연결한다.
3. [PM-015](../GUI_REVIEW_PROTOCOL.md)에 따라 실행 전에 최소 필수 검수 행·고정 시험본·입력/기대·증거·종료 기준을 합의한다. 같은 실제 VS-02 완주 증거를 S3/AC/VP에 공동 사용한다.
