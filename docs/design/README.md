# 디자인 산출물

디자인의 신규 화면·아트 사양·공유 보고서는 이 디렉터리에 둡니다. 게임에 사용하는 소스 에셋 반영은 개발 티켓으로 인계합니다.

- 티켓/결과: `docs/design/tasks/DSG-NNN_TITLE.md`, `DSG-NNN_RESULT.md`
- 브랜치: `codex/DSG-NNN-description`
- 커밋 예: `[디자인][docs] DSG-001 화면 사양 초안을 공유합니다` + 빈 줄 + 본문
- 필수: main의 AGENTS.md와 [부서별 작업 규칙](../engineering/DEPARTMENT_WORKFLOW.md)을 명시적으로 읽고, 플러그인 쓰기 시 branch를 반드시 지정합니다.
- 다른 부서·개발 소스·CI 수정은 기본 금지입니다. main에 직접 쓰지 않습니다.
