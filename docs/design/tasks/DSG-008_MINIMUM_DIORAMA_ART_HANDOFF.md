## 1. A1의 이번 인계 단위

현행 draw/Control 유지와 **교체 가능한 최소 역할 목록/원본·수출조건 준비**가 A1이다. 이번에 아트 파일·스프라이트/atlas·Theme·제품 import/씬을 만들거나 제품 경로를 예약하지 않는다. 8개 행은 **역할 인계 단위**이며 새 이미지8장·실제 생성 파일 수·동시 표현 상한이 아니다. 외형 제작/제품 적용은 선택 목록·실제 환경·정확한 경로/권한과 최소 검증 후 별도다.

디오라마는 2D 모형감의 기존 방향을 유지한다. 장식은 역·노선·상태/포커스·이름보다 낮은 위계이며 실제 좌표·행정 소속·허용 간선·운영 상태를 재분류하지 않는다. MVP 이후 배치/콘셉트 대규모 개편 가능성을 고려해 정보/입력과 시각 자원을 분리한다.

## 4. 실제 제작/제품 인계 시 채울 공통 필드

각 선택 역할마다 `role_id`, 적용 화면/상태, 원본 작성자/승인 근거·출처/권리 조건, source/export 버전·해시·형식·원본 크기, 색/투명 배경, pivot/늘림/반복/표시위상·필터/배율 후보, 겹침/입력 제한, 표시 내용/동적 문자 분리, 검증 환경·입력/기대·근거를 한 묶음으로 준다. 제품 target 경로/import·Control 구조/atlas 여부는 DEV와 특정한다.

현재 실제 신규 source/export·게임 assets 경로·치수·폰트·필터·작업량/일정은 **NOT_DEFINED / NOT_SUPPLIED / NOT_ESTIMATED**다. 디자인 원본은 소관 docs/design 아래 향후 승인 범위에서 관리하며 이번에 빈 파일·미래 폴더를 만들어 실제 공급처럼 표시하지 않는다. 최종 제작/반입 경로가 DEV E/F/N 후보18개에 자동 포함된다고 가정하지 않는다.
