## 1. 이번 선택의 효력

이번에는 **MVP 디자인 규격을 어디까지·어떤 환경에서 검증해 확정할지** 선택한다. 승인된 게임 MVP 기능을 축소/확대하는 선택이 아니다. 실제 지원 수치·폰트·아트를 이미 채택한 명세도 아니다. 모든 MV 선택은 **미선택**이며 권고는 승인과 다르다.

[O01~07 Owner 승인](https://github.com/wisberry2022/MetroManager/issues/92#issuecomment-7057405335), [기존 선택안 §5](DSG-008_F08_OWNER_OPTIONS.md), [DEV 공동 확인](https://github.com/wisberry2022/MetroManager/issues/92#issuecomment-7057935798), [Track A 준비 검토 완료](https://github.com/wisberry2022/MetroManager/issues/92#issuecomment-7057978655)를 재사용한다. 기존 방향의 재승인을 요청하지 않는다. [PR162](https://github.com/wisberry2022/MetroManager/pull/162)은 확인 시점 미병합이며 그 후속 반영안을 main 승인본으로 취급하지 않는다. 이번 문서는 승인된 main과 실제 댓글을 직접 근거로 한다.

권고 묶음은 **MV-S1 / E1 / F1 / N1 / A1 / P1**이다. 제한된 검증 대상에서 정보·조작·가독성 규격을 먼저 확정할 준비를 하고, 실제 미공급/미검증 항목은 담당·시점을 남긴다. 이 묶음만으로 F08 전체 CLOSED 또는 배포/성능 보장을 선언하지 않는다.

## 3. 지원 환경 선택 — MV-E

아래 값은 **Owner 검토용 새 후보**다. 현재 Windows 판/하드웨어·유효 DPI가 검증됐다고 주장하지 않는다. Windows PC용 프로젝트 범위 안에서 비교한다. 타 OS 지원을 이번에 추가하지 않는다.

| 선택 | 검증 대상으로 제안하는 환경 | 범위·대가 |
| --- | --- | --- |
| **E1 한정 환경 우선 (권고)** | Windows 11 x64를 지원 후보로, Owner 지정 기준 PC1대·창모드·한국어 UI·마우스/키보드. Godot4.7.2 및 현재 Windows 렌더링 경로를 비교 출발점으로 유지. OS100%와 Owner 현용 배율1개를 확인 후보로 지정(같으면 중복 제거) | 해당 PC의 OS build·GPU/driver·renderer·유효 DPI·작업영역을 DEV가 먼저 공급. Windows11이 아닌 PC라면 실제 OS와 후보 불일치를 해결한 뒤 프로파일 확정. **모든 Windows11 PC/모든 DPI 지원 보장 아님**, 타PC 배포 전 범위 확장 필요 |
| E2 제한 배포 환경까지 | E1 + 다른 GPU/해상도 조합의 대상 PC1대, OS 배율100/150/200% 후보 중 실제 지원할 조합을 지정 | 환경별 직접 영향 확인 및 선택 폰트 포함 export 확인 필요. 지원 하드웨어 하한은 2대 성공만으로 정하지 않음. 추가 기기 접근·실행 범위 사전 특정 |

**창 후보(두 안 공통):** 1280×720·1600×900은 Godot 요청 창 크기의 비교 후보다. root1을 초기 대조 조건으로 사용하며 root 배율을 OS 배율로 취급하지 않는다. 실제 client 픽셀·Godot viewport/논리영역·OS 작업영역·창 테두리를 각각 기록한다. 작게 한 조건과 크게 한 조건의 정보/행동 접근을 확인한 뒤 **실제 지원 최소 client/논리영역·최대/재크기 허용 범위**를 제안한다. 현재 1280×720 최소 지원 확정 아님. OS 배율을 무단 변경하거나 창이 작업영역에 들어간다고 가정하지 않는다.

예비 최소 행렬: 기준 DPI의 작은/큰 창2조건 + 다른 선택 DPI의 같은 경계2조건, 최대4셀. 같은 유효 배율이면2셀로 축소한다. 불가능한 셀은 숨기지 않고 환경/후보 조정 대상으로 남긴다. root1.25/1.5/2 전수 반복은 기본 의무가 아니다. 환경이 바뀌어 폰트/레이아웃 영향이 생긴 행만 추가한다. 성능·배포판은 MV-P와 분리한다.
