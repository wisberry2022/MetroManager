## 1. 결과와 Owner 결정

최초 3안(생활 도시·철도 관제반·도시 계획 도면)과 Owner 후속 요청의 추가 4안(철도 모형 디오라마·역무실 업무 책상·레트로 PC 경영·공공교통 안내)을 채팅의 비교 시안으로 제시했다.

**Owner는 철도 모형 디오라마를 현재 MVP의 비주얼 방향으로 선택했다.** 선택에는 **MVP 이후 UI 재배치·콘셉트 변경을 포함한 대규모 개편 가능성을 고려한다**는 조건이 붙는다. 현재 배치·팔레트·폰트·타일·마커 크기·제품 해상도·배율·목표 FPS·화면당 표현 상한의 확정은 아니다.

최초 Design 우선 권고는 생활 도시였다. 추가 탐색 후 Owner가 디오라마를 선택했으며, 후속 Design 권고는 이 선택에 따라 최소 모형 도시 표현과 교체 가능한 UI 요소를 정리하는 것이다. 이전 권고나 후보를 삭제해 처음부터 디오라마가 우선안이었던 것처럼 기록하지 않는다.

콘셉트 선택, 이 문서 PR 제출, S2-D01 공식 인수, Stage 2 DONE, 실제 제품 적용은 각각 별개다.

## 4. MVP에 채택할 표현 원칙

1. 작은 모형 도시의 낮은 건물·지형·역으로 철도 계획의 공간감을 표현한다. 지형·건물은 역 ID, 계획 순서·선, 경고보다 낮은 우선순위다.
2. 선택 계획과 실제 시공·운행 상태를 구별한다. 연출이 개통·승객·수익을 생성하거나 판정한 것처럼 보이게 하지 않는다.
3. 색상 외 번호·윤곽·선 스타일·상태 문구·포커스를 사용한다. 후보·계획 포함·정보 선택·키보드 포커스를 동일 상태로 합치지 않는다.
4. 시간·재무는 읽기 쉬운 별도 업무 패널로 구성한다. 현재·과거·예측과 실제 0·없음·실패를 구별하고 권위 값을 재계산하지 않는다.
5. 건물·패널 변형을 필요한 최소 범위부터 제작한다. 대량 장식·애니메이션·도시 다양화는 이번 선택만으로 착수하지 않는다.
