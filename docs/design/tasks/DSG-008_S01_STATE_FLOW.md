예측 공급의 현행 기간은 선택일 06:00부터 다음날 06:00까지 반열린 구간이다. 일반적인 '하루'나 24:00까지만의 결과로 바꿔 표시하지 않는다. 0 예시는 검증용 수요0 입력을 참고한 정적 기대값이며 요청/탑승/완료·예상 운임0, 운영비108000, P-A 거리5km/종단9게임분, 생성분360을 표시한다. 게임 실제 실행 PASS나 새 수요 규칙을 뜻하지 않는다. 이전 입력 결과도 자기 기간·생성 시점과 함께 분리한다.

## 2. 의도와 상태 흐름

| 사용자 입력 | 표시/요청 의도 | 실제 제품에서 확인할 후속 | 목업의 한계 |
| --- | --- | --- | --- |
| 미포함 후보 마커/동일 ID 목록 | 후보를 노선에 추가 | 기존 Session의 단일 명령 결과·최신 계획·유효성 | 의도만 기록, 계획 추가 성공을 생성하지 않음 |
| 포함 역 마커/순서 목록 | 같은 ID 정보 열람 | 계획판 불변·경제/시간 사건 없음 | 정보 선택만 실행, 고정 데이터는 불변 |
| 위/아래·제거·되돌리기 | 선택 ID·현재 계획에 대한 편집 | 허용/사유·정렬/제거 결과·undo 실패 의미 | 의도만 기록, 새로운 순서/히스토리 계산 안 함 |
| 예측 계산 | 현재 입력 기준 예측 요청 | 기존 Prediction의 입력판·기간·READY/FAILED | 동기 완료에 인위적 pending 추가 안 함 |
| 시간 입력 | 정지/재개/배속 요청 | 실제 효력·정지 중 tick 불변 | 의도만 기록. 표시 시각/속도는 바꾸지 않음 |
| 공공입찰 목록 열기 | 기존 P01로 이동 | 실제 tender panel·복귀 후 최신 S01 상태 | 의도만 기록. 허구 P01/사업 결과를 만들지 않음 |

권위 흐름은 입력→실제 공급자의 수락/거부/실제 대기→동일 완료 시점의 최신값·허용 행동 표시다. 늦은 결과는 당시 이력에만 연결한다. 이 순서의 게임 구현은 DEV 소관이며 목업의 상태 선택기를 실제 사건 진행으로 해석하지 않는다.
