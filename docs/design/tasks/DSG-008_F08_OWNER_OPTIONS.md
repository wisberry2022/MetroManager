## 1. 먼저 검토할 요약

권고 묶음은 **현행 글꼴 임시 유지·배포용 후보의 권리 확인 준비 / 시험 기준만 유지하고 지원 수치 보류 / 픽셀과 동적 문자 분리·정수 nearest 우선 비교 / A 잠정 우선·B 보완 후 비교 / 동일ID 목록 대안 유지 / 역할 분리 / 최종 FPS 보류**다.
