**경계 원칙:** 이 문서의 시각 규칙은 Design이 결정한다. 게임 시각·금액·판정·행정/경제 공식 및 허용 행동은 DEV의 **권위 있는 안정 스냅샷**을 소비하며 UI에서 재계산하지 않는다. 실제 개발 API·enum·씬 구조를 명령하지 않는다.

### 2.1 저충실도 텍스트 와이어프레임 (공식 픽셀 규격 아님)

```text
┌───────────────────────────────────────────────────────────────────────────────┐
│ [회사 / 관할 C01]  [게임일 D | 게임시각 06:00]   [정지] [▶ 재개] [1×] [2×] [4×]│
│  상태: [시뮬레이션 일시정지 / 정상 진행 / 확인 중 중 하나]  기준 revision: N  │
├───────────────────────────────────────────────────┬───────────────────────────┤
│                                                   │ 현재 자금 · 게임시각 T     │
│             S01-B 중앙 작업 공간                  │ ──────────────────────── │
│             [DSG-004 지도 자리표시자]              │ 현금 C                  — │
│             지도·목록·노선은 별도 설계             │ 제한자금 ΣR             — │
│                                                   │ 자유자금 F              — │
│                                                   │ 공사예약 ΣK             — │
│                                                   │ 신규약정 가용 A         — │
│                                                   │ 운영비 미지급 B         — │
│                                                   │ [읽기 전용 · 직접 수정 불가]│
│                                                   ├───────────────────────────┤
│                                                   │ 과거 확정 보고           │
│                                                   │ 보고일 D-1 / 보고 ID     │
│                                                   │ [마감 수치 또는 자료 없음]│
├───────────────────────────────────────────────────┴───────────────────────────┤
│ 상태/원인: [실제 사유 텍스트]    명령: [접수 대기/당시 결과]   [허용된 행동]     │
└───────────────────────────────────────────────────────────────────────────────┘
```

- 이 그림의 `—`는 **미결정 레이아웃 자리표시자**이며 실제 값 `0`이나 로딩 실패가 아니다. 실제 표시에서는 아래 상태 매트릭스를 따른다.
- PC 창의 논리 좌표, 패널의 정확한 px 크기, 배율, 한국어 폰트, 인게임 아이콘/색상·FPS는 **미승인**. 이전의 1280×720 / 40px 조작 목표는 추후 검증 가설로만 유지.
- 이 도식은 **제작된 Godot UI·동작하는 목업이 아니며** S1 실제 조작 검증 증거가 아니다.

## 3. S01-A 시간 HUD·조작 규칙

| 표시/입력 상태 | HUD 라벨 (Design 제안) | 사용자에게 보여줄 동작 | 권위 데이터/검증 구분 |
|---|---|---|---|
| 최초 안정 상태 | `게임 시간 06:00` · 현재 게임일 · `진행 중` | 허용된 1/2/4배속 또는 정지 버튼 | DEV 공급된 게임분·정지/속도·허용 행동; 초기 06:00은 승인 초기 fixture의 예 |
| 일시정지 상태 | `일시정지` (게임분 변경 없음) | 허용 시 `재개` 및 현재 속도 정보를 제공 | 정지 중 UI 조회·선택이 시간을 진행시키지 않음 |
| 1/2/4배속 선택 | 해당 속도 선택 상태에 **텍스트+선택 표시** | 한 시점에 선택 속도를 명확히 표시 | 속도 선택의 실제 효력·다음 게임분 변화는 DEV 결과에서 확인; UI 자체 시뮬레이션 금지 |
| 명령 접수 후 미확정 | `속도 변경 요청 처리 중` 등 해당 명령 결과 | 중복 명령을 자동 새 입력으로 만들지 않음 | `command_id`를 기준으로 요청/대기/효력 당시 결과 분리 |
| 명령 거부/최신 상태 변경 | `변경 불가: [공급 사유]` · `최신 상태 확인` | 같은 명령의 당시 거부 기록과 **현재** 허용 버튼은 구분 | 오래된 상태의 늦은 결과가 최신 UI 버튼 상태를 덮어쓰지 않음 |
| 스냅샷 미수신/오류 | `현재 게임 시간 확인 중` 또는 `시간 정보를 불러오지 못했습니다` | 정보가 불확실할 때 추정 시각 표시 금지 | 같은 revision/observation_phase의 안정값만 확정 표시 |

**제약:** '정지'와 '속도'가 함께 공급되면 각각 다른 의미로 표기한다. 재개 시 적용할 배속 유지/초기화 동작은 디자인팀이 임의 가정하지 않으며 DEV의 시간 제어 계약 결과를 따른다. `simulation_minute/day_id`는 게임 사건 시각이고 컴퓨터 시각/프레임 속도와 다르다. '일시정지'를 심사 대기·공사 중단·영업 중단 등 **다른 업무 상태와 혼용하지 않는다**.

## 4. S01-C 현재 자금·S01-D 고정 보고

### 4.1 재무 의미(게임 통화 정수, UI 표시)

| ID | 화면 라벨 제안 | 수치의 의미 | 화면 처리 원칙 |
|---|---|---|---|
| `C` | 총 현금 | 현재 회사 보유 현금. 제한 자금 R 포함 가능 | R을 현금에서 다시 합산해 현금 늘리지 않음 |
| `ΣRᵢ` | 사업 전용 제한 자금 | 정부 지정 공사에 한해 사용 가능한 잔액 | 자유 현금처럼 강조·사용 가능으로 표시 금지 |
| `F` | 자유 자금 | `C−ΣRᵢ` 승인 의미 | DEV 공급 수치 표시, UI가 계산해 원장에 반영하지 않음 |
| `ΣKᵢ` | 자기부담 공사 예약액 | 지출되지 않았지만 공사에 묶인 회사 자금 | 비용/현금지출로 **중복 차감 금지** |
| `A` | 신규 약정 기준 가용액 | `max(0,F−ΣKᵢ)`의 승인된 정의 | **계약 가능 최종 판정과 다름**. 자격/미지급 우선 의무 등을 UI에서 재판정하지 않음 |
| `B` | 운영비 미지급 | 발생했으나 지급하지 못한 운영비 | 자동 상환 시 추가 비용으로 다시 적지 않음. B 자체를 신규 사업 계약 금지로 표시하지 않음 |

- **현재 자금**은 snapshot의 `simulation_minute/day_id` 및 `snapshot_revision`을 한 번 명시한다. 세부 계열 간 서로 다른 revision/observation_phase를 섞어 합계가 맞지 않는 화면을 만들지 않는다.
- 기본 표시 예는 정수·천 단위 구분을 우선한다. **게임 통화의 공식 이름·기호는 미확정**이므로 단위는 `게임 통화 단위`로 표기하고 원화 기호를 임의 확정하지 않는다.
- 실제 수치 `0`은 `0`으로 렌더링하고, 자료 없음은 `자료 없음`으로 표시한다. 해당 자금 계열이 현재 사용되지 않아도 실값이 0으로 공급되면 실제 0이다.
- 기능상 입력/수정이 불가능한 영역은 버튼처럼 표현하지 않는다. 조회용 표의 값·단위를 **오른쪽 정렬**, 명칭·의미 설명을 **왼쪽 정렬**하는 레이아웃 가설.

### 4.2 마감된 보고·현재값은 별도의 출처

- **현재값**: 권위 시뮬레이션이 최신 완료 관측 시점에서 공급한 현금/예약/미지급 금액.
- **확정 과거 보고**: `report_id` + 마감 게임일 + 해당일 고정 수치. 자정 보고의 값은 현재 스냅샷 변동으로 덮지 않으며 별도의 `확정`/`보고일` 라벨을 쓴다.
- 아직 보고가 없다면 **`확정 보고 없음`**, 값이 확정되고 0이면 **`0`**, 응답 오류면 **`보고서를 불러오지 못했습니다: [사유]`**로 구분한다.
- W02의 테스트 이벤트로 생성되는 가상 계약/도착/운임/정산 사례는 사용자에게 실제 영업이 개통됐다고 암시하지 않는다. **테스트/검증 데이터**인 경우 그 출처를 명시한다. 제품용 신규 계약·입찰·탑승 버튼은 제공하지 않는다.

## 5. S01-E 상태·원인·허용 행동 공통 규칙

| ID | 수신 조건(의미) | UI 표제·처리 | 금지 표현·주의 |
|---|---|---|---|
| `ST-01` | `available=true, value=0` | `0` (정수/해당 단위) | `자료 없음` 또는 `—`로 바꾸지 않음 |
| `ST-02` | `available=false`, 미계산/미수신 | `자료 없음` 또는 `산출 전` + 공급 이유 | 정수0으로 표시하거나 임의 계산하지 않음 |
| `ST-03` | 공급 실패/오류 `reason_codes` | `정보를 불러오지 못했습니다: [공급 사유]` | 전역 오류만 띄우고 문제 패널에 원인 누락 금지 |
| `ST-04` | `allowed_actions`가 특정 조작 불허 | 해당 입력 비활성 + `불가 이유` | 색·아이콘만으로 비활성 판정 전달 금지 |
| `ST-05` | 명령 접수·효력 대기 | `요청 접수/처리 중` + command_id 연결 | 결과가 나기 전에 완료·수락 표시 금지 |
| `ST-06` | 과거 명령 수락·거부 결과 | `당시 처리 결과` + effective_at/reason | 현재 조작 권한과 섞어서 역전 표시 금지 |
| `ST-07` | 최신 완료 스냅샷 수신 | 해당 `게임 날짜·시각`/revision + 새 최신 허용값 | 늦게 도착한 더 낮은 revision으로 값·허용 버튼 덮어쓰기 금지 |
| `ST-08` | `observation_phase`가 미완료/불일치 | `현재 상태 확인 중` | 자정/계약/도착/B 정산 중간값을 '현재 완료 잔액'처럼 혼합 금지 |
| `ST-09` | 일시정지 상태 | `게임 일시정지` | 영업/시공/심사 중단과 동일한 오류·금지로 분류하지 않음 |
| `ST-10` | 고정 과거 보고 존재 | `확정 보고 / 보고 게임일` | 현재 자금의 변화가 과거 보고에 소급 반영되지 않음 |

**색/접근성:** 정보·선택·정지·주의·오류·사용불가 상태는 텍스트 표제, 선/패턴, 포커스 표시를 동반한다. 명도 대비 4.5:1, 한글 본문 16px 이상, 40px 조작 목표는 **실측할 가설**이며 아직 Owner 승인 UI 규격이 아니다. 게임 조작 단축키/키보드 세부 바인딩은 Godot 기술팀의 입력 정책과 정렬하기 전 임의로 확정하지 않는다.
