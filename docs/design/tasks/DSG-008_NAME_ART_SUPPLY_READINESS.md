## 2. 지금 가능한 일·대기 경계

현재 가능한 디자인 정적 준비는 이 표의 반례/의존·입력 누락 추적과 DEV 제안의 NR/DA 연결이다. 이 로컬 산출물로 수행했다. 이후 콘텐츠가 오면 이름별 전체 열람/ID 연결, 환경이 오면 창/DPI·문자 판독 조건, 교체 역할이 오면 해당 DA 인계 필드를 구체화할 수 있다.

실제 이름 데이터/loader·Session/guard/Host/Map 보완과 검사 구현은 DEV 소관이다. 읽기 전용 목록+정보 영역은 기존 편집 버튼과 분리하는 방향 제안이며 최종 배치/새 키·Tab 순서·치수는 미확정이다. 무효 문맥을 우회하는 읽기 fallback을 새 의무로 만들지 않는다.

DEV는 N13 후보 안에서 검토 가능하다고 회신했다. 기존 E5/F11/N13 합집합18·공통 문서6개 후보를 유지한다. 신규 파일/씬/자원을 추출한다면 DEV가 정확한 추가 경로와 행동을 착수 전 특정한다. 이 표는 구현·실험·계측·반입·Git 권한이 아니며 미게시 DEV6문서 게시를 새 선행조건으로 요구하지 않는다.

## 3. 최소 검증 준비 — 실행은 모두 NOT_RUN

아래 N01~08은 이 문서의 검토 사례 ID이며 새 제품 티켓/승인 조건 번호가 아니다. 실제 입력·버전·시험 SHA·기대/실제·효과·관측 근거를 실행 시 연결한다. 자동 단언과 OS 가시성 증거를 따로 기록한다.

환경 E/V01은 지정 PC·유효 실행 범위 이후 요청창1280×720/1600×900·root1×OS100%/현용 배율의 중복 제거 최대4셀부터 검토한다. 요청창·실측 client·viewport/논리영역·유효 DPI를 구분하며 지원 최소값으로 확정하지 않는다. 설정 변경은 자동 포함하지 않는다.

폰트 F/V02는 실제 파일/고지 해시→권한 있는 격리 평가→해당 L2/채택 순서다. 긴 한글/기호·금액 끝자리·사유/필수 행동 접근과 fallback을 실제 범위로 확인한다. 설치된 맑은 고딕 복사/번들 없음. 아트 M04는 실제 교체 역할이 생길 때 문자·선택/포커스·입력·겹침·크기/위상/필터 영향만 추가한다. DA8 전체를 새 이미지/검사8건으로 세지 않는다.

관련 자동·프로젝트 로드, 실제 공급·해당 L2를 연결하고 화면 통합의 영향 GUI만 Track A/B 한 패킷으로 심사한다. 전체 F08/이미 수용한 GUI 반복·W04B 비의존 행 일괄 차단 없음. 수행 불가능한 셀은 이유와 NOT_RUN을 보존한다. V07 성능은 기존 인수 시점에 목표환경/부하/기간/상한을 결정한다.

## 4. 검토·유지 상태

이번 준비표는 실행 결과가 아니다. FINAL_SPEC_PENDING·F08-01~04 OPEN과 기존 DEV025/026 PARTIAL/INCONCLUSIVE는 [대조 결과 §4](DSG-008_NAME_ART_DEV_RESPONSE_REVIEW.md)에 별도로 기록했다. 새 이름 구현·게임 자동·로드·GUI/플레이·환경/폰트/아트·성능·빌드/export는 NOT_RUN이다. DEV026 한정 수용/P07 일반 재진입·문맥 복귀 구분, DEV027 P1 완료/전체 통합 구분, S3-10-C·S3-12·Stage 최종 인수 별도를 유지한다.
