## 2. DS-01 — 모형 도시 표현

**핵심:** 낮은 건물·지형의 모형감과 별도 업무 패널을 결합한다. 지도 장식은 역 ID·계획 순서·연결·경고·포커스보다 낮은 위계다.

- 배경: 잔디 면, 작은 지붕·벽·그늘·수목의 직각/계단 윤곽. 모서리 장식·음영은 정적이며 데이터나 클릭 대상이 아니다.
- 건물: 마커 사이의 여백에 놓고 역·노선·범례를 가리지 않는다. 현재 보드는 후보당 건물 1개·수목 1개만 사용한 밀도 예시다. 공식 에셋 수량·오브젝트 상한이 아니다.
- 역: 배경과 분리된 불투명 정보 표찰. 미선택 후보는 고유 ID, 계획 포함역은 순서 번호+고유 ID를 표시한다.
- 선: 후보 간선은 가는 선, 선택 계획은 굵은 실선. 편집 불가 예시의 점선은 상호작용 상태이며 노선 연결 유효성이나 개통 상태가 아니다. 오류 간선은 별도 오류 기호·대상/사유와 함께 표현한다.
- 입체감은 2D 윤곽·하단 두께의 표현이다. 3D 기능·카메라 회전·등각 좌표 변환을 도입하지 않는다.
- 과도한 반짝임·전역 점멸·연속 배경 애니메이션은 기본으로 사용하지 않는다. 처리 대기도 실제 공급 상태가 있을 때만 표시한다.

지도는 C01의 승인 4×3 좌표·12역·행정 부모와 공식 P-A 순서를 유지한다. 장식과 구획은 관할 판정 도형이 아니며 실제 간선·검증 결과는 DEV 공급이다.

## 3. DS-02 — 역할별 잠정 시각 기준

토큰 JSON의 `status=PROVISIONAL_REVIEW`, `production_ready=false`가 모든 값의 효력 범위다. 역할 이름은 의미를 식별하고 값은 MVP 검토용 외관이다. 배치 좌표·게임 공식·입력 단축키·통화 기호·Godot 리소스 형식은 토큰에 넣지 않는다.

글자 가설은 본문 16px, 라벨 14px, 보조 12px, 구획 제목 20px, 보드 제목 28px다. 한국어·숫자는 샘플에서 시스템 `Malgun Gothic, Segoe UI, sans-serif`를 사용하며 폰트 파일은 포함하지 않는다. 제품 글꼴의 배포 라이선스·가용성·Godot 표현은 F-08에서 확인한다. 금액은 천 단위 구분·탭형 숫자를 사용하고 정수 의미를 보존한다. 실제 제품 재무 표는 이름 왼쪽·금액 오른쪽 정렬을 우선 검토한다.

간격은 2/4/8/12/16/24px, 보통/강조 테두리 1/2px, 포커스 3px, 조작 최소 높이 44px, 역 표찰 58×44px를 검토값으로 둔다. 좁은 보드에서는 표찰 폭 54px를 사용한다. 이 값들은 최종 뷰포트·타일·글꼴·입력 규격의 승인이 아니다. 브라우저의 크기·검증 폭을 제품 해상도로 해석하지 않는다.

색 대비 계산의 내부 검토 목표는 글자 4.5, 포커스·지도 간선 3.0이다. 제한된 색상 쌍의 산술 결과이며 접근성 표준 전체 준수·실제 한글 가독성 합격을 주장하지 않는다. 적용 색상 쌍과 실측 계산은 결과서에 기록한다.

## 5. DS-06 — 최소 샘플 보드

`component_board.html`은 네트워크 없이 열리는 독립 디자인 보드다. 외부 라이브러리·폰트·게임 모델이 없다. JSON 토큰을 내부 사본으로 포함해 `file:`에서도 재열람 가능하게 했다. 원본 토큰과 내부 사본 일치 여부를 검증한다.

- 역할별 팔레트·글자 위계, 버튼 정상/선택/포커스/비활성, 정보/주의/실패/잠금 표식을 제시한다.
- 실제0·미계산·조회실패·처리대기·과거확정 및 과거 거부/현재 행동의 분리 예시를 제시한다.
- 공통 장면은 C01 12후보·P-A 6역·초기 C/F/A=1,000,000, R/K/B=0, 1일06:00·일시정지를 사용한다.
- `비교 장면`은 정상/잠금·예측 조회실패의 고정 예시를 바꾼다. 재조회·게임 명령을 실행하지 않는다.
- `업무 패널 위치`는 같은 요소를 지도 오른쪽/아래로 바꾼다. 원본 ID·행동 바인딩과 데이터 의미는 그대로다. 반응형 좁은 폭에서는 자동으로 쌓는다.
- 역 마커와 순서 목록에서 같은 대상 정보를 선택할 수 있다. 현재 열람 ID를 바꿔도 계획 순서·자금은 변경되지 않는다.
- 게임 시간·편집·예측 버튼은 외관 예시로 비활성이다. 디자인 보드용 선택·장면·배치 컨트롤과 구별한다.

독립적인 컴포넌트·상태 예시를 한 보드에 모은 것이며 완성 S01이나 공공입찰/시공/운행 제품 화면은 아니다. 동일 장면에서 처리대기·역 오류 등을 동시에 발생시킨 게임 스냅샷도 아니다.

## 7. F-08 및 미완료 항목

DEV 기술 의견은 아직 수신하지 않았다. 다음을 Owner를 통해 협의할 입력으로 남기며 회신 완료로 표시하지 않는다.

1. 대상 화면·배율에서 한글 본문/라벨·긴 사유·큰 금액이 읽히는가. 폰트 배포/가용성·대체 폰트와 검증 환경은 무엇인가.
2. 픽셀 배경과 텍스트/벡터 정보를 함께 표시할 때 필터·정수/비정수 배율의 대안과 위험은 무엇인가.
3. 실제 지도 밀집·선/마커/포커스 겹침·목록 대체·클릭 영역은 어떻게 검증할 것인가.
4. 테마·패널 재사용·임포트/게임 적용 형식과 실제 성능 측정 장면은 무엇인가.
