## 1. 결론과 판정의 의미

개정 C/D는 1차 디자인 회신의 핵심 요구를 구체화했다. 기관별 결과와 후속 행동, 후보역 순서/무결성, 시범운행과 안전검증, 예상/실적, 제한/가용자금, 집계와 경량 시각 연출이 문서에 반영되었다. 8개 승인 MVP 영역을 삭제할 디자인상 근거는 발견하지 못했다.

그러나 문서 반영은 정책 승인·데이터 공급·실제 사용성 검증과 다르다. DSG-R01~06·08은 **PARTIAL**, DSG-R07은 **BLOCKED**다. 총 **RESOLVED 0 / PARTIAL 7 / OPEN 0 / BLOCKED 1**. 미반영만 있는 항목은 없으므로 OPEN으로 분류하지 않았으며, 완료 조건 전체가 충족된 항목도 없으므로 RESOLVED를 부여하지 않았다.

**CONDITIONAL의 허용 범위:** 정보 구조, 두 경로의 저충실도 와이어프레임, 상태 텍스트 구조는 후속 작업으로 진행 가능하다. **차단 범위:** 정책에 종속된 재무 수치/라벨의 최종 확정, 확정 제작 일정, Gate 2 최종 승인 상정. 특히 Q06이 결정되지 않은 상태에서 숫자까지 확정된 P07 재무 화면을 개발 인수인계하지 않는다. 본 판정은 D의 “최종 승인 상정 BLOCKED”를 해제하지 않는다.

판정 기준:
- RESOLVED: 해당 1차 조건 전부가 근거로 해소됨.
- PARTIAL: 명시적 개선은 있으나 정책·데이터·디자인 검증 조건이 남음.
- OPEN: 필요한 보완이 아직 제시되지 않음.
- BLOCKED: 핵심 외부 결정이 없어 해당 최종 산출물을 확정할 수 없음.
- 이 표는 **1차 조건의 종결 여부**다. 구현 PASS 또는 기획팀의 문서 반영 누락률을 뜻하지 않는다.

## 3. DSG-R01~08 비교 및 미해결 조건

### DSG-R01 — 지도·행정구역 계층: PARTIAL / HIGH

- **1차 요구:** §2 R01·§3-4. 현재 관할 텍스트, 서로 다른 두 행정 위계, 레이어 전환, 지도 혼잡 방지.
- **반영 위치:** C §2-1(L75), §5-3(L181), §5-8(L274), §6 AC-01·02. 부모 유형/관할/오류 거부와 행정 경로 텍스트, 타 시 공고 비노출이 명시됨. 데이터 위계·관할 조건의 문서 반영은 해소됨.
- **남은 위치·문제:** C §5-1·§5-8, D §3 Q02·§5 BLOCK-G2-02. 경계와 수요·역·노선이 겹칠 때의 강조 우선순위, 실제 경계/후보 좌표·밀집도, 확대 시 충돌 검증 자료가 없음.
- **개선/담당:** 디자인은 §4 DD-01의 단일 강조 레이어와 브레드크럼을 사용한다. 기획은 ID·부모·경계·후보 좌표를, 개발은 표시/선택 가능 데이터를 제공한다. 광역시/특별시를 도의 자식으로 표시하지 않는 별도 테스트 데이터도 필요하다.
- **영향/종결 증거:** S01/P03 지도 스케일·마커 가독성 확정 지연. Q02 채택 데이터로 겹침/관할/두 위계 목업 검수, 타 시 공고가 비활성 항목으로도 보이지 않는 AC-02 증거가 있어야 종결.

### DSG-R02 — 동별 수요 분석: PARTIAL / HIGH

- **1차 요구:** §2 R02. 수치·패턴·범례, 예상/실적 분리, 노선안 A/B 예상 이용·사업비·기간 비교, 허구 인과설명 금지.
- **반영 위치:** C §5-7(L256), §5-8, §6 AC-04·08. OD 이동시간·접근비율·수송량·부분 영업과 예상/실적 차이의 설명 근거가 보강됨. 대칭 역순의 결과가 같을 수 있다는 예외도 타당함.
- **남은 위치·문제:** C §5-7 계산 변수/단위·집계 주기·반올림과 §8 Q05가 미승인. 비교 시 두 노선안이 같은 기준일·영업 구간·규칙 버전인지 확인할 표시 계약이 없고, 등급 경계와 값 없음/0 구분도 없음.
- **개선/담당:** 기획·개발은 두 안의 ID/버전, 예상 통행 단위·대상 기간, 거리/시간/비용, 차이 사유를 제공한다. 디자인은 동일 조건 비교표, “예상” 표기, 값 없음과 0의 구분을 채택한다. 불확실성 수치가 공급되지 않으면 임의 오차 범위를 만들지 않는다.
- **영향/종결 증거:** P03·P06의 비교 카드와 툴팁 제작/문구 QA 증가. Q05 승인 후 정상·동일 예측·수요 0·수송 부족·부분일 fixture를 연결한 AC-04·08 화면 대조로 종결.

### DSG-R03 — 공공입찰·자체 제안: PARTIAL / HIGH

- **1차 요구:** §2 R03. 진입·단계 구분, 입찰 고정값 읽기 전용, 정부 사전 허가 표시, 기관·이유·허용 다음 행동.
- **반영 위치:** C §2-2·2-3, §5-4(L193), §6 AC-03·05와 VP-01·02. 입찰 재허가 없음, 탈락 후 다른 사업, 정부 보류 1회 설득, 재접수 제한, 결과 공통 필드가 구체화됨.
- **남은 위치·문제:** C §5-4, D §3 Q04. 음수 사업성 처리, 동일 사업/신규 사실 판정, 동점·재응찰·감액 계수와 실제 판정 사유가 미정. 한 개의 일반 “재신청” 버튼으로 구현하면 시청 무제한 재제출과 정부 제한이 뒤섞임.
- **개선/담당:** DD-02의 독립 경로 카드/진행 단계와 DD-03의 기관·상태·사유·다음 행동을 채택. 기획은 승인 정책별 허용 행동표 및 이유 코드를, 개발은 actions/blocked_reason/설득 잔여 횟수/회차를 제공한다. UI는 이름 변경만으로 재접수 가능 판정을 만들지 않는다.
- **영향/종결 증거:** P01·P02·P04/D01·D03의 실패 문구·회차 상태 증가. Q04 승인표를 바탕으로 두 VP의 독립 성공 경로 및 탈락/보류/부적합/설득 소진/신규 사실 유무를 대조해야 종결.

### DSG-R04 — 후보역 선택·정렬: PARTIAL / MEDIUM

- **1차 요구:** §2 R04. 클릭 선택·해제, 위/아래 이동·제거·되돌리기, 제출 전 확인, 밀집 마커의 대체 조작.
- **반영 위치:** C §5-3, §6 AC-04. 재클릭 해제, 순서 이동/제거/되돌리기, 중복·단절 차단, 예측 재계산과 심사 중 잠금이 추천안에 반영됨.
- **남은 위치·문제:** C §5-1·5-3, D §3 Q02·03. 후보 좌표와 밀집도, 4~6 후보/2~4역 및 선택 방식은 미승인. 최소 클릭 영역, 겹침 시 목록 조작, 제출 전 최종 요약은 아직 구체 디자인으로 연결되지 않음.
- **개선/담당:** DD-04로 버튼 정렬을 기본, 드래그는 필수 아님으로 결정. 화면 표시 기준 40×40px 클릭 영역을 시안 목표로 하고 겹치면 목록으로 동일 동작 제공. 제출 확인에 역 순서와 예측 기준을 표시한다. 개수/연결 유효성은 공급 데이터로 판단한다.
- **영향/종결 증거:** P03/D02 상태 화면 증가. Q02·03 확정과 실제 밀집 좌표의 선택/해제/정렬/되돌리기·최소 미달·단절·잠금 검수 후 종결. 자유 선로 편집 채택 시 본 견적 재산정.

### DSG-R05 — 시공·검증·개통 상태: PARTIAL / HIGH

- **1차 요구:** §2 R05. 공사 완료와 개통 분리, 시험/안전 단계, 실패 복구, 일시정지 시 허위 진행 금지.
- **반영 위치:** C §5-6(L235), §5-5 자금 부족, §6 AC-06·07·08. 대기/진행/성공·실패, 재시험/시험 무효화, 자정·부분 영업·0분 매출 조건이 보강됨.
- **남은 위치·문제:** C §5-6의 결함 발생/수정 조건·재시험 비용/기간과 자정 순서는 승인 대기. 자금 중단·시험 실패·비영업·일시정지가 모두 “정지”로 표시되면 플레이어가 복구 행동을 알 수 없음.
- **개선/담당:** DD-05로 공정 단계와 일시정지/자금 중단/결함 경고를 별도 표시한다. 기획·개발은 단계·원인·남은 게임 시간·비용·무효화된 시험·허용 재시험 동작을 전달한다. 시각 연출을 이유로 시험 시간을 생략하지 않는다.
- **영향/종결 증거:** P05의 중단/실패/재시험/검증 결과 무효화 상태와 HUD 문구 증가. Q05·06 확정 후 일시정지·자정 완공·안전 실패·재시험·개통 0분·첫 실제 영업 보고를 검수해야 종결.

### DSG-R06 — 시민 이용 시각화: PARTIAL / HIGH

- **1차 요구:** §2 R06. 집계+열차 이동/정차+승하차 경량 피드백, 개별 시민 AI 불요, 수요 고저 구분과 성능 대안.
- **반영 위치:** C §2-5, §5-8(L274), §6 AC-07·08, D §4 “차이/조정”. “시각적 또는 정보적”의 모호함이 제거되었고 수치만 남기지 않는 권고, 아이콘 대체, 시험/비영업/수요 0·일시정지 구분까지 수용됨. **최소 표현 방향의 문서 누락 자체는 해소**.
- **남은 위치·문제:** C §5-8과 D §5 BLOCK-G2-05. Q08 승인, 대상 PC/해상도·상한·갱신 빈도·목표 프레임·측정 장면이 없음. 문서에 “채택”이라고 써도 추천안 채택이지 Owner 승인 또는 실제 성능 증거가 아님.
- **개선/담당:** 디자인은 DD-06의 재사용 열차 1종·승하차 아이콘을 우선 표현으로 선택한다. 걷는 시민 다양화는 최소 피드백을 충족한 후 선택한다. 개발은 실제 집계와 연출 연결·정지·시험 구분의 시연 및 성능 측정안을 제출하고 HQ/Owner가 합격 기준을 고정한다.
- **영향/종결 증거:** 새 대량 시민 콘텐츠는 요구하지 않음. 열차 방향/피벗과 연출 상한 결정 전 최종 스프라이트 시트 수는 잠정. Q08 승인 + 실제 탑승/수요 0/비영업/정지/시험 상태의 구별 및 합의 PC의 측정 결과로 종결.

## 6. 제작 규모와 선행 의존성 변화

### 6-1. 동일한 것과 늘어난 것

- **유지:** 승인 MVP 8영역, 두 독립 경로, 1셸(S01)+7패널(P01~07)+3공용 대화상자(D01~03)라는 컨테이너 가정. 새로운 전용 도시·개별 시민 AI·추가 고유 배경을 요구하지 않는다.
- **증가:** P04 재접수·회차·신규 사실/감액, P05 자금 중단·재시험·결과 무효화, P06 0수요·비영업·시험·부분일, P07 제한/자유/약정/가용자금·일자 경계·영업 0분의 상태/문구/검수 조합.
- **소스 파일:** 24~36개 추정 유지 가능하나 보장값 아님. 새 상태를 공용 배지·텍스트·표로 재사용한다는 가정이다. 상태 화면이 늘어도 PNG 수가 같은 비율로 늘지는 않는다. 열차 방향/시트 분할·시민 걷기·폰트 결정에 따라 재산정한다.
- **미포함 선택:** Q03 자유 선로, Q07 저장 MUST, Q02 다수 도시/후보 확대, Q08 대량 시민 표현은 아래 범위에 포함하지 않는다. 채택 시 별도 증분 견적과 HQ 조정 필요.

### 6-2. 수정 추정 — 실측 아님

기획 추천의 작은 단일 도시·후보역 편집·경량 연출을 선택하는 조건, 디자이너 1명·1일 8시간. 기존 요구를 다시 세분화한 **전체 최초 제작 노력**이며 이번 리뷰 자체의 소요시간이나 이미 완료한 제작량이 아니다.

추정에는 대규모 컨셉 재작업·반복 승인 변경·엔진/UI 구현·통합·게임 테스트 구현·외부 사용자 모집/연구·부서 대기를 포함하지 않는다. 표의 QA는 디자인 상태/가독성 체크다. 실제 수행 성능이나 사용성 합격을 뜻하지 않는다. 개발의 M/L 추정과 단순 합산하거나 달력 완료일로 환산하지 않는다.

### 6-3. 작업 순서

1. 디자인 내부 IA·공용 표현 기준은 본 리뷰로 정리. 후속 와이어프레임은 미승인 자리표시자 상태로 준비 가능.
2. Owner Q01·04·05·06 우선 결정 → 기획 상태/장부/시간 기준과 fixture 고정 → P04/P05/P07 상세화. Q06은 재무뿐 아니라 계약·시공·다음 사업의 공통 선행이다.
3. Q02·03과 경계/후보 좌표·연결 데이터 → 지도/후보역 밀집도 목업 → P03 상세화. OD 예측은 Q05와 연결되어 지도만 먼저 고정해도 수요 비교는 확정되지 않는다.
4. Q08과 대상 PC·해상도·연출 상한의 기술 검토 → 열차/승하차 시트·P06 최종화. Q07 저장 채택 여부는 진입/재개/보고 접근점과 QA 범위에 반영.
5. 두 VP의 독립 실제 실행 및 실패/경계 상태 검수 → 디자인 수정 견적/결과 → HQ 통합. 시간·거래 결함 수정은 두 경로에 공통 영향을 준다.

## 8. 승인 범위 보존 확인

C §1-3의 8개 영역(가상 도시·시철 경영·두 사업 경로·행정 심사·개발/개통·시민/운임/만족·경영 성과/다음 사업·행정구역 기초)을 모두 유지한다. 11 MUST, AC-01~10, VP-01·02를 제거하거나 SHOULD로 강등하지 않는다.

Gate 1 모드 배타성, 두 위계, 소속 시 공고만 표시(정부 발주 포함), 입찰 공고 전 정부 허가, 쉬움 시설 유지비 면제/운임 100%, 정부 사업비의 매출/현금 유입·MVP 공사 용도 제한을 보존한다. 시청 수익성 0 통과를 음수 자동 통과로 확대하지 않는다. 시청 최초 포함 제출 횟수와 정부 신규 사실 제한을 구분한다. 파산 연속 음수 24/12/6/3개월·지원 5/4/3/2회·0 이상 회복 초기화·인피니트 기본 OFF·극한 지분 25/25/50도 변경하지 않는다.

Q01~08은 모두 미승인으로 유지한다. 위 콘텐츠 수·시간 예시·수요 공식·C/R/F/K/A 정책·시민 최소 기준을 “승인된 게임 규칙”으로 선언하지 않는다. 8영역 수용과 세부 MVP 제한 승인은 별개다.
