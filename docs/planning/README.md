# 기획 산출물

기획의 신규 규칙·밸런스·공유 보고서는 이 디렉터리에 둡니다. 문서 저장은 게임 명세의 최종 승인을 뜻하지 않습니다.

- 티켓/결과: `docs/planning/tasks/PLN-NNN_TITLE.md`, `PLN-NNN_RESULT.md`
- 브랜치: `codex/PLN-NNN-description`
- 커밋 예: `[기획][docs] PLN-001 경제 규칙 초안을 공유합니다` + 빈 줄 + 본문
- 필수: main의 AGENTS.md와 [부서별 작업 규칙](../engineering/DEPARTMENT_WORKFLOW.md)을 명시적으로 읽고, 플러그인 쓰기 시 branch를 반드시 지정합니다.
- 다른 부서·개발 소스·CI 수정은 기본 금지입니다. main에 직접 쓰지 않습니다.
