## 3. COH-E01 평가할 협력 경험

세 영역은 조직 결속도를 계산하기 위한 중간 구분이다. 회사 상태값 계층에 정식 자식 노드 세 개를 추가하는 제안이 아니다.

| 영역 | 확인할 실제 경험 | 좋은 경험의 예 | 그것만으로는 근거가 아닌 것 |
|---|---|---|---|
| 공동업무 수행 | 둘 이상의 직원이 맡은 역할을 조율해 공동 책임을 이행했는가 | 역할·인수 조건에 맞춰 각자 맡은 부분을 제때 제공 | 회사 매출 증가, 열차 정상 운행, 회의 개최 횟수 |
| 정보 공유·인수인계 | 다음 담당자가 업무에 필요한 정확한 정보·상태·결과물을 제때 사용할 수 있었는가 | 필수 내용이 실제로 전달되고 인계 조건을 충족 | 전달 버튼 클릭, 메시지 수, 읽음 표시만 존재 |
| 상호 지원 | 정해진 업무 권한·자격·부담 범위 안에서 성립한 도움 책임을 실제로 이행했는가 | 지원이 정당하게 배정되거나 수락된 뒤 필요한 도움 제공 | 지원 요청 수, 무조건 수락, 휴식 포기, 장시간 잔업 |

위 예시는 기획상 경험의 의미다. 현 게임에 해당 직원·업무·인계·지원 기능이 존재한다고 전제하지 않는다. 친목·회식·팀 행사·소속감 설문·개인 갈등·노사 관계 전체를 첫 평가에 추가하지 않는다. 향후 실제 콘텐츠가 생기면 관측 의미와 중복을 별도로 정한다.

## 4. COH-E02 대상과 원래 사례

대상은 회사에 직접 고용되어 실제 협력 업무에 참여한 직원이다. 고용된 관리직이 동료로서 업무에 참여했다면 포함한다. 경영진의 설명·공정성·권한 행사 자체는 경영진 신뢰도의 독립 판단 대상이다. 추상 플레이어, 고용 관계 없는 이사·주주, 외주 인력은 결속도의 평가 대상 직원에 넣지 않는다.

서로 다른 실제 직원 최소 두 명이 있는 협력 경험을 사용한다. 같은 부서 안의 협력도 인정한다. 부서 이름 두 개, 동일 인물의 두 역할, 1인 회사의 혼자 한 업무로 대인 협력 사례를 만들지 않는다. 집계형 인력 표현을 쓰더라도 실제 서로 다른 인원과 겹치지 않는 책임을 입증해야 하며 기술 저장 형식은 정하지 않는다.

‘원래 사례’는 콘텐츠 규칙에 따라 실제로 성립한 하나의 협력 책임이다. 시작 시점에 참여자·역할·필수 결과·기한·주 영역·권한/자격·필요 자원 조건을 식별할 수 있어야 한다. 플레이어가 좋은 사례만 평가에 등록하는 방식은 사용하지 않는다. 해당하는 좋은 경험과 문제 경험을 모두 수집한다.

같은 인계를 보낸 쪽과 받은 쪽의 두 사례로 세지 않는다. 메시지·재요청·작은 작업으로 나누거나 참여자를 늘려도 원래 하나의 책임은 한 사례다. 주 영역은 사전에 한 개로 고정한다. 별도 사례가 되려면 독립된 책임·기한·완료 조건이 실제로 성립해야 한다. 같은 작업의 부수 절차를 복제해 여러 영역·표본 수를 채울 수 없다.

기한이 다른 실제 교대 인계처럼 독립적으로 반복되는 업무는 별도 원래 사례가 될 수 있다. 평가를 올리려고 필요 없는 지원·인계를 생성하는 콘텐츠는 첫 범위에 넣지 않는다. 구체적인 업무 종류와 필요성·기한·권한은 후속 실제 기준표에서 정한다.

## 5. COH-E03 사례 판정

| 사례 상태 | 내부 처리 | 필요한 근거 |
|---|---|---|
| 정상 이행 | 10 | 원래 유효한 기한까지 필수 결과와 협력 책임을 모두 충족 |
| 문제 발생 후 실제 시정 | 5 | 확인된 책임 미이행이 있었으나 누락 전달·미완료 역할·필요 구제까지 실제로 회복 |
| 확인된 미해결 문제 | 0 | 정당한 책임·기한 도래·미이행을 확인했고 필요한 시정이 아직 완료되지 않음 |
| 진행 중 | 채점 대기 | 책임은 있으나 기한 전이며 아직 완료되지 않음. 현재 미해결 실패와 구분 |
| 자료 부족 또는 판정 조건 미정 | 채점 불가 | 역할·권한·기한·실제 이행을 판별할 수 없음. 0이나 10으로 채우지 않음 |
| 정당하게 성립하지 않은 요청 | 평가 대상 제외 | 권한/자격/부담 조건상 협력 책임이 성립하지 않았다는 근거가 있음. 성공 가점도 없음 |

두 사람이 협력 절차를 제때 이행했어도 외부 사유로 사업이 실패할 수 있다. 사업 성패를 그대로 협력 실패로 복사하지 않는다. 반대로 사업이 성공했더라도 필수 인계를 누락한 사실은 별도로 남는다.

휴식 중이거나 필요한 자격·권한이 없는 직원, 이미 유효한 다른 의무 때문에 수행할 수 없는 직원에게 부당한 지원을 요구한 뒤 거절을 감점하지 않는다. 지원을 받아들였다는 버튼만으로 정당한 의무가 성립하지도 않는다. 회사의 인력 배치 문제를 동료의 비협조로 추정하지 않는다. 부당한 요청을 거절한 것만으로 결속 가점을 주는 방식도 사용하지 않는다.

기한이나 역할의 유효한 변경·종료는 사전에 정의된 콘텐츠 조건과 실제 효력 시각에 따른다. 변경 전에 이미 발생한 문제를 사후 삭제하거나, 단순 취소를 정상 이행으로 바꾸지 않는다. 외부 장애가 생겼다는 이유만으로 기한을 자동 연장하지도 않는다. 적용할 조건이 미정이면 판정 불가로 두며 면제나 실패를 임의로 만들지 않는다. 기록이 없다는 사실만으로 미이행이 입증된 것으로 보지 않는다.

## 6. COH-E04 영역과 회사 집계

실제 평가 가능한 사례는 원래 사례마다 같은 비중이다. 영역별로 그 사례 값을 평균한 뒤, 실제 관측된 영역의 평균을 같은 비중으로 합친다. 참여 인원·임금·거래 금액·메시지 수·플레이어가 붙인 중요도로 가중하지 않는다. 중간 반올림으로 값이나 경계가 달라지지 않게 한다.

아래 예시는 내부 설계 검산이며 플레이어 화면에 산식을 공개한다는 뜻이 아니다.

- 공동업무 두 사례가 10과 0이면 영역 값은 5.
- 정보 공유·인수인계 한 사례가 10이면 영역 값은 10.
- 상호 지원은 전수 관측 결과 기회 없음이 확인됐다면 합산 대상에서 제외.
- 실제 3사례·2영역과 나머지 충분성 조건을 충족했다면 결속도는 `(5 + 10) / 2 = 7.5`.

이는 결속도 내부의 영역 집계 규칙이다. 정식 상태값 부모가 미관측 자식을 빼지 않는 기존 원칙과 별개다. 상호 지원을 확인할 자료가 없거나 진행 중인 지원만 있다면 이를 ‘기회 없음’으로 바꿔 같은 7.5를 현재 평가로 제공하지 않는다.

## 7. COH-E05 기억 기간과 갱신

정상 일일 마감에서 최근 마감된 **28게임일** 안에 정상 이행 또는 실제 시정이 확정된 경험을 반영한다. 이 기간 밖이라도 현재 미해결로 확인된 문제는 계속 포함한다. 28일은 이동 기억 기간이며 28일마다 별도 평가 과제를 만드는 주기가 아니다. 경영진 신뢰도의 성과 약속 주기를 복사하지 않는다.

정상 이행 사례는 실제 완료일, 시정 사례는 실제 시정 완료일을 기준으로 기간을 판단한다. 미해결 기간에는 원래 사례 하나의 현재 값 0을 사용하고, 실제 시정 뒤에는 같은 사례의 값 5를 사용한다. 0과 5를 동시에 두 사례로 더하지 않는다. 조회·재저장·재로딩·이름 변경은 완료 시각이나 기억 기간을 새로 만들지 않는다.

예를 들어 10일에 정상 이행이 끝난 사례는 10일 마감부터 37일 마감까지 포함하고 38일 마감에서는 빠진다. 1일에 확인된 미해결 사례는 40일에도 남는다. 이를 40일에 실제 시정하면 40~67일 마감에는 같은 사례의 값 5로 반영하고 68일에는 빠진다.

실제 평가 적용 시작일과 최초 최소 수집 기간, 도입 전 사례의 취급은 이번에 정하지 않는다. 위 기억 기간을 근거로 기존 세이브의 과거를 자동 소급 평가하지 않는다. 별도 적용·승계안에서 정한다.

## 8. COH-E06 현재 평가에 필요한 자료

다음 조건을 모두 만족할 때 현재 결속도 평가를 낸다.

1. 세 영역의 실제 콘텐츠·판정 규칙·관측이 준비되어 있고, 회사 전체의 해당 협력 책임을 누락 없이 구분할 수 있다.
2. 집계 대상에 평가가 확정된 서로 다른 원래 사례가 최소 3개 있다. 정상 이행·시정·확인된 미해결을 모두 실제 사례로 인정한다.
3. 실제 사례가 최소 두 영역에 걸쳐 있고, 실제 기회가 있는 각 영역에 평가 가능한 사례가 최소 하나 있다.
4. 합산에서 제외한 영역은 전수 관측으로 실제 기회 없음이 확인되어야 한다. 구현되지 않았거나 자료가 없거나 아직 진행 중인 것과 구분한다.

| 상황 | 권고 처리 |
|---|---|
| 두 영역에 각 2개·1개, 세 번째는 확인된 기회 없음 | 다른 조건 충족 시 현재 평가 가능 |
| 한 영역에서만 3개 이상 | 실제 범위 부족. 현재 회사 평가 대기 |
| 두 영역에 각 1개뿐 | 실제 사례 수 부족. 현재 회사 평가 대기 |
| 두 영역 충분, 세 번째는 아직 진행 중인 사례만 존재 | 기회 없음이 아니므로 세 번째 영역의 실제 결과를 기다림 |
| 세 영역에 각 1개 | 전수·판정 조건 충족 시 현재 평가 가능 |
| 이미 실제 평가가 있는 영역에 새 기한 전 업무가 추가됨 | 새 진행 중 사례 자체가 기존 현재 평가를 무효화하지 않음 |
| 결과를 판정해야 할 사례의 자료가 누락됨 | 누락 사례만 빼고 유리한 현재 평균을 내지 않음. 현재 평가 대기 |
| 세 영역 모두 기회 없음, 직원 0명 또는 실제 협력 없는 1인 회사 | 현재 결속 경험 없음. 높은 결속 또는 실제 보통 5로 설명하지 않음 |

평가 대기 중 기본 보유값 또는 마지막 유효 보유값을 관리하는 기존 공통 원칙은 유지한다. 마지막 보유값과 현재 유효한 평가는 구분하며, 상세 과거값·표시·승계는 후속안에서 정한다. 현재 결속도가 유효하지 않으면 대내적 평판 현재 종합 단계도 기존 승인 조건을 충족하지 못한다.

## 9. COH-E07 해결과 회복

회복은 실제 책임의 이행과 필요한 구제의 완료로 판단한다. 사과·회의·계획 수정·담당자 교체만으로 미해결 값을 올리지 않는다. 인계 누락이라면 업무에 필요한 정보가 실제로 복구되어 후속 담당자가 사용할 수 있고, 해당 콘텐츠가 정한 추가 시정까지 완료되어야 한다.

시정 시 다음 정상 마감에서 같은 원래 사례를 0에서 5로 바꾼다. 기한을 지킨 과거로 다시 쓰지 않는다. 이후 별도로 성립한 협력을 제때 이행하면 새 사례 10을 인정한다. 아직 해결되지 않은 과거 책임을 새 이름의 성공 사례로 대체하지 않는다. 사실 오류 정정은 실제 개선과 구분하고 원래 기록·정정 근거를 보존한다. 구체적인 과거 보고 표시·승계는 후속 범위다.

첫 범위에는 별도의 ‘중대 사례가 있으면 회사 점수 최대 3’ 같은 상한이나 최저 사례 강제 적용을 추가하지 않는 것을 권한다. 경영진 신뢰도의 중대 상한을 자동 이식하지 않는다. 미해결 문제는 0으로 계속 반영하고, 높은 종합 단계와 별개로 현재 협력 문제가 있음을 전달한다. 구체적인 사유 개수·배치·알림 빈도는 정보 전달 후속안에서 정한다.

따라서 여러 좋은 협력과 일부 미해결 문제가 공존할 수 있다. 첫 범위가 특정 문제의 심각성 전체를 요약한다고 설명하지 않는다. 심각도별 상한을 택하려면 어떤 문제인지, 어떤 근거로 확인하는지, 언제 해제하는지를 별도로 결정해야 한다. 실제 사례가 기간에서 빠지거나 충분성이 사라질 수 있으므로 시정만 하면 회사 현재 단계가 반드시 오른다고 보장하지 않는다.

## 10. COH-E08 조직 변경과 다른 항목의 경계

원래 참여자·책임·발생/기한/완료 시각을 보존한다. 퇴사·부서 이동·명칭 변경·조직 개편만으로 과거 경험이나 미해결 책임을 지우지 않는다. 퇴사 자체를 결속 실패로 채점하지도 않는다. 유효한 후임 배정은 앞으로 수행할 역할을 바꿀 수 있지만, 이미 늦어진 인계를 제때 이행한 것으로 바꾸지 않는다. 재입사나 재요청이 같은 과거를 새 사례로 만들지 않는다.

같은 원천 사실이 서로 다른 질문에 답할 수 있다. 예를 들어 직원들이 인계는 잘했지만 과도한 근무를 했다면 인계 협력 경험은 좋고 직원 만족도는 나쁠 수 있다. 경영진의 불공정한 배치와 동료의 약속 미이행도 각각 근거를 확인한다. 한 항목의 점수나 단계를 다른 항목에 복사하거나, 같은 협력 책임을 결속도에서 중복 채점하지 않는다.

결속도 때문에 자동으로 생산성·운행·수요·입찰·사고 확률·퇴사·파업이 달라지는 효과는 이번 선택에 포함하지 않는다. 강제 지원·징계·감정/관계 시뮬레이션·새 채용 제도도 추가하지 않는다. 기존에 별도 보류된 상태값 효과와 인사 콘텐츠의 도입은 각각 후속 기획이다.

이번 승인 대상은 COH-E01~08의 8개다. 현재는 모두 미채택이다. 이를 채택하더라도 조직 결속도 1차 기획 전체가 끝난 것은 아니다.

후속 세부 결정 개수는 아직 확정하지 않았다. 실제 직원 공급·직무·권한·업무 배정 등 공통 직원 콘텐츠의 별도 기획도 남아 있으며, 이 평가안이 그 규칙을 대신 승인하지 않는다.

## 14. 작성 및 전달 상태

기존 승인 문서를 수정하지 않은 별도 로컬 초안이다. [작업 티켓](tasks/PLN-018_ORGANIZATIONAL_COHESION.md)과 [검증·결과](tasks/PLN-018_RESULT.md)를 함께 관리한다. OWNER의 채택 이전에 COH-E01~08을 승인 기준선으로 기록하지 않는다. 개발·디자인 검토 요청, 착수 지시, 원격 게시·PR 생성·main 병합은 이번 작업에 포함하지 않는다.
