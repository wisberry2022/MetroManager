## 1. 기존 승인과 이번 선택의 구분

세 영역·원래 사례·정당한 책임·실제 기준, 10/5/0, 영역별 동일 비중, 28일 기억과 기간 밖 미해결 유지, 최소 3사례/2영역, 별도 중대 상한 없음은 유지한다. 기본 보유값 5와 실제 보통 성적을 구분하며 대내적 평판의 현재 종합 단계는 세 자식 모두 현재 유효할 때만 제공한다.

이번에는 이 규칙을 **언제부터 누구의 어떤 기록에 적용할지**를 새로 제안한다. 최초 적용 전에 없던 의무를 소급해 실패로 만들지 않으면서, 지금도 남아 있는 실제 책임은 원래 기한과 함께 보존하는 방향이다. 다른 분야의 적용일·보고 주기·최초 대기기간을 조직 결속도에 자동 복사하지 않는다.

정확한 내부 점수·산식·가중·정밀 기여도는 모든 플레이어 접근 경로에서 비공개다. 적용 예정 시각·업무 범위·실제 책임·자료 상태는 이해할 수 있게 알린다. 구체적인 화면·단계·추세·사유 수·이력 길이는 다음 정보 전달 기획의 범위다.

## 3. COH-M01 준비와 최초 예고

준비 시각 τ는 해당 회사에서 다음 조건을 실제로 확인한 시점이다.

- 첫 세 영역의 직원/업무 콘텐츠, E/C 기준과 전수 수집 경로, 정상 일일 마감이 준비되어 있다.
- 실제 회사·직원·사례·기한·결과·변경/시정의 의미를 구분하고, 적용 경계와 저장/복원을 보존할 수 있다.
- 적용 범위·예정 시각·실제 업무 조건을 플레이어에게 알릴 수 있다.
- 최초 도입인지 기존 적용의 복원인지 판별할 수 있다. 적용 이력 자체가 불명하면 M06으로 분류한다.

이미 실제 3사례가 모였거나 직원 두 명이 근무 중이어야 τ가 되는 것은 아니다. 콘텐츠/관측의 준비와 실제 표본 충분성은 다르다. 회사에 직원이 없다는 사실을 정확히 관측할 수 있다면 도입은 가능하지만 현재 결속도 성적은 자동 생성하지 않는다. 이전 업무의 일부 평가 자료 부족은 그 범위를 명시하고 M03/M06에 따라 현재 평가를 보류할 수 있다.

최초 적용 시각 E는 **τ에서 24게임시간 이상 지난 뒤 처음 맞는 게임일 시작 경계**다. 기존 마감 처리를 마친 뒤 새 적용 구간을 연다. 게임 정지 중 현실 시간이 흘러도 예고가 진행되지 않는다. 평가 도입을 위해 게임 시간·업무·휴식·책임을 강제로 진행하지 않는다.

τ가 10일 09:00이면 24시간 뒤는 11일 09:00이므로 E는 12일 00:00이다. τ가 10일 00:00의 경계 처리 완료 시점이면 E는 11일 00:00이다. 예고 중에는 기존 업무와 실제 결과가 그대로 진행되지만 새 결속 성적을 미리 만들지 않는다. 이어받을 것으로 확인된 현재 책임·원래 기한·미해결과 승계 확인이 필요한 범위를 함께 알려 갑자기 새 의무가 생긴 것으로 오해하지 않게 한다.

최초 적용 전 준비 조건이 사라지면 예정 적용을 보류하고, 실제 준비가 다시 충족된 새 τ부터 온전한 예고를 확보한다. 이미 적용한 회사의 일시 자료 부족은 새 최초 도입이 아니므로 E를 다시 만들지 않는다.

## 4. COH-M02 처음 도입하는 회사의 과거와 새 사례

신규 게임과 결속도 제도를 처음 도입하는 것으로 확인된 기존 세이브에 같은 규칙을 적용한다. 게임 버전 이름이나 저장 날짜만으로 최초 도입을 추정하지 않는다. 이미 같은 제도를 쓰던 세이브는 M05, 적용 여부가 불명한 세이브는 M06 대상이다.

| 최초 적용 경계에서의 상태 | 권고 처리 |
|---|---|
| E 이후 실제 새 협력 책임 성립 | 승인된 E/C 기준으로 수집·판정. 원래 시작·기한·영역·참여자를 기록 |
| E 전에 정상 완료·시정 완료·유효 종료까지 끝난 경험 | 실제 업무 이력은 보존하되 첫 도입의 현재 기억·평가 표본과 과거 성적표를 새로 생성하지 않음 |
| E 당시 진행 중 또는 미해결 | 완료된 과거로 일괄 분류하지 않고 M03의 현재 책임 승계 판단 |
| E 전에 요청만 있었고 정당한 책임은 E 이후 성립 | 실제 책임 성립 시각을 기준으로 새 사례 판단. 오래된 요청 시각만으로 제외하지 않음 |
| 최초 적용 전 보유 숫자만 있고 제도의 실제 평가 근거는 없음 | 그 숫자를 실제 현재 성적으로 인정하지 않음. 출처가 있는 기록은 구분 보존 |

처음 도입하는 회사의 내부 보유값은 기존 기본값 5와 미관측 상태에서 시작한다. 이를 실제 보통 성적이나 과거 보고로 표시하지 않는다. 새 실제 평가가 유효해지면 정상 마감에서 갱신한다. 기존에 유효하게 평가하던 회사의 낮은 값을 5로 초기화하는 규칙이 아니다.

E와 같은 표시 시각의 성립·완료는 기존 게임 사건의 실제 경계 순서까지 확인한다. 새 구간보다 앞서 끝난 일을 새 실적으로 옮기지 않는다. 원래 기한 T에 완료한 일을 로딩·마감 처리 순서 때문에 늦은 것으로 바꾸지도 않는다. 경계가 불명하면 자료 확인 전 판정을 보류한다.

## 5. COH-M03 진행 책임과 미해결 승계

적용 전부터 있던 책임이라도 다음이 확인되면 같은 원래 사례로 연결한다.

1. 당시 실제 필요와 정당한 성립, 서로 다른 실제 직원·역할·주 영역을 식별할 수 있다.
2. 필수 결과·자격/권한·자원/시간 조건·원래 기한이 현재 기준과 같은 의미로 실제 존재했다.
3. 지금까지의 완료·변경·위반·시정과 현재 남은 책임의 전수 근거가 있다.
4. 새 필수 조건을 과거에 추가한 것이 아니며, 메시지·부수 지원·재인계를 별도 사례로 복제하지 않는다.

| 현재 남은 책임 | 권고 처리 |
|---|---|
| 같은 의미의 책임이며 아직 원래 기한 전 | 원래 기한과 완료 조건으로 이어받음. E부터 새 제한시간을 주지 않음 |
| 같은 의미의 책임이 이미 기한을 넘겼고 현재도 미이행 | 현재 미해결 사례로 이어받아 E 이후 정상 마감에서 0 반영 가능. 과거 날짜의 새 보고는 만들지 않음 |
| 이어받은 미해결 책임을 E 뒤 실제로 시정 | 같은 원래 사례 5, 실제 시정 시각부터 기존 28일 기억 적용 |
| 일부 준비가 E 전에 이뤄졌지만 책임은 E 뒤 완료 | 같은 의미의 원래 책임 전체 이행을 확인해 정상/시정 구분. 과거 준비를 별도 성공 사례로 추가하지 않음 |
| 당시 존재하지 않았던 필수 인계 항목이나 새 책임 | 과거 누락·새 위반을 만들지 않음. 원래 실제 업무와 남은 책임을 보존하고 승계 범위 판정 보류 |
| 원래 책임·기한·조건 또는 남은 영향이 불명 | 기한을 E부터 다시 세거나 정상/실패로 추정하지 않음. 해당 불명확 범위를 포함해 현재 평가 보류 |

예를 들어 기존에도 ‘14일 10:00까지 필요한 자료를 넘길 책임’이 같은 조건으로 성립했다면 E가 12일이어도 기한은 14일 10:00이다. 원래 기한이 11일이고 E인 12일에도 같은 책임을 미이행 중이면 현재 미해결로 이어받을 수 있다. 새 제도가 생겼다는 이유로 원래 문제를 없애지 않는다.

반대로 당시에는 요구하지 않았던 인수인계 다섯 조건을 소급해 ‘11일 위반’을 만들지 않는다. 원래 현재 업무는 계속 처리하며, 실제 종료/책임 해소와 평가 범위의 정당한 정리 근거 또는 별도 승인된 전환 기준을 확보한 뒤 다시 판단한다. 승계가 불명확한 진행 책임을 기회 없음으로 빼고 좋은 사례만 평균하지 않는다.

기준이 같은 현재 미해결 사례는 첫 표본에도 들어갈 수 있다. 첫 도입 전에 생겼다는 이유만으로 현재의 실제 책임을 표본에서 제외하지 않는다. 유효한 취소·대체 시정·사실 정정은 C06/C07을 그대로 따르며, 책임 종료 자체를 새 성공 사례로 만들지 않는다.

## 6. COH-M04 최초 현재 평가

적용 이후 온전한 첫 게임일을 마친 정상 마감부터 현재 평가를 판단한다. E에서 시작된 첫 24게임시간이 끝나는 경계가 가장 이른 시점이다. 모든 경우 기존 E06의 충분성 조건을 충족해야 한다.

- 세 영역의 콘텐츠·판정·전수 관측이 준비되어야 한다.
- 실제 평가 사례가 최소 3개, 최소 2영역에 있어야 한다. 같은 의미로 승계된 현재 미해결도 실제 사례다.
- 실제 기회가 있는 영역에는 평가 사례가 최소 하나 있어야 하며, 제외 영역은 실제 기회 없음이 입증되어야 한다.
- 자료 부족·판정 불가·진행 중만 존재·무채점 종료만 존재를 기회 없음으로 바꾸지 않는다.

**28일은 경험을 기억하는 이동 기간이며 최초에 반드시 기다리는 기간이 아니다.** 따라서 E가 12일 00:00이고 첫날에 충분성이 충족되면 가장 빠른 판단은 13일 00:00 정상 마감이다. 그때 부족하면 다음 정상 마감에서 다시 확인한다. 28일이 지나도 자료·표본이 부족하면 자동 현재 성적을 만들지 않는다.

현재 결속도가 유효하지 않으면 직원 만족도·경영진 신뢰도가 유효하더라도 현재 대내적 평판 종합 단계는 대기한다. 결속도를 제외한 새 평균이나 기본 5를 실제 성적으로 쓰지 않는다. 이후 과거의 정상 완료·시정은 원래 시각에 따른 28일 범위에서만 반영하고, 현재 미해결은 기간 밖에서도 유지한다.

## 7. COH-M05 이미 같은 제도를 쓰던 호환 세이브

호환은 저장 형식의 이름이 아니라 평가 의미와 사실을 기준으로 판단한다.

- E/C 규칙의 영역·첫 유형·원래 사례·정당한 책임·완료/시정 조건이 같다.
- 점수 앵커·영역 집계·28일 기억·전수/최소 표본·현재 유효성의 의미가 같다.
- 이미 적용 중이면 원래 E, 예고 중이면 τ/예정 E와 준비 상태를 확인할 수 있다.
- 원래 직원/책임·기한·실제 완료/시정 시각·변경/종료·현재 미해결과 기억 창의 전수 범위를 보존할 수 있다.

| 호환 세이브 상태 | 권고 처리 |
|---|---|
| 이미 적용 중이고 최신 정상 마감의 유효 보고가 있음 | 그 보고가 해당 저장 시각에도 현재성을 유지한다는 근거가 있으면 그대로 복원. 새 보고 발행 아님 |
| 같은 제도의 원천자료·원래 경계는 충분하지만 과거 보고는 없음 | 다음 정상 마감에서 현재 평가 가능 여부 판단. 과거에 발행하지 않은 보고 신설 금지 |
| 원래 예고 중인 저장본 | 남은 예고와 원래 예정 E를 이어받고 준비 상태 재확인. 최초부터 다시 세지 않음 |
| 완료 사례가 원래 기억 창에서 20일 경과 | 원래 완료 시각으로 남은 범위만 사용. 로드 시각부터 새 28일 부여 금지 |
| 현재 미해결이 28일보다 오래됨 | 그대로 현재 책임에 포함. 업데이트/로드/부서 이동으로 삭제 금지 |
| 값만 있거나 적용 이력·의미를 확인할 수 없음 | 호환이라고 추정하지 않고 M06으로 분류 |

로드하는 순간을 새로운 정상 마감으로 취급하지 않는다. 같은 시각을 여러 번 불러도 사례·표본·보고가 늘어나지 않는다. 평가 자료만 다시 계산해야 하는 경우에도 실제 게임 시각과 정상 마감을 따른다. 다른 회사 상태값의 기존 적용·갱신 규칙은 바꾸지 않는다.

## 8. COH-M06 불명확하거나 부족한 자료

적용 이력 불명과 확정된 최초 미도입을 구분한다. 적용 흔적이 있는데 E를 잃었다고 새 τ/E를 만들지 않는다. 점수가 낮거나 현재 미해결이 많다는 이유로 새 회사처럼 초기화할 수 없다.

현재 평가가 불가능하면 마지막 신뢰 가능한 보유값·실제 보고를 원래 시각과 범위로 보존하되 현재 유효성은 보류한다. 믿을 수 있는 값이 없다면 공통 기본값과 미관측 상태를 사용하며 자료 부족을 실제 0 또는 보통 성적으로 설명하지 않는다. 일부 확인된 미해결 책임은 전체 평가 자료 부족과 별개로 남긴다.

핵심 회사·시간·실제 업무 상태가 정상 복원되었다면 플레이와 새 사실 수집을 계속할 수 있다. 일부 자료를 갖춘 영역만으로 회사 현재값을 만들거나, 불명확 영역을 기회 없음으로 제외하지 않는다.

현재 평가를 다시 낼 수 있는 근거는 다음 중 필요한 항목의 실제 충족이다.

1. 누락 자료·원래 E/기한·의미·전체 대상 범위를 복원하여 정상 계산 조건을 충족한다.
2. 빠진 경험이 실제로 종료된 과거라는 점과 그 영향 범위가 확인되어, 해당 완료/시정 시각이 28일 기억 창 밖으로 정당하게 나갔음을 입증한다.
3. 현재 진행/미해결 책임을 실제로 해소하고 승계/제외 경계를 확인한다.
4. 의미가 다른 자료는 별도 승인된 전환 기준으로 연결한다. 이번 안 자체가 임의 환산 권한을 부여하지 않는다.

‘28일이 지났으니 모든 문제를 잊는다’는 복구 규칙은 사용하지 않는다. 현재 미해결 또는 그 존재 범위, 원래 적용 여부가 불명하면 시간 경과만으로 해결되지 않는다. 콘텐츠·관측이 잠시 중단된 경우도 원래 E와 사례를 보존하고 누락 영향이 해결될 때까지 현재 평가를 보류한다.

## 9. COH-M07 과거 보고와 정정

실제로 발행된 과거 보고는 당시 평가 범위·기준·마감 시각·현재성/자료 상태와 함께 보존한다. 처음 도입한 세이브에 과거 성적표를 만들어 채우거나, 자료 없는 날짜 사이를 임의로 보간하지 않는다. 서로 다른 의미의 과거 값을 현재와 같은 조건의 개선/악화 비교점으로 자동 연결하지 않는다.

사실 오류가 확인되면 원래 보고와 실제 근거를 보존한 채 정정 내용·정정 시각·수정 결과를 연결한다. 예를 들어 원래 T에 이행했다는 증거를 뒤늦게 확인한 경우에는 원래 완료 시각으로 사실을 정정한다. 정정일에 새로운 시정 5나 새 28일 경험을 만들지 않는다.

실제로 늦게 해결한 경우에는 실제 시정 시각부터 5로 반영하고 과거에 기한을 지킨 것으로 바꾸지 않는다. 원래 보고의 낮은 성적과 이후 실제 개선을 구분한다. 과거 보고가 없었다면 사실 정정 자료가 있어도 새 과거 보고를 발행한 것처럼 보관하지 않는다.

기준의 의미가 실질적으로 바뀌는 개정은 단순 사실 정정이 아니다. 별도 OWNER 승인과 전환 기준이 필요하며, 이번 안으로 과거 전체 재채점·기준 자동 변경을 허용하지 않는다. 보고의 화면 형식·이력 길이·추세 간격은 후속 정보 전달에서 정한다.

## 10. COH-M08 안전한 전환과 저장 분기

원본을 보존하고 별도 사본에 전환 결과를 만든 뒤 핵심 게임 상태와 평가 승계를 검증하여 사용한다. 전환이 실패한 결과로 원본을 덮어쓰지 않는다. 이는 미래 제품의 전환 정책 제안이며 이번 작업에서 실제 세이브를 변환하는 지시가 아니다.

| 상황 | 권고 처리 |
|---|---|
| 핵심 게임과 평가 의미/경계가 정상 복원됨 | 해당 분기의 원래 적용일·경험·책임·유효 보고를 사용 |
| 핵심 게임은 정상이고 평가 자료만 부족 | 원본 보존, M06의 현재 평가 보류와 새 사실 수집 |
| 핵심 회사/시각/실제 책임 상태를 안전하게 복원하지 못함 | 전환 실패로 처리. 정상 진입을 가장하지 않고 원본 보존 |
| 제도 도입 전 실제 저장 분기로 돌아감 | 그 분기의 준비·예고·최초 적용 여부를 기준으로 처리. 다른 미래 분기의 성적·사건을 가져오지 않음 |
| 이미 적용한 분기의 저장본으로 돌아감 | 그 분기의 원래 E·기한·완료/시정·미해결 복원. 로드를 새 도입으로 취급하지 않음 |
| 인원 증감·퇴사/재입사·부서 변경·회사 표시명 변경 | 이미 승인된 원래 경험/책임 보존. 이 변화만으로 새 예고·E·표본 초기화 없음 |

실제 회사 동일성이나 업무 유형의 의미가 바뀌어 호환을 입증할 수 없다면 적용한 척하지 않고 관련 승계를 보류한다. 새 콘텐츠·회사 단계·기준 확장은 별도 기획으로 다룬다. 다른 상태값의 승계나 전체 인사 기능을 이번 안이 대신 결정하지 않는다.

## 13. 문서 상태

COH-M01~08은 새 제안이며 아직 승인 기준선에 정책으로 편입하지 않았다. [작업 티켓](tasks/PLN-018_ORGANIZATIONAL_COHESION.md)과 [결과](tasks/PLN-018_RESULT.md)에 승인/미결·검증을 구분한다. 개발·디자인 검토 요청, 구현 착수, 실제 세이브 변환, 원격 게시·PR·main 병합은 수행하지 않는다.
