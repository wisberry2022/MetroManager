# PLN-IDEA-007 — 배당 재투자 자금 조달과 자본배분
- 버전: v0.1-draft / 2026-11-21 / Planning
- 상태: **BACKLOG / 현재 승인 범위 밖의 콘텐츠 후보**. Owner의 아이디어 보존 지시에 따른 등록이며 기능·수치·도입 승인은 별도다.
- 근거: [경영진 신뢰도 범위 보정과 영향 요인](../PLN-017_MANAGEMENT_TRUST_SCOPE.md), [PLN-017 티켓](../tasks/PLN-017_MANAGEMENT_TRUST_SCOPE.md).
- 연결 영향 요인: MGT-F01·MGT-F03·MGT-F05·MGT-F06.

## 아이디어와 목적

투자·유보·배당 방침과 실제 집행, 증자와 기존 지분 변화, 조달 목적·장기 투자·주주 간 배분의 경험을 설계하여 경영진에 대한 신뢰의 실제 경험을 만들 수 있게 한다.

## 유지하는 현재 정책

기존 C/R/F/K/A/B 원장·정부 제한자금 용도·사업 예약금 규칙과 재정 FIN-01~07을 보존한다. 이미 남아 있는 신용/부채 후속 기획과 연계하며 별도 대출 체계를 중복 확정하지 않는다.

## 후속 결정과 제외 범위

- 검토할 사항: 재원과 배분 가능 범위·결정 주체·금액/시점·주주 권리·지분 변화·유동성/공사/안전 영향·계획 변경·회계/세이브.
- 이번에 확정하지 않는 사항: 배당이 많을수록 신뢰가 높다거나 재투자가 항상 우수하다고 정하지 않는다. 정부 R·예약 K를 배당 재원으로 전환하거나 당장 새 회계 거래를 만들지 않는다.
- 다시 검토할 시점: 주주 관계/자본 구조와 실제 금융 콘텐츠의 도입 범위를 먼저 정한 뒤 연계 설계.
- 관계 있는 기존 아이디어: [기존 목록](README.md)의 PLN-IDEA-001~003 정책은 변경하지 않는다.

## 소관과 상태

Planning은 규칙·경계·평가 연결을, Development는 실제 자료·저장·구현을, Design은 선택과 상태 전달을 검토할 대상이다. 구현 범위·일정·최종 기능은 후속 승인 사항이다. 이번 부서 검토 요청·메시지·착수 지시는 없다. 로컬 아이디어 등록이며 Commit/Push/PR·main 병합은 하지 않았다.
