# PLN-IDEA-003 — 장기 미지급에 따른 신규 사업 계약 제한
- 버전: v0.1-draft / 2026-11-01 / Planning
- 상태: **BACKLOG / MVP 제외 Owner 결정 완료**, 추후 세칙·기간 승인 별도.
- 의사결정 이력: 초기 6게임개월 경과 신규 계약 제한 제안 및 중간 'MVP 유지' 정정 후, Owner의 **최종 A안 'MVP에서 제외하고 Idea Library에 보존'** 결정 우선.
- **MVP 쉬움·시철:** 미지급 B>0이면 신규 승차 제한. 그러나 미지급 존재·6개월 경과만으로 **신규 사업 계약을 금지하지 않는다**. 일반 자금·자격·K/R 제약은 유지.
- 미래 기능 후보: 6개월 연속 미지급 시 신규 계약 제한. 최초 B>0 기산, 일부 변제/추가 미지급에 미초기화, 완납 B=0 시 초기화는 당시 논의한 참고 모델이며 미래 명세 확정은 아님.
- 검토 과제: 난이도×회사 운영주체 차등 기간, 신용도/부채/정부 계약 자격, 기존 계약·공사 영향, 장기 세션/시뮬레이션 재현, UX 경고.
- 소관: Planning 밸런스, Development 시간·상태, Design 제한 사유, HQ 범위/견적; Owner 별도 승인 필요.
