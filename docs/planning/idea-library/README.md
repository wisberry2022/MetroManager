## 경영진 신뢰도 관련 추가 기록

2026-11-21 Owner의 범위 보정·아이디어 보존 지시에 따라 PLN-IDEA-004~009를 로컬 등록했다. [PLN-017 개정안](../PLN-017_MANAGEMENT_TRUST_SCOPE.md)의 여섯 영향 요인과 연결한다. **직원과 주주를 신뢰의 평가 대상으로 포함하는 정의는 현재 기획에 반영**하며, 아이디어 저장소에는 이를 실현할 별도 콘텐츠와 평가 이후 효과를 보존한다. 기존 PLN-IDEA-001~003은 변경하지 않았다. 당시에는 로컬 등록 단계였다. 이번 PLN-017 직접 제출 지시에 따라 회사 설계서와 함께 작업 브랜치의 draft PR로 게시하며 부서 검토 요청은 보내지 않는다.

2026-11-22 여섯 영향 요인·평가 집계 A01~10·실제 평가 기준표 B01~10·적용/승계 M01~08·표시 I01~06의 총 40개 권고 묶음이 모두 채택됐다. [경영진 신뢰도 1차 기준선 v1.0](../PLN-017_MANAGEMENT_TRUST_BASELINE.md)에 현재 승인과 필수 콘텐츠 입력·조건부 전환·별도 확장·부서 확인/검증을 통합했다. 이 목록의 독립 콘텐츠 기능 전체를 채택한 것으로 확대하지 않으며 PLN-IDEA-004~009의 BACKLOG 상태를 유지한다. 승인된 평가를 위한 최소 직원/주주 관계·보고·직무·권한 등의 준비는 필수이며, 전체 아이디어 기능이 BACKLOG라는 이유로 선택 사항으로 낮추지 않는다.
