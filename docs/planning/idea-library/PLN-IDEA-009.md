# PLN-IDEA-009 — 경영진 신뢰 변화에 따른 직원과 주주 행동

- 근거: [경영진 신뢰도 범위 보정과 영향 요인](../PLN-017_MANAGEMENT_TRUST_SCOPE.md), [PLN-017 티켓](../tasks/PLN-017_MANAGEMENT_TRUST_SCOPE.md).
- 연결 영향 요인: MGT-F01~06의 평가 이후 효과.

## 아이디어와 목적

직원의 잔류/이직·협조·노사 갈등, 주주의 의결·경영진 교체 요구·추가 투자 의향 등 실제 행동으로 이어지는 조건과 회복을 설계하여 경영진에 대한 신뢰의 실제 경험을 만들 수 있게 한다.

## 유지하는 현재 정책

회사 상태값의 역방향 효과는 기존 미승인 후속 범위다. 신뢰값을 만들었다고 기존 채용·운행·수요·입찰·원장·주주 의결을 자동 변경하지 않는다.

## 후속 결정과 제외 범위

- 검토할 사항: 효과 대상·발동/해제·지연·반복 방지·규모·무작위성/재현·사전 안내·회복·상쇄·난이도/회사 유형·세이브.
- 이번에 확정하지 않는 사항: 정확한 내부 점수나 발동 임계값을 플레이어에게 노출하지 않는다. 항의나 파업이 없다는 사실을 신뢰의 원천 실적으로 역산하지 않는다. 주가·주식시장 효과는 별도 범위 선택이 필요하다.
- 다시 검토할 시점: 신뢰 평가와 데이터/표시가 검증된 뒤, 실제 게임 효과가 필요한지 별도로 결정.
- 관계 있는 기존 아이디어: [기존 목록](README.md)의 PLN-IDEA-001~003 정책은 변경하지 않는다.

## 소관과 상태

Planning은 규칙·경계·평가 연결을, Development는 실제 자료·저장·구현을, Design은 선택과 상태 전달을 검토할 대상이다. 구현 범위·일정·최종 기능은 후속 승인 사항이다. 이번 부서 검토 요청·메시지·착수 지시는 없다. 로컬 아이디어 등록이며 Commit/Push/PR·main 병합은 하지 않았다.
