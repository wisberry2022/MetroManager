# PLN-IDEA-004 — 직원 처우 고용 약속과 공정한 인사 절차
- 버전: v0.1-draft / 2026-11-21 / Planning
- 상태: **BACKLOG / 현재 승인 범위 밖의 콘텐츠 후보**. Owner의 아이디어 보존 지시에 따른 등록이며 기능·수치·도입 승인은 별도다.
- 근거: [경영진 신뢰도 범위 보정과 영향 요인](../PLN-017_MANAGEMENT_TRUST_SCOPE.md), [PLN-017 티켓](../tasks/PLN-017_MANAGEMENT_TRUST_SCOPE.md).
- 연결 영향 요인: MGT-F01·MGT-F05.

## 아이디어와 목적

급여·상여·복지·승진·고용 안정에 관한 확정 약속과 실제 이행, 인사 기준·의견 접수·이의 처리·변경 협의을 설계하여 경영진에 대한 신뢰의 실제 경험을 만들 수 있게 한다.

## 유지하는 현재 정책

기존 직원 만족도 1차는 근무·휴식 경험 기준이다. 그 승인에 필요한 실제 직원·근무·휴식 최소 콘텐츠는 계속 필요하며, 이 등록으로 선택적 후순위로 내리지 않는다. 현재 운영비를 임금으로 추정하지 않는다.

## 후속 결정과 제외 범위

- 검토할 사항: 첫 도입 기능·대상·실제 비용과 원장·약속 성립/변경·공정한 차등 기준·종료/퇴사·구제/분쟁·직원 만족도와 신뢰의 중복.
- 이번에 확정하지 않는 사항: 임금 지급·고용 종료·추가 권리·보상 또는 파업 효과를 이번 등록으로 만들지 않는다.
- 다시 검토할 시점: 실제 직원 콘텐츠의 첫 범위를 정할 때, 근무·휴식 외 처우/인사 기능의 필요성을 별도 판단.
- 관계 있는 기존 아이디어: [기존 목록](README.md)의 PLN-IDEA-001~003 정책은 변경하지 않는다.

## 소관과 상태

Planning은 규칙·경계·평가 연결을, Development는 실제 자료·저장·구현을, Design은 선택과 상태 전달을 검토할 대상이다. 구현 범위·일정·최종 기능은 후속 승인 사항이다. 이번 부서 검토 요청·메시지·착수 지시는 없다. 로컬 아이디어 등록이며 Commit/Push/PR·main 병합은 하지 않았다.
