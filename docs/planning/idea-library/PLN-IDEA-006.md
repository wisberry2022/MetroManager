# PLN-IDEA-006 — 회사 형태별 주주 관계와 지배구조
- 버전: v0.1-draft / 2026-11-21 / Planning
- 상태: **BACKLOG / 현재 승인 범위 밖의 콘텐츠 후보**. Owner의 아이디어 보존 지시에 따른 등록이며 기능·수치·도입 승인은 별도다.
- 근거: [경영진 신뢰도 범위 보정과 영향 요인](../PLN-017_MANAGEMENT_TRUST_SCOPE.md), [PLN-017 티켓](../tasks/PLN-017_MANAGEMENT_TRUST_SCOPE.md).
- 연결 영향 요인: MGT-F01~06의 주주 관점, 특히 MGT-F05.

## 아이디어와 목적

회사 형태·주주 구성·지분·주주 권리·정보 접근·주주총회·이사회·경영진 선임/감독, 직원 겸 주주의 역할 구별을 설계하여 경영진에 대한 신뢰의 실제 경험을 만들 수 있게 한다.

## 유지하는 현재 정책

경영진 신뢰도 정의에 주주를 포함하는 것은 이번 Owner 정정이다. 이 아이디어는 주주 포함을 미루는 기록이 아니라 이를 실현할 구체 제도 후보다. 현재 C v0.7의 MVP/쉬움/시철 고정 범위는 유지한다.

## 후속 결정과 제외 범위

- 검토할 사항: 어떤 회사에 주주가 존재하는지·인원/지분/관점별 평가 집계·공공 출자자와 감독기관의 경계·의결/감독 절차·소수 주주·회사 형태 전환과 승계.
- 이번에 확정하지 않는 사항: 주주가 있다는 이유로 상장·주식시장·주가를 자동 추가하지 않는다. 주주 자료 부족을 직원 점수로 채우거나 임의 50:50 가중/새 정식 계층을 확정하지 않는다.
- 다시 검토할 시점: 주주가 실제 존재하는 운영주체의 콘텐츠를 설계할 때. 신뢰의 평가 대상 정의는 지금부터 주주를 포함.
- 관계 있는 기존 아이디어: [기존 목록](README.md)의 PLN-IDEA-001~003 정책은 변경하지 않는다.

## 소관과 상태

Planning은 규칙·경계·평가 연결을, Development는 실제 자료·저장·구현을, Design은 선택과 상태 전달을 검토할 대상이다. 구현 범위·일정·최종 기능은 후속 승인 사항이다. 이번 부서 검토 요청·메시지·착수 지시는 없다. 로컬 아이디어 등록이며 Commit/Push/PR·main 병합은 하지 않았다.
