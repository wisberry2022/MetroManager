## 1. 이미 승인된 원칙과 이번 선택

[회사 내부 상태값 설계서](PLN-004_POST_MVP_COMPANY_STATE_V0_7.md) §1~2에서 기관 연계는 관계·교류·업무 협력의 범위와 활성화를 나타내는 규모형 상태값으로 승인됐다. 높을수록 더 넓은 범위가 관측된다는 의미이며, 호감·신뢰·우호·규제 지지나 성과의 좋고 나쁨을 뜻하지 않는다. 기관의 제재·감시가 있었다는 이유만으로 자동 증가하는 규칙은 승인되지 않았다.

기존 시청/정부 심사, 공개 입찰 점수·낙찰, 제출 제한·수정/재접수, 사업비·제한자금, 공사·안전·영업의 규칙은 그대로다. 이번 내부 지표의 인정 여부로 그 업무의 접수나 결과를 바꾸지 않는다. 이 문서는 게임 규칙이며 현실 행정기관의 법정 권한을 규정하지 않는다.

## 3. 기관과 관할을 구분하는 기준

### 3.1 같은 기관과 서로 다른 기관

한 시청 안의 교통 담당·재정 담당·담당자 교체는 같은 행정주체다. 구·동이 여러 개이고 역·노선이 여러 곳에 있어도 각 구청/동 행정조직과 실제 적격 활동이 있었다고 추정하지 않는다. 실제 독립 업무 주체 여부와 기관 분류는 게임의 기관 목록과 승인된 업무 권한으로 먼저 정한다.

첫 지방 범위는 기존 도시의 시청과 동일한 도시 행정주체 역할이다. 광역시/특별시를 도 아래 시와 혼동하거나 구/동을 독립 시청으로 취급하지 않는다. 도청·구청·읍면동의 독립 접점, 기관 없는 가상 상대, 외국·복합기관 등은 첫 범위에 자동 추가하지 않는다. 해당 콘텐츠를 추가하면 기관 단위·역할·범위 전환을 별도로 기획한다.

같은 업무라도 서로 다른 실제 기관이 각자의 권한으로 독립 처리한 경우는 기관별 근거로 구분할 수 있다. 한 기관의 같은 결정을 지방·중앙·안전으로 복제하지 않는다. 안전/감독 전담 기관은 소재지나 상급 기관만 보고 일반 지방/중앙기관과 이중 계산하지 않는다. 복합기관의 여러 기능을 나누는 새로운 콘텐츠는 별도 기준이 필요하다.

기관의 단순 개칭·담당 변경은 같은 기관과 원래 활동 시각을 보존한다. 실제 합병·분할·권한 이전은 이름만 보고 같은/다른 기관으로 확정하지 않는다. 그 콘텐츠가 필요하면 별도 연결 정책을 정하며, 확인 전 영향을 받는 현재 집계를 임의로 확정하지 않는다.

### 3.2 첫 시나리오의 의미

기존 C01 첫 범위는 한 도시이며 실제 시청 주체도 하나다. B01 시청 발주와 B02 같은 도시의 정부 발주는 다른 역할이다. B02가 C01 안에 있다는 이유로 지방기관을 추가하지 않는다.

따라서 A05 권고안을 적용하면 C01의 단일 시청만 접촉할 수 있는 동안은 실제 지방 값이 0 또는 5로 제한될 수 있다. 이는 작은 관계 범위를 나타내며 불성실·실패·처벌 근거가 아니다. 3기관 이상이라는 상한은 미래에 실제로 허용된 다기관 범위를 표현하는 첫 환산 기준이며, 새 도시 진출·외부 관할 응찰·기관 신설 권한을 주지 않는다. 아래의 2·3기관 계산은 합법적인 게임 콘텐츠가 마련되었을 때의 가상 예시다.

## 4. 첫 활동의 실제 인정과 제외

| 활동 | 인정 조건 | 인정 시각과 결과 |
|---|---|---|
| 회사 제안의 시청 판정 | 기존 규칙상 유효 접수된 실제 사업 계획, 실제 대상 시청, 해당 계획/근거에 대한 확정 판정이 연결됨 | 실제 승인 또는 거부 판정의 효력 시각. 예상 결과·접수·대기만으로 인정하지 않음 |
| 지방기관 발주 입찰 | 실제 발주자가 첫 범위의 지방기관이고, 회사의 유효 응찰이 경쟁 판단 대상으로 처리되어 확정 낙찰/탈락 결과가 있음 | 실제 확정 결과의 효력 시각. 공고 조회·접수 오류·자격 미충족 차단·단순 포기만으로 인정하지 않음 |

시청의 음수 사업성 거부도 실제 유효 심사 결과라면 인정한다. 같은 기업의 사업 위험이나 경영진 판단에 미치는 영향은 해당 승인 규칙으로 따로 판단한다. 긍정 결과를 선택해 관계 규모를 과장하지 않는다.

정부 최종 심사·정부 발주 입찰은 지방 첫 활동에 포함하지 않는다. 중앙행정기관 세칙을 미리 확정하거나 유효 점수를 생성하는 것도 아니다. 안전검증·제재·감시·일방 통지·자동 영수증은 이번 두 활동으로 자동 전환하지 않는다. 별도 유형을 인정하려면 실제 양측 업무의 의미를 새로 정한다.

계약 체결·정부금 입금·지역사회 안내·공사 기성·완공만으로 추가 기관을 만들지 않는다. 지역사회 안내를 했다는 것과 지방행정기관이 실제 업무를 처리했다는 것은 다른 사실이다. 입찰 낙찰 뒤 기존 규칙에 없는 시청/정부 재심사를 새로 요구하지 않는다.

실제 심사 중 사업 종료·응찰 취소로 결과까지 도달하지 않았다면 인정 활동은 아직 없다. 이미 유효하게 확정된 결과 뒤 사업이 끝나거나 계약 관계가 종료된 경우에는 실제 과거 접점을 그 기간 안에서 보존한다. ‘최근 실질 교류가 있었던 기관’과 ‘지금도 협약·계약이 유효한 기관’을 동일한 정보로 표시하지 않는다.

### 4.1 반복과 재제출

기관 수는 활동 수가 아니다. 한 시청과 유효한 업무가 열 번 있어도 그 기간의 N에는 한 번만 들어간다. 여러 활동 가운데 하나가 기간 밖으로 나가도 다른 유효 활동이 남으면 그 기관은 유지한다.

같은 원래 사업·기관·실질 심사 근거를 그대로 재전송/재처리하거나 조회·불러오기한 경우에는 새 활동 시각을 만들지 않는다. 옛 활동이 28일 밖으로 나간 뒤 같은 자료를 다시 제출해도 이 금지는 유지한다. 새 명령 ID·revision·슬롯명·화면명만으로 구분하지 않는다.

기존 절차가 허용하는 재제출 자체를 막지는 않는다. 연계 활동의 새로운 인정에는 실제 심사에 쓰인 계획 또는 관련 수요/비용 등 판단 근거의 실질 변화와 실제 새 판정이 필요하다. 같은 원래 사업에서 이미 처리된 근거 A를 B로 바꿨다가 예전 A로 되돌린 경우, 관련 실제 사실의 변화가 없다면 A를 새 근거로 반복 인정하지 않는다. 새 계획을 저장했다는 사실만으로 판단 근거가 달라졌다고 보지 않는다.

기존 동일 사업 규칙상 독립된 실제 새 사업이나 별도 실제 입찰 회차는 독립 활동일 수 있다. 기존 하나의 사업을 슬롯·역 이름·서류로 쪼개 새 사업으로 만드는 것은 인정하지 않는다. 같은 기관이면 여러 독립 활동도 N에는 한 번만 들어가지만 마지막 유효 활동 시각에는 영향을 줄 수 있다.

어떤 변경이 실질 근거 변화인지 입증할 자료가 없으면 새 활동이라고 임의 확정하지 않는다. 누락이 측정 범위의 완전성을 훼손하면 A07에 따라 현재 평가를 보류한다.

## 5. 내부 계산과 시간의 의미

N은 정상 측정 대상 기간 안에 A03~04의 인정 활동이 한 번 이상 있는 서로 다른 첫 범위 지방기관 수다. 회사가 일방적으로 연락할 수 있는 기관 수, 행정구역 수, 심사 성공 수가 아니다.

- N=0이면 내부 값 0.
- N≥1이면 내부 값 `min(10, 5 + 2.5 × (N − 1))`.
- 중간 반올림·금액/횟수/승인 성공률 가중을 추가하지 않는다.
- 중복 제거는 일별 기관 수를 합산한 뒤 하는 것이 아니라 전체 28일 기간의 기관 집합을 기준으로 한다.

| 실제 인정 기관 수 | 내부 제안값 | OWNER가 이해할 의미 |
|---:|---:|---|
| 0 | 0 | 확인된 기간에 첫 범위의 실질 처리 접점 없음 |
| 1 | 5 | 한 기관과 접점이 확인됨 |
| 2 | 7.5 | 두 기관으로 접점 범위가 넓어짐 |
| 3 이상 | 10 | 첫 환산 기준의 넓은 범위 상한. 기관의 호감이나 전 기관 접촉 완료를 뜻하지 않음 |

이 값과 식은 플레이어 비공개다. 확인된 기관 이름·실제 업무 결과 등 기존에 공개할 수 있는 업무 정보와 내부값/정밀 변화·산식·필요 기관 수의 안내는 구분한다. A05 채택만으로 새 업무 목록 화면이나 점수 계산기를 승인하지 않는다.

### 5.1 28게임일과 정상 마감

활동이 발생한 업무일을 10일이라고 부르면 10~37업무일의 정상 마감 집계에 포함하고 38업무일 마감부터 제외한다. 실제 마감 시각은 그 업무일을 마치는 경계이며 업무일 번호와 혼동하지 않는다. 같은 시각의 판정/마감 귀속은 기존 일계·사건 순서를 따르고 새 순서를 강제하지 않는다.

한 기관에 10일과 20일의 서로 다른 유효 활동이 있으면 10일 활동이 빠진 뒤에도 20일 활동 때문에 남는다. 마지막 유효 활동까지 기간 밖으로 나가면 그 기관은 최근 접점 수에서 빠진다. 과거 보고와 업무 이력을 삭제하는 뜻은 아니다.

열린 신청·현재 미해결 의무·직원이 알고 있는 기관 연락처만으로 활동 기간을 늘리지 않는다. 반대로 접점 수에서 빠졌다고 계약·지급·보고·시정 의무를 면제하지 않는다. 조직 결속도나 리스크의 ‘모든 현재 미해결 유지’ 집계 방식을 기관 활동 수에 복사하지 않는다.

게임 정지 중 현실 시간이 지나거나 배속·분할 실행·조회·재로드해도 실제 활동이 추가되지 않는다. 현재 값 갱신은 정상 마감에 하며, 실제 새 판정의 당일 안내와 마감 측정값을 구분한다. 사실 정정으로 원래 인정 근거가 달라지면 원래 사실/시각에 연결하고 정정일을 새 기관 접점으로 생성하지 않는다. 과거 보고·세이브 정정의 구체 전달은 후속 적용/승계·표시에서 정한다.

## 6. 자료 완전성과 현재 종합

정상 28게임일 측정에서는 그 기간의 전체 대상 기관·회사 제안/입찰의 적용 범위·실제 결과·원래 활동 시각·중복/재처리 근거가 확인되어야 한다. 성공한 결과만 있거나 일부 사업 기록만 남아 있는 경우 전체 관계 범위를 확정하지 않는다.

이 요건을 충족하면 유효 활동 0건은 실제 0이다. ‘최소 3사례/2영역’, ‘성공한 심사 1건’ 같은 다른 지표의 표본 조건을 추가하지 않는다. 모든 회사가 반드시 시청 제안과 입찰을 모두 해야 하는 것은 아니다. 두 유형의 전수 관측이 준비되고 그중 한 유형에 실제 활동이 없다는 사실이 확인되면 된다.

소속/관할 위반, 접수 실패, 판정 전 대기가 사실로 확인되면 그것은 아직 인정 활동이 없는 상황이다. 기록이 없어 그 상태인지 판별할 수 없는 상황과 구분한다. 존재하는 기관을 식별할 수 없거나 일부 유형이 구현/관측되지 않은 상태를 ‘활동 없음’으로 바꾸지 않는다. N≥3으로 보이더라도 관측 누락을 숨겨 확정값 10을 제공하지 않는다.

기본/마지막 보유값과 현재 유효성을 분리한다. 미관측 기본값 5가 ‘실제로 한 기관과 접촉했다’는 뜻은 아니다. 기관 연계의 정식 세 자식 보유값 평균은 기존 승인대로 계속 유지하지만, 플레이어에게 현재 종합을 제시하려면 지방·중앙·안전/감독 세 자식 모두 현재 유효해야 한다. 지방만 유효할 때 중앙/안전의 기본값을 실제 관측처럼 설명하거나 유효 자식만으로 평균을 다시 만들지 않는다.

**최초 관측 기간을 온전한 28일로 요구할지, 적용 이후의 짧은 기간을 인정할지와 기존 자료 승계는 이번 8개에 포함하지 않는다.** 적용 시작·기존 세이브 안에서 명시적으로 선택한다. 따라서 이 초안을 근거로 새 게임의 첫 마감에 0 또는 5를 실제 평가로 확정하지 않는다. 중앙·안전/감독의 개별 활동/환산·적용 세칙도 후속 분야다.

## 7. 기존 기능에 미치는 영향과 후속 기획

규모가 넓어져도 시청 승인, 정부 적합 확률, 설득 기회, 입찰 점수/자격·동점 순위, 사업비, 수요·운임, 사고 확률에 보너스나 제한을 자동 적용하지 않는다. 관계의 질·기관 신뢰도를 새 정식 상태값으로 추가하지 않는다. 기존 기능의 실제 결과를 관측 자료로 읽는 범위다.

이번 8개를 채택하면 공통 의미·명칭·기관 단위와 지방의 첫 측정/집계 원칙이 확정된다. 다음에는 지방 분야의 적용 시작·기존 세이브/과거 활동 승계, 그 다음 규모형 단계·추세·원인·과거값·자료 부족 전달을 정리한다. 이후 중앙행정기관·안전/감독기관의 개별 기준을 별도 진행한다.

실제 기관 목록과 기존 발주자/시청의 연결, 관할·실질 근거 변화의 실제 자료가 필요한 점은 유지한다. 새 교류 콘텐츠·추가 기관/도시·합병/분할·금융/지원 협약·민원/제재 등을 첫 활동에 확장할지는 해당 범위를 도입할 때 별도 기획한다. 이번 초안은 별도 신규 기관 이벤트를 만들어 바로 실행하라는 지시가 아니다.

## 10. 현재 선택과 작성 상태

이번 새 선택은 ILK-A01~08의 8개다. 기존 승인 사항을 다시 선택하는 목록이 아니다. 특히 명칭, 첫 두 활동, 기관 수 환산, 28일 기간과 상위 현재 종합 조건은 기존에 확정된 값으로 주장하지 않는다.

채택 이후의 적용 시작·기존 세이브·과거 활동 승계와 규모형 정보 전달, 중앙/안전·감독 세칙은 별도 후속이다. 실제 데이터 공급과 화면·게임 검증도 남아 있다. [작업 티켓](tasks/PLN-019_INSTITUTION_LOCAL_LINKAGE.md)과 [결과](tasks/PLN-019_RESULT.md)에 로컬 범위·검사를 기록한다. 승인 문서·기존 코드·타 부서 산출물은 변경하지 않는다.
