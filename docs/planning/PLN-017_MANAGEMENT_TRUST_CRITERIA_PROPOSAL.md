## 1. 이번 기준표가 결정하는 것

권고는 **안정운영 중인 회사의 첫 기준표**다. 직원에게는 실제 영업의 지속과 필요한 인력의 충족을, 주주에게는 운행 손익과 가용자금 완충을 성과 목표로 둔다. 그 밖의 다섯 요인은 실제 약속·보고·위기 대응·공정절차·자원 집행 사례로 판단한다.

기존 10개 승인 규칙을 다시 선택하지 않는다. 회사에 실제 직원·주주와 필요한 콘텐츠가 없으면 평가 입력을 만들 수 없으며, 현재 구현 완료라고 가정하지 않는다. 자료 공급이 어려운 경우에도 이 기준을 개발팀이 임의로 완화하도록 넘기지 않는다.

| ID | 새로 결정할 사항 | 권고안 | 대안과 차이 |
|---|---|---|---|
| MGT-B01 | 첫 적용 회사와 최소 콘텐츠 | 안정운영 기준표부터. 실제 직원·보통지분 주주 관계, 계획·약속·보고·공정절차·자원 집행 근거 필요 | 개통 전·성장투자·특수지분 회사까지 함께 설계하면 범위와 예외가 커짐 |
| MGT-B02 | 약속의 실제 평가 대상 | 확정된 근무조건/개선 이행과 확정된 사업/자금 운용 약속. 대상·결과·기한·유효 조건을 성립 시 고정 | 전망·홍보까지 전부 약속으로 취급하거나 자발적으로 등록한 약속만 평가 |

| MGT-B04 | 직원 성과 목표 | 28일마다 계획 영업 충족률 95% 이상, 필수 직무 충족률 100%의 두 목표 | 직원 만족도 점수로 대신하거나 직원 목표에도 이익을 직접 요구 |
| MGT-B05 | 주주 성과 목표 | 28일 운행 손익 0 이상과 실제 활동 조건, 기간 말 가용자금이 기준 정상 운영비 3일분 이상인 두 목표 | 모든 기간에 투자이익·배당·주가 상승까지 요구하거나 현금 총액만 비교 |
| MGT-B06 | 위기 때 무엇을 언제까지 해야 하는가 | 기존 원천 사건에 연결. 재무 회복 7일, 공사 중단의 실제 재개/지급 정상화 1일, 안전 유효 복구 1일 | 모든 종류를 같은 기한으로 처리하거나 리스크 점수를 그대로 사용 |

| MGT-B08 | 책임 있는 자원 집행 | 중요한 실제 결정마다 용도·유효 계획/예산·권한·필수 운영기반 보호를 대조 | 지출 규모·배당액·재투자액이 크면 좋은 평가로 처리 |
| MGT-B09 | 정당한 변경·종료와 실제 시정 | 통상 변경은 1일 전 통지와 필요한 동의, 미래 의무에만 적용. 실제 손상/의무의 복구까지 확인 | 모든 취소를 위반 처리하거나 설명만 하면 과거 위반도 면제 |
| MGT-B10 | 중요한 정보·핵심 권리·중대사건의 판정 | 미리 정한 유형과 실제 사실로 판정. 일반 실수·의견 충돌과 고의 은폐/권리 박탈/사익 사용을 구분 | 금액 한 가지로만 중대성을 정하거나 담당자의 자유 판단에 맡김 |

각 묶음은 아래의 관련 세칙을 포함한다. 채택 대상은 평가에 필요한 의미와 조건이며 전체 인사·지배구조 기능의 구현 착수 승인이 아니다.

## 2. B01 첫 적용 범위와 공통 기록

### 2.1 안정운영 기준표

첫 기준표는 기간 시작에 유효 개통된 실제 운행과 양수의 정상 운영계획이 있고, 시나리오에서 정상 영업을 지속하는 단계로 지정된 회사에 적용한다. 안정운영 단계 지정은 기획된 시나리오/사업 단계에 근거한다. 플레이어가 평가 직전 편한 기준표를 고르거나 손실을 보고 성장투자 단계로 소급 변경하지 못한다.

개통 전, 계획된 대규모 투자손실을 감수하는 성장 단계, 축소/정리 단계의 성과 목표는 별도 기준표가 필요하다. 아직 없는 표를 안정운영 목표로 대체하거나 해당 관점 자체를 미적용 처리하지 않는다. 다른 요인의 확인된 사건은 보존하되 현재 전체 평가는 승인된 충분성 조건을 따른다. 이는 전체 회사 유형을 설계 완료했다는 뜻이 아니다.

직원은 실제 직접 고용자, 주주는 실제 등록된 동일 권리의 보통지분 보유자를 첫 콘텐츠 기준으로 삼는다. 상장·거래시장·의결권·배당 시스템이 선행 조건은 아니다. 특수지분·간접 보유·자기주식·공공 출자자/감독기관은 의미를 정한 별도 표가 필요하며 이미 존재하는 관계를 조용히 제외하지 않는다. MVP 시철이 어떤 주주를 가진다고 임의 가정하지 않는다.

### 2.2 최소 입력과 적용 대상의 고정

각 사례에는 원래 사례 ID, 요인, 직원/주주 대상, 실제 관계와 당시 가중, 기준 버전, 내용/결과, 성립·효력·판정 기한, 실제 이행, 시정 완료조건, 사실 확정 근거, 변경 이력을 둔다. 기술 필드명·저장 스키마는 추후 개발 계약이다.

| 사례 | 원래 대상·가중을 정하는 경계 |
|---|---|
| F01 확정 약속 | 의무가 성립해 대상에게 효력이 생긴 때 |
| F02 정기 보고 | 해당 보고 대상 기간 종료. 중요 사건 보고는 실제 영향이 생긴 때 |
| F03 성과표 | 해당 28일 기간 시작 |
| F04 위기 대응 | 실제 위험/중단/결함 사건 시작 |
| F05 공정절차 | 원래 결정의 대상이 확정된 때 |
| F06 자원 집행 | 실제 원래 배분/집행 결정의 효력 경계 |

과거 대상·가중은 퇴사/매도로 다시 쓰지 않는다. 기간 중 신규 직원/주주에게 발생한 새 약속·보고·권리 경험은 그때의 실제 관계로 평가하며, F03의 기존 기간 대상은 유지하고 다음 기간에 갱신한다. 대상은 단순 회사 전체 인원이 아니라 실제 역할별 영향을 받은 집단이어야 한다.

첫 콘텐츠 묶음에는 실제 관계·유효 운영/직무 계획, 확정 약속 기록, 보고 전달/정정, 정해진 공정절차, 중요한 자원 결정 기록이 필요하다. 급여·승진·배당·주식거래 전체는 별도 확장 후보로 유지한다. 기능/기준이 아직 없는 요인은 기회 없음이 아닌 미준비다. 준비된 기능에서 실제 결정이 없었다는 전수 근거가 있을 때만 기회 없음이다.

여섯 요인의 준비가 끝나도 실제 평가 요인이 4개 미만이면 현재 종합은 보류한다. 조용한 정상 운영에서 보고·성과·자원 결정만 관측됐다는 이유로 약속/위기/공정성의 가상 성공을 만들거나 불필요한 변경을 권하지 않는다. A08을 바꾸려면 별도 명시적 정책 개정이 필요하며 이번 표는 이를 완화하지 않는다.

F03의 목표 결과는 각 관점 대상에 동일한 회사 성과를 근거로 제공한다. F01/F02/F05처럼 대상별 이행 결과가 다르면 A03의 직원 동일 인원·주주 당시 지분 가중을 실제로 적용한다.

## 3. B02 약속과 방침 이행 — F01

| 관점 | 첫 실제 약속 | 판정 근거·기한 | 시정 완료 |
|---|---|---|---|
| 직원 | 확정된 배치/근무조건 변경, 실제 문제 개선 조치. 휴식 약속도 그 한 종류 | 유효한 내용과 대상에게 약속한 효력 시각/완료 기한에 실제 상태가 약속과 일치 | 남은 의무 이행과 이미 발생한 권리/업무 손상의 정해진 복구를 모두 완료 |
| 주주 | 회사가 확정한 사업 추진·자금 운용 방침의 구체적 이행 약속 | 약속한 결정/집행 결과와 기한. 예산/자금의 실제 권한·제약을 함께 확인 | 남은 실행 의무 또는 정당하게 합의된 대체 이행과 필요한 구제 완료 |

금액·조건이 정해지지 않은 급여·상여·배당을 이번 표로 생성하지 않는다. 해당 콘텐츠가 도입될 때 별도 약속 유형을 추가한다. ‘좋아질 전망’, 목표 수익, 계획 검토와 확정된 지급/실행 약속은 구별한다.

확정 의무에 해당하는 실제 행동은 별도 즐겨찾기/평가 등록을 하지 않아도 모두 대상이다. 유리한 약속만 선택 등록하지 못한다. 기한 없는 표현에는 임의 1일/28일 기한을 부여하지 않으며 약속 성립 기준 미충족 또는 기준 확인 필요로 구분한다.

기한 내 전부 이행은 10, 확인된 위반 후 실제 시정은 5, 확인된 미해소 위반은 0이다. 기한 전 정상 진행과 결과 불명은 실패가 아니다. F04 복구와 같은 원래 의무를 F01에 다시 등록하지 않는다. F03의 성과 목표는 예측/성과 기준이며 같은 결과를 확정 약속으로도 중복 채점하지 않는다.

## 4. B03 정보 정확성과 투명성 — F02

### 4.1 보고 내용

| 관점 | 7일 정기 보고의 필수 내용 | 별도 중요 변화 알림 |
|---|---|---|
| 직원 | 지난 기간의 실제 운영·필수 직무 배치, 확정 근무조건/변경, 남은 약속과 문제·대응 상태 | 근무조건/배치의 중요한 변경, 업무 기반을 바꾸는 위험·중단·안전 결함, 확인된 권리 침해와 시정 |
| 주주 | 도착 완료 운임 매출·발생 운영비·운행 손익, 총현금과 제한/예약/가용자금 구별, 사업·약속·위험과 자원 결정 상태 | 중요한 사업/자원 계획 변경, 위기·확정된 중요 오류·권리 침해, 예정된 중요한 자본 결정 |

보고하지 않아도 되는 추측·미확인 의도를 의무 내용으로 만들지 않는다. 일부 실제 자료가 불명이라면 확인된 사실과 미확인 범위·확인 진행을 정확히 밝혀야 한다. 원천 사실 자체를 검증할 수 없으면 ‘확인 중이라고 썼다’는 이유만으로 전체 정확성 10을 만들지 않는다.

### 4.2 기한과 사건 수

- 연속된 7개 마감 게임일을 한 보고 기간으로 하고, 기간 종료부터 **1게임일 이내** 실제 대상에게 전달한다. 종료 후 정확히 1일 경계의 기존 처리를 마친 뒤 판정한다.
- 중요한 사건을 회사가 확인한 때부터 **1게임일 이내** 사실·현재 조치·남은 문제를 알린다. 실제로 알려진 사건의 공지를 늦춰 기한 시작을 미루지 못한다.
- 미리 정한 변경은 해당 효력이 생기기 전에 고지한다. B09의 통상 1일 전 통지를 적용한다. 긴급 보호조치는 먼저 실행할 수 있으나 확인 후 1일 이내 설명 의무는 남는다.
- 보고의 중요한 오류가 실제 확인되면 **1게임일 이내** 동일 영향 대상에게 정정과 필요한 보완을 전달한다. 이미 발생한 잘못된 전달이 확인됐다면 정정으로 시정 5가 될 수 있으며 과거부터 정확했던 10으로 바꾸지 않는다.
- 정기 보고와 같은 순간·같은 범위의 중요 사건 통지를 한 전달로 모두 충족할 수 있다. 전달 횟수만 늘려 같은 원래 의무를 복제하지 않는다. 정기 보고는 원래 기간별로 한 사례다.
- 자동 발송도 실제 회사의 보고 의무·정책과 대상 전달 사건이 있으면 수동과 동일하게 인정한다. 플레이어용 자동 재무 화면·열람·보고서 재발행만으로 새 보고 실적을 생성하지 않는다.

첫 보고 기간의 시작점은 후속 적용 기획에서 정하며 이번 표에서 새 세이브 적용 시점을 확정하지 않는다. 보고 내용의 실제 업무 사실과 정확한 신뢰 점수의 공개는 별개다.

## 5. B04 직원의 실제 성과평가표 — F03-E

안정운영 직원 표는 **두 목표를 동일하게** 적용한다. N=2이며 각 목표 충족 여부를 확정한 뒤 기존 10×K/N을 사용한다. 두 목표면 10, 하나면 5, 둘 다 미달이면 0이다. 개별 목표를 작은 항목으로 나눠 비중을 늘리지 않는다.

| ID | 목표 | 실제 판정 방법 | 권고 기준 |
|---|---|---|---|
| E-P01 | 계획한 영업을 지속할 능력 | 기간 시작에 고정한 실제 운행별 계획 영업분 중, 기존 영업/신규 승차 조건을 실제로 충족한 분의 비율 | 28일 합산 **95% 이상** |
| E-P02 | 필요한 업무 인력을 확보·배치할 능력 | 확정된 직무별 필요 인원×시간 중 실제 자격/배치가 충족된 인원×시간의 비율 | 28일 합산 **100%** |

E-P01은 단순 운영 스위치나 수요/승객 수가 아니다. 수요가 0이어도 실제 영업 조건이 충족되면 그 분은 충족으로 본다. 같은 실제 운행을 노선 이름으로 복제하지 않고 기존 서비스의 실제 운행 동일성을 따른다. 계획 분모가 양수여야 하며 계획을 사후 줄여 중단 시간을 없애지 않는다.

E-P02는 직무별·시간별로 필요 인원까지만 인정한다. 한 구간의 초과 배치가 다른 시간/직무의 결원을 상쇄하지 못하고, 같은 직원을 동시에 두 업무에 중복 배치한 것처럼 세지 않는다. 실제 직무 자격·필수 인력 표는 직원/운영 콘텐츠의 기획 입력이어야 한다. 영업 중이었다는 사실만으로 인력이 있었다고 추정하지 않는다.

이 목표는 직원 만족도의 W/U·7일 점수나 휴식 평가를 복사하지 않는다. 인원이 충분해도 과부담은 별도로 발생할 수 있으며 직원 만족도와 F01/F05의 실제 경험은 독립적으로 남는다. 부족 인력 때문에 실제 운행을 강제로 중단하는 새 게임 규칙을 추가하는 것도 아니다.

두 분모와 전수 자료가 유효하면 실제 영업/인력 공급 0은 목표 미달이다. 필요 직무 표나 대상 기록이 없으면 0이 아니라 기준 미준비/자료 부족이다.

## 6. B05 주주의 실제 성과평가표 — F03-H

안정운영 주주 표도 **두 목표**, N=2다. 실제 지분 비중은 그 기간 원래 대상에게 적용하며 직원/주주 전체 비중 50:50을 바꾸지 않는다.

| ID | 목표 | 실제 판정 방법 | 권고 기준 |
|---|---|---|---|
| H-P01 | 운영 자체에서 손실을 확대하지 않음 | 같은 28일의 실제 도착 완료 운임 매출−발생 운영비. 양수 발생 운영비와 실제 영업 합계 1,080분 이상도 충족 | **손익 0 이상** 및 활동 조건 모두 충족 |
| H-P02 | 다음 운영을 이어갈 자금 기반 | 기간 말 기존 정산 완료 후 A=max(0,F−ΣK), 기간 시작에 고정한 정상 1게임일 운영비 E_ref>0와 비교 | **A≥3×E_ref** |

H-P01은 현금 지급액이 아닌 발생 비용을 쓴다. 정부 사업금·신규 출자·차입·자산 매각을 운임 매출로 넣지 않는다. 1,080분은 이번 첫 성과표의 활동 조건으로 새 제안하며 기존 재정의 7일 평가 기간을 바꾸지 않는다. 완전한 기록으로 실제 무영업/활동 미달이 확인되면 목표 미달이다. 기록이 없어서 활동을 모르면 보류다. 비용이 아예 없는 별도 사업모델에는 이 표를 적용하지 않는다.

H-P02의 E_ref는 유효한 기간 시작 운영계획에서 고정한다. 기간 중 계획 축소로 목표를 낮추지 않으며 기간 말 하루만의 비용으로 바꾸지 않는다. R/K를 배당/일반 운영 가능한 자유현금으로 합산하지 않는다. 지급을 미뤄 발생 비용을 없애지 않으며 과거 약속 위반도 지워지지 않는다. 이 값은 재정 점수/위험 사례의 회복 기준을 변경하지 않는다.

목표 두 개를 충족했어도 정보 은폐·불공정·미해소 중대사건은 다른 요인 및 승인된 상한에 그대로 반영된다. H-P02는 28일 전체가 항상 안정적이었다는 의미가 아니라 기간 말의 다음 운영 기반이다.

### 6.1 양 관점의 첫 필수 유지조건

첫 성과표의 공통 필수 유지조건은 **기존 승인 게임 규칙상 회사 존속 종료/파산이 실제 확정되지 않았을 것**으로 한정한다. 실제로 확정되면 해당 F03 사례는 0이다. 현금 부족·적자·장기 전망만으로 파산을 새로 추정하지 않으며 파산 기능/사건을 이번 표로 도입하지 않는다. 상태 자체가 불명이라면 평가 근거가 부족하다.

다른 요인에서 이미 판정한 같은 지급 지연·허위 보고·권리 위반·자원 위반을 필수 유지조건으로 다시 등록하지 않는다. 해당 위반은 원래 요인과 A06의 중대 상한으로 처리한다.

계획적 투자손실·성장투자 단계는 별도 성과표에서 허용 손실/기간별 목표를 사전에 정해야 한다. 이번 안정운영 표에 임의 적자 허용액을 끼워 넣지 않는다.

## 7. B06 위기 대응과 책임 이행 — F04

같은 원천 위험이라도 직원의 실제 업무/보호 관계와 주주의 실제 사업/자본 관계가 있어야 해당 관점의 사례가 된다. 기존 리스크 점수나 사건 알림을 모든 사람의 신뢰로 자동 복사하지 않는다.

| 종류 | 실제 시작과 필요한 결과 | 신규 신뢰 의무 기한 |
|---|---|---|
| 운영자금 위험 | 기존 §26의 실제 위험 시작. 미지급 해소·기존 재무상 승차 조건·사례 중 최고 정상 하루 운영비의 3일분을 1게임일 유지한 실제 회복 | 원래 시작부터 **7게임일 이내**, 안정 확인 1일 포함 |
| 실제 공사 중단/지급 차질 | 착공 후 실제로 공정을 이어가야 하나 중단된 원래 사건. 기성 지급 차질 해소와 실제 공정 재개, 이미 공정 100%이면 미지급 최종 기성까지 지급 | 원래 중단 시작부터 **1게임일 이내** |
| 개통 전 안전 결함 | 유효 검사에서 실제 결함 확정. 필요한 수리와 현재 조건에 유효한 재시험 통과 | 원래 결함 확정부터 **1게임일 이내** |

모두 신뢰 의무를 기한 내 충족하면 10, 기한이 지났고 확인된 미해소이면 0, 뒤늦게 실제 시정하면 5다. 정상 기한 전/자료 부족을 실패로 처리하지 않는다. 경계 시각의 기존 처리를 마친 후 판정한다.

**기존 리스크는 그대로다.** 예를 들어 안전 복구 300분은 기존 안전 역량에서 5지만 새 신뢰 의무인 1일 안에는 이행했으므로 F04는 10일 수 있다. 1일을 넘겨 복구하면 기존 안전 사례의 확정 0은 남고, F04는 실제 시정 5가 될 수 있다. 두 항목은 평가 목적과 회복 규칙이 다르다.

공사 1일은 새 신뢰 대응 의무이지 법정/공사계약 완료 기한이 아니다. 기존 사업위험의 25%/100% 누적 중단·완공·최저 집계는 유지한다. 지연이 없었던 정상 완공을 F04의 가상 위기 성공으로 넣지 않는다.

같은 미해소 사건에서 중단·재개 요청·수리 재시도·이름 변경은 시계/사례를 초기화하지 않는다. 유효한 실제 회복 후 독립된 새 위험의 여부는 원천 사례 동일성으로 판단한다. 기존 재무위기의 재발 연결 규칙도 유지한다. 기존 위험이 재개되면 같은 신뢰 사례를 다시 연결하고 최초 기한·과거 위반을 보존한다.

직원에게 필요한 실제 보호조치가 추가로 정의된 콘텐츠라면 해당 조치 완료도 필요하다. 이번 첫 표에 없는 산업재해·구조·보상·사고 모델을 임의로 가정하지 않고 후속 기준으로 분리한다.

## 8. B07 공정성과 존중 — F05

첫 범위는 실제로 발생한 배치/근무조건 결정과 사업/자원 의사결정 과정이다. 급여·승진·배당·의결권의 전체 제도를 이번에 확정하지 않는다.

| 관점 | 사전 기준과 실제 절차 | 복구해야 할 대상 |
|---|---|---|
| 직원 | 직무 필요·자격·유효 근무조건 등 미리 정한 기준을 같은 상황에 일관되게 적용. 영향 대상에게 이유와 의견/이의 경로 제공 | 잘못 제외된 참여 기회, 잘못 적용한 배치/조건 및 해당 콘텐츠의 구제 |
| 주주 | 같은 권리의 보통지분 대상에게 같은 종류의 설명/참여 기회를 제공. 소수 지분만 근거 없이 제외하거나 소유 기록을 임의 변경하지 않음 | 박탈한 정보 접근/의견 기회·실제 권리 또는 잘못 변경된 지분 기록 |

실제 이의가 접수되면 **7게임일 이내** 근거 있는 답변과 실제 필요한 후속 조치를 명시한다. 답변만으로 미복구 권리 침해가 시정되지는 않는다. 내용 검토 후 정당한 기각도 가능하며, 모든 요구를 수용해야 공정한 것으로 보지 않는다. 같은 원래 결정에 대한 반복 제출은 새 점수 사례로 복제하지 않는다.

F02는 정보의 진위·필수 전달·기한을, F05는 대상 선택·차등 적용·권리/절차를 판정한다. 동일한 정보 미전달 사실만으로 양쪽을 자동 감점하지 않고 독립된 판단 근거가 있을 때만 각각 평가한다. 이의 답변의 기한/절차는 F05에서 한 번 처리한다.

모든 조건을 충족한 실제 절차 10, 확인된 위반 후 실제 구제 5, 확인된 미해소 위반 0이다. 의견 차이·불만 건수·같지 않은 결과만으로 위반을 추정하지 않는다.

## 9. B08 자원 운용과 장기 방향 — F06

첫 실제 평가 대상은 기존 승인 범위에서 효력이 생긴 신규 사업 참여/집행, 유효한 운영계획·필수 인력 배분 변경, 실제 중요한 예산/용도 변경이다. 확정된 원래 결정과 종속 집행은 한 사례로 묶고 지급을 쪼개 사례 수를 늘리지 않는다.

| 관점 | 중요하게 보는 실제 영향 | 모든 사례에서 대조할 조건 |
|---|---|---|
| 직원 | 필수 인력·안전·운영 기반에 실제 배분한 자원과 업무 영향 | 정당한 권한, 용도 제한, 사전 유효 예산/계획, 그 계획에 명시된 보호조건 충족 |
| 주주 | 회사의 사업 선택·자금 집행·미래 부담과 공개한 방향 | 같은 조건에 더해 실제 대상에게 설명한 목적과 집행 결과의 일치 |

실제 중요 결정의 제약과 계획을 지킨 집행 10, 위반 후 원상/대체 복구를 완료하면 5, 확인된 미해소 위반 0이다. 승인 예산이 실제 비용 때문에 초과됐다면 원래 위임된 변경 범위 또는 사전 유효한 재승인 근거가 있어야 한다. 미래 계획을 바꿀 수 있으나 과거 잘못된 집행을 소급 합법화하지 않는다.

장기 방향은 설명 문구의 웅장함이나 투자금액이 아니라 **그 결정에 적용되는 실제 기간·사업 목적·보호조건과 일치하는가**로 판정한다. 배당·재투자·인력 축소를 일률적으로 좋거나 나쁘다고 정하지 않는다. 실제 보호조건이 정의되지 않았다면 담당자가 임의로 도덕적 판단을 붙이지 않는다.

이 평가는 현재 금지된 자금 전용·플레이어 직접 공사 취소·새 조달/배당을 실행 가능하게 만들지 않는다. 금지행위가 없다는 이유만으로 청렴 10을 생성하지 않는다. 정상적으로 가능한 실제 자원 결정에서 계획/권한 준수를 확인해야 한다.

F03의 운영 충족·인력 충족·손익·기간 말 자금 결과와 F06의 결정 권한·집행 절차는 다른 질문이다. F03 실패를 이유로 F06도 자동 실패로 만들지 않는다.

## 10. B09 유효 변경·종료·시정 조건

통상적인 미래 조건 변경은 **효력 1게임일 전까지** 내용·이유·영향을 알리고 원래 규칙이 요구하는 권한과 동의를 실제로 확보해야 한다. 대상자의 확정된 권리를 줄이는 변경은 실제 영향 대상의 동의와 해당 콘텐츠의 변경 권한이 모두 필요하다. 동의 기능/기록이 없는데 묵시적 동의를 가정하지 않는다.

현재 안전을 지키기 위한 긴급 중단/보호는 사전 통지를 기다리지 않는다. 기존 권한과 실제 긴급 사유에 따라 행동하고 B03의 1일 이내 설명을 적용한다. 긴급조치를 이유로 과거 지급/복구 책임을 삭제하지 않는다. 새로운 비상 권한이나 공사 취소권을 부여하는 규칙은 아니다.

| 요인 | 실제 시정 완료의 최소 확인 |
|---|---|
| F01 | 남은 이행 의무와 필요한 대체 이행/구제 완료. 사과/새 계획만으로 완료 아님 |
| F02 | 정정과 누락 보완의 실제 대상 전달, 잘못된 정보로 생긴 확인된 권리 침해의 필요한 구제 |
| F04 | B06의 실제 회복/재개/유효 복구. 요청·예약·비용 지출만으로 완료 아님 |
| F05 | 박탈한 기회/권리 복구, 필요한 결정 재처리와 명시된 구제. 답변만으로 완료 아님 |
| F06 | 잘못 집행한 자원/용도·권한 문제의 실제 복구와 필요한 구제. 장부 설명 변경만으로 완료 아님 |

원상복구가 불가능한 경우에는 사전에 정의된 대체 구제 조건을 실제 충족해야 한다. 그 콘텐츠에 대체 구제 기준이 없으면 ‘시정 완료’로 임의 선언하지 않는다. 모든 위반을 돈을 지급하면 해결되는 것으로 만들지 않으며 구체 보상 제도는 별도 콘텐츠다.

정당한 종료는 권한·기한·통지·필요 동의·미정산 책임을 확인한다. 아직 발생하지 않은 미래 의무는 정당하게 끝날 수 있으나, 이미 위반한 의무는 종료·퇴사·매도로 지워지지 않는다. 이 종료만으로 성공 10이나 시정 5 사례를 추가하지 않는다.

## 11. B10 중요성과 중대사건 판정표

‘중요’는 자의적 금액 문턱 대신 실제 결정에 영향을 주는 범위로 첫 지정한다.

| 구분 | 첫 지정 범위 | 단독으로 해당하지 않는 것 |
|---|---|---|
| 중요 정보 | 확정 근무조건/필수 배치 변경, 현재 위기·안전 결함, 유효 사업/자원 계획 변경, 총현금과 제한/예약/가용자금 혼동, 실제 지급·손익·권리 상태를 바꾸는 오류 | 결과 해석에 영향 없는 문구/서식 차이, 확인되지 않은 소문 |
| 핵심 권리 | 적용 콘텐츠에 명시된 필수 설명 접근·의견/이의 기회, 실제 확정 근무조건과 필요한 동의, 실제 등록된 주주 소유/동일권리의 참여 기회 | 승진 보장·항상 배당·이익 보장 등 아직 정하지 않은 권리 |
| 중대사건 사실 | 중요한 공식 정보의 고의 허위/은폐가 실제 확정, 핵심 권리 박탈이 실제 확정, 제한 자원 목적 외 사용/사익 제공이 실제 확정 | 단순 적자·의견 충돌·일반 실수·의도 불명·실행되지 않은 의혹 |

중요 정보의 고의 허위/은폐는 게임에서 의도적 선택/행위와 사실 대조가 확인돼야 한다. 불완전한 자료나 오류만으로 고의를 붙이지 않는다. 핵심 권리의 ‘박탈’은 해당 권리를 실제로 제거/거부한 것이며 단순 절차 지연은 우선 일반 사례로 다룬다. 늦은 답변이 자동으로 중대사건이 되는 것은 아니다.

중대사건이 미해소면 기존 A06 상한을 적용한다. F02·F05·F06 어디의 사건인지 주 요인을 기록하며 별도 감점 사건을 다시 더하지 않는다. 확인된 중대사건은 현재 사실로 유지하고 전체 자료가 부족하면 점수를 3으로 확정하지 않는다. 실제 시정조건 완료 후 다음 정상 마감에 해제 가능하다.
