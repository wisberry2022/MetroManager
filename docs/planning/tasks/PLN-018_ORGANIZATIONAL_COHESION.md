## OWNER 요청과 허용 범위

2026-11-22 현재 Planning 대화에서 OWNER는 조직 결속도 1차 기획 기준선을 원격 저장소의 기존 회사 내부 상태값 설계서에 반영하고 PR을 생성하도록 직접 요청했다. 최신 main 확인, 기존 승인 및 정확한 내부 점수 비공개 유지, 개발·디자인 검토 요청과 main 병합 제외가 조건이다.

이 지시는 이번 문서 통합에 필요한 작업 브랜치 생성·단일 부모 커밋 게시·PR 생성을 포함한다. main 직접 쓰기/병합·auto-merge·릴리스/배포, 개발·디자인 메시지·리뷰어 지정·착수 지시, 실제 구현/화면/세이브 변환은 허용 범위가 아니다. 과거 다른 항목의 PR 지시를 재사용하지 않는다. 비공개 대화 전문이나 개인 링크를 게시하지 않는다.

원래 로컬 PLN-018의 7파일은 보존하고 최신 main의 별도 작업 사본에서 통합한다. 원격 main의 기획 경로·동명 브랜치와 PLN-018 제목의 Issue/PR 검색에서 기존 해당 업무를 찾지 못했다. E01 PLN-016·경영진 신뢰도 PLN-017과 다른 작업이며 번호나 정책을 대체하지 않는다.
