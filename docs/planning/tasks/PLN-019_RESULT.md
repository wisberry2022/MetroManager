현재 명칭을 ‘유관기관 연계 수준’과 세 ‘연계 수준’으로 정리하고 원래 노드·값·이력을 보존한다. 기존 헤더/공통 범위·명칭·미결 표·개정/참조를 승인 내용과 연결했다. 기존 §3~5·§9~99 정책 본문은 변경하지 않는다.

실제 기관·두 활동·같은 근거 재처리·기관 수 환산·28일·전수 자료·부모 현재성, 예고·과거 활동/첫 28일·진행 업무·호환/불명·정정/원본/분기, 중립 3단계·7일 비교·사유 2개·28개 이력·복수 자료 상태와 정확한 점수 비공개를 보존한다. 중앙/감독 개별 세칙과 조건부 확장은 후속으로 구분했다.

개발 확인 18개·디자인 확인 11개, 기대 사례 A/M/I 각 40개 총 120개를 연결했다. 요청이나 실행 완료를 뜻하지 않는다. [채택 당시 기준선](../PLN-019_INSTITUTION_LOCAL_LINKAGE_BASELINE.md)에는 제출 연결 배너만 추가하고 세 원문은 원래 로컬 파일과 동일하게 제출한다. 원래 로컬 6파일은 수정하지 않는다.

제출은 회사 설계서 1개·기준선/원문 4개·티켓/결과 2개, 총 7파일이다. 다른 기획·타 부서·게임 소스·공통 정책/도구/CI는 변경하지 않는다.

## 원격 제출과 권한 경계

OWNER가 이번 작업의 원격 기존 설계서 반영·PR 생성을 직접 요청했다. 최신 main에 단일 부모 commit, 기존 base tree 보존, 명시 브랜치·expected head·force=false로 게시하고 draft PR을 생성한다. API 게시가 로컬 commit/push 훅을 실행했다고 주장하지 않는다. 게시 후 실제 head의 필수 policy·department-policy와 provenance 진단, 로컬 preflight를 확인해 PR 본문에 기록한다.

현재 Agent-ID는 미확인이며 다른 담당자 ID나 가짜 Manifest를 사용하지 않는다. main/head가 바뀌면 다시 확인하고 같은 브랜치의 다른 변경을 덮어쓰거나 강제 push하지 않는다.
