## 미실행·제출 경계

이용자 신뢰도의 실제 자동 게임 테스트·세이브 변환/불러오기·UI·독립 Design 검수·밸런스 실측: NOT_RUN. Godot 프로젝트 로드·게임 플레이·Windows 빌드·성능·AC/VP 인수: NOT_RUN. 문서 통합 범위이며 구현 착수/인수 지시가 아니다. §56의 32개는 후속 수용 기준이며 문서 사례의 산술 검산은 실제 게임 테스트와 다르다.

GitHub 플러그인의 단일 부모 commit·base tree 보존·기대 head·force=false 방식으로 작업 브랜치와 draft PR에 제출한다. 원격 main 보호의 필수 검사 policy·department-policy는 실제 제출 head에서 별도 확인한다. REPORT_ONLY 진단도 실제 상태대로 기록하며 Agent-ID를 임의 발급하지 않는다.

현재 공통 범위·이용자 신뢰도 1차 정책 미결은 0건이다. 개발 공급·디자인 상세·실제 검증은 미확인/미실행이며 다른 두 평판 자식의 상세 기획·조건부 확장·다른 회사 상태값은 별도 범위다. 기존 승인 정책의 변경 필요성은 이번 통합에서 확인하지 못했다.

개발·디자인 검토 요청·리뷰어 지정·착수 지시·main 병합·auto-merge·릴리스/배포는 수행하지 않는다. PR 작성과 CI 성공을 최종 승인·DONE·제품 구현 인수로 표시하지 않는다.
