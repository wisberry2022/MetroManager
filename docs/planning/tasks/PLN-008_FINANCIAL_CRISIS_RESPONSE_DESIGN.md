## 목적

재무위기 대응역량 1차 기준선 v1.0의 승인된 평가 8개, 적용·승계 6개, 정보 전달 6개를 기존 회사 내부 상태값 설계서에 통합한다. 기존 재정·서비스 수준 본문을 보존하고 승인 규칙·후속 범위·부서 확인 목록·검증 기준을 구분한다.

## 승인·선행조건·근거

- 후속 Planning 대화에서 권고안 **8+6+6=20개**를 순차 채택했으며, 이번 지시 직전 최종 통합 기준선을 유지한다. 비공개 대화·인수인계서 원문·개인 경로는 게시하지 않는다.
- 이번 Owner 직접 지시: 재무위기 대응역량 1차 기준선을 원격의 기존 설계서에 반영하고 PR 생성. 최신 main 확인과 기존 재정·서비스 수준 보존. 개발·디자인 검토 요청과 main 병합은 하지 않음.
- 허용 범위: `wisberry2022/MetroManager`, `codex/PLN-008-financial-crisis-design`, 아래 기획 문서 3개의 작성·커밋·브랜치 게시·draft PR 제출 및 필수 검사 확인. 이번 요청 수행 기간에 한정하며 포괄 권한 위임이 아니다.
- 제외 권한: main 직접 쓰기/병합, auto-merge, 릴리스/배포, 부서 메시지·리뷰어 지정·착수 지시, 게임 구현/인수 완료 선언.
- 확인한 최신 main: `a65591b1e632121cd6dab4b66a23424fe8803869`. 기존 회사 설계서 v0.9 blob `a4413b3e2bc389a2187ed80547119e82178adbe7`. 서비스 PR #109와 재정 PR #112의 본문을 보존한다.
- 이번 회사 문서는 v0.10, 재무위기 대응역량 1차 기준선은 v1.0이다. 기존 링크 호환을 위해 파일명은 유지한다.
- 원격 main 트리·117개 Issue/PR·브랜치 및 로컬 파일명을 대조해 PLN-008 중복을 확인하지 못했다. 과거 PLN-004/006/007 티켓·결과는 수정하지 않는다.
- main의 AGENTS, Planning README, 부서/Git/제출/코드 규칙, ENFORCEMENT, HQ 운영 규정과 provenance/등록 전환 규정을 확인했다. 별도 작업 사본을 사용하며 새 Agent-ID를 임의 발급하지 않는다.
