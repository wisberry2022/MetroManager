## 목적

재정 1차 기획 기준선 v1.0의 승인된 계산·관측 8개, 적용·승계 6개, 정보 전달 6개를 기존 회사 내부 상태값 설계서에 통합한다. 서비스 수준 1차 본문을 보존하고, 추후 담당자가 승인 규칙·조건부 확장·부서 확인 목록·검증 기준을 구분해 사용할 수 있도록 한다.

## 승인·선행조건·근거

- 후속 Planning 대화의 3차례 권고안 채택: **8+6+6=20개**. 이번 지시 직전 재정 1차 최종 통합본의 정책을 유지한다. 비공개 대화·인수인계서 원문이나 개인 경로를 공개 저장소에 올리지 않는다.
- 이번 Owner 직접 지시: 재정 1차 기준선을 원격의 기존 회사 내부 상태값 설계서에 반영하고 PR 생성. 최신 main 확인, 기존 서비스 수준 기획 유지. 개발·디자인 검토 요청과 main 병합은 하지 않음.
- 허용 범위: `wisberry2022/MetroManager`, `codex/PLN-007-company-state-finance-design`, 아래 기획 문서 3개 작성·커밋·브랜치 게시·draft PR 제출. 이번 지시를 수행하는 기간에 한정하며 포괄 권한 위임이 아니다.
- 제외 권한: main 직접 쓰기/병합, auto-merge, 릴리스/배포, 부서 메시지·리뷰어 지정·착수 지시, 게임 구현/인수 완료 선언.
