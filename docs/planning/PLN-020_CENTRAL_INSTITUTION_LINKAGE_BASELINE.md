**측정 기준 7개**

중앙행정기관 연계 수준은 최근 실제 업무를 처리한 중앙기관의 범위다. 정부의 호감·우호·신뢰·지지나 승인 성공률을 뜻하지 않는다. 첫 범위는 국토교통부의 기존 사업 심사·발주 업무다. 추가 중앙부처·산하기관이나 안전·감독 활동을 자동 편입하지 않는다.

| ID | 확정 내용 |
|---|---|
| CEN-A01 | 첫 기관 범위는 기존 사업 심사·발주를 담당하는 국토교통부. 소재 도시가 같아도 지방기관으로 바꾸지 않으며 실제 기관과 기능으로 분류한다. |
| CEN-A02 | 유효 회사 제안의 실제 정부 적합·보류·부적합 판정을 모두 인정한다. 같은 근거의 보류→설득 성공/실패는 하나의 처리 묶음이며 최초 정부 판정 시각을 유지한다. |
| CEN-A03 | 중앙기관이 실제 발주한 공고의 유효 응찰에 대해 확정된 낙찰·탈락 결과를 인정한다. 결과의 유불리로 가중하지 않는다. |
| CEN-A04 | 같은 기관은 한 번만 센다. 같은 원래 업무·같은 실질 근거의 반복은 시각을 갱신하지 않는다. 독립된 새 사업·입찰 회차 또는 적격 신규 사실에 따른 실제 새 판정은 유효한 새 활동일 수 있다. |
| CEN-A05 | 정상 기간 안에서 인정되는 서로 다른 기관 수 N으로 환산한다. 0기관=0, 1기관=5, 2기관=7.5, 3기관 이상=10. 기관별 동일 비중이며 금액·성공률·횟수는 가중하지 않는다. |
| CEN-A06 | 최근 마감된 28게임일을 정상 일일 마감마다 집계한다. 진행 중 사업·계약·지급 대기·연락처만으로 활동 기간을 연장하지 않는다. |
| CEN-A07 | 전체 대상·정부 심사와 중앙 발주 입찰의 전수 기록이 완전하면 활동 없음도 실제 0이다. 성공 횟수나 다기관 접촉을 최소 표본으로 요구하지 않는다. 누락·미제공·기관/근거 불명으로 현재 집계를 확정할 수 없으면 보류한다. |

정부의 실제 보류 판정과 아직 결과가 없는 심사 대기는 다르다. 조회·예상 결과·접수 차단·단순 접수·단순 포기는 적격 결과가 아니다. 시청에서 거부되어 정부 심사에 도달하지 못한 업무도 중앙 접점을 만들지 않는다.

국토교통부 심사 부서와 발주 부서, 담당자 변경, 같은 기관의 여러 사업은 별도 기관 수가 아니다. 시청 발주 B01의 정부 사전 승인만으로 회사와 중앙기관의 접점을 만들지 않는다. 국토교통부 발주 B02의 실제 유효 응찰 결과는 중앙 활동이다. 낙찰 이후 기존에 없는 정부 재심사를 요구하지 않는다.

정부금 입금·계약 체결·지역사회 안내·공사 진행만으로 새 중앙기관이나 새 활동 시각을 만들지 않는다. 같은 기관의 같은 활동을 지방·중앙·안전감독에 복제하지 않는다. 서로 다른 실제 기관이 각자 처리한 독립 근거는 해당 기관 분야에서 구분한다.

보류 뒤 같은 근거로 설득이 끝나면 최초 판정일을 유지한다. 실제 새로운 적격 사실이 판단에 사용된 유효 새 판정은 CEN-A04에 따르며, 단순히 설득 버튼을 누르거나 새 문서 번호를 부여한 사실로 인정하지 않는다. 기존 설득 기회·재접수 제한·사실 소비·E01 규칙은 그대로다.

같은 사업의 이미 판단한 근거 A→B→예전 A는 실제 사실 변화 없이 새 활동으로 인정하지 않는다. 슬롯·revision·명령 ID·회사/기관 표시명 변경이나 28일 경과도 중복 이력을 초기화하지 않는다. 새 활동이라는 근거가 부족하면 임의 시각을 만들지 않는다.

활동 업무일이 40일이면 40~67업무일의 정상 마감에 포함하고 68업무일 마감부터 제외한다. 같은 기관의 다른 유효 활동이 기간 안에 남아 있으면 그 기관은 유지한다. 사업이 종료돼도 기간 안의 실제 과거 접점은 남지만 현재 계약의 유효성을 뜻하지 않는다.

첫 C01 범위의 국토교통부 하나에서는 실제 내부값이 0 또는 5다. 이는 관계 범위이며 성과 부족·불이익의 근거가 아니다. 2기관 이상 환산은 승인된 계산 기준이지만 추가 기관·관할·콘텐츠를 도입하는 승인은 아니다. 숫자·환산표는 OWNER와 제작팀용이다.

내부 노드 범위 0~10 소수, 기본 5와 미관측 구분, 부모의 직접 자식 보유값 산술평균을 유지한다. 부모 계산에서 미관측 자식을 빼지 않는다. 플레이어의 현재 종합은 지방·중앙·안전감독 모두 현재 유효할 때만 제공한다. 중앙만 유효하다고 기본 5를 실제 다른 기관 접촉으로 설명하지 않는다. 이 지표로 허가 확률·입찰 점수·금액·수요·사고 등에 보너스나 제약을 자동 적용하지 않는다.

준비는 실제 교류 경험을 요구하지 않는다. 활동이 없는 상태까지 온전히 관측하고 저장·안내할 수 있으면 된다. 과거 자료가 없는 회사도 새 관측을 시작할 수 있으나 첫 현재 평가의 요건은 별도다. 최초 미도입이 확인된 상태, 이미 적용한 상태, 적용 여부가 불명한 상태를 구별한다.

위 시점은 기관·중복·승계 근거도 확인된 경우다. 전체 기간에 실제 교류가 없어도 자료가 완전하면 실제 0으로 판단한다. 두 활동 유형을 모두 수행해야 하는 것은 아니다. 활동 1회·성공 1회 조건도 없다. 과거 활동의 승계는 당시 없던 보고를 소급 발행하는 권한이 아니다.

E와 같은 표시 시각의 결과는 기존 사건 순서와 실제 효력 경계에 따라 귀속한다. 경계를 확인할 수 없으면 임의로 적용 후 활동으로 옮기지 않는다.

호환성은 이름·버전명·보유 숫자만으로 판단하지 않는다. 실제 기관/활동 의미, 원래 적용·관측·중복 근거, 실제 보고가 같은 의미인지 확인한다. 예고 중이면 원래 예정 시점과 남은 예고를, 적용 후면 원래 기간을 이어받는다. 최신 정상 마감의 유효 보고를 복원할 수 있지만 로드는 새 마감이 아니다. 실제 보고가 없었다면 다음 정상 마감에 현재 평가를 판단한다.

과거 누락이 현재 창 밖으로 나갔더라도 현재 재처리·기관 동일성·최초 보류 판정 등에 영향을 주면 보류를 유지한다. 영향이 해소되고 필요한 현재 근거가 충족되면 다음 정상 마감에 재개한다. 28일 경과만으로 초기화하거나 재개하지 않는다. 믿을 만한 값이 없을 때는 공통 기본값과 미관측 상태를 사용하되 새 최초 적용으로 가장하지 않는다.

정정은 원래 활동 시각과 실제 보고에 연결한다. 현재 보고의 근거가 깨졌으면 현재 유효 표시를 보류하고 새 현재 평가는 다음 정상 마감에 판단한다. 실제 평가 의미의 변경은 사실 정정과 구별하며 별도 기획이 필요하다. 핵심 회사·시간·업무를 안전하게 복원하지 못한 전환 실패는 평가 자료만 부족한 정상 플레이와 구분한다. 다른 저장 분기의 미래 기록이나 현실 경과 시간으로 관측 기간을 채우지 않는다.

OWNER·제작팀용 공통 단계 경계는 0 이상 4 미만 제한적, 4 이상 7 미만 형성됨, 7 이상 10 이하 폭넓음이다. 중앙 환산값 0/5/7.5/10에 순서대로 제한적/형성됨/폭넓음/폭넓음이 대응한다. 첫 C01에서는 국토교통부 하나이므로 실제 제한적 또는 형성됨이 가능하다. 미관측 기본 5를 형성됨으로 표시하지 않는다.

R은 가장 최근 도래한 정상 일일 마감이다. R의 실제 보고가 유효하고 현재 범위와 호환될 때만 현재 대표 단계로 쓴다. R 보고가 없거나 무효이면 오래된 보고를 현재로 대신하지 않는다. 오늘 새 결과·확인 필요는 R 단계와 구분한다. 오늘 자료만 부족하고 R 근거가 유효하면 병기하고, R의 기관/중복/승계 근거가 깨지면 현재 표시를 보류한다.

추세는 실제 R과 정확히 R−7일의 유효 보고가 같은 회사/분기·호환되는 측정/단계/범위일 때 공개 단계끼리 비교한다. 범위 확대·비슷한 범위·범위 축소로 표현하며 성공/실패·호감 변화로 번역하지 않는다. 같은 단계 안 변화의 방향·크기·속도를 알려주지 않는다. 비교점이 없으면 가까운 날짜·소급 계산으로 대체하지 않는다. 중간 이력에 공백이 있어도 양 끝이 유효하면 두 점 비교는 가능하지만 공백을 채우거나 연속 확대라고 설명하지 않는다.

사유는 실제 반영 활동·해당 기관 마지막 유효 활동의 기간 이탈·확인된 승계/정정에서 최대 2개다. 공통 정렬대로 새 활동은 원래 효력 시각, 기간 이탈은 해당 마감, 승계/정정은 반영 마감으로 최신 것을 우선하며 동률은 고정된 원래 기관/업무 순서를 쓴다. 같은 사실을 쪼개거나 점수 기여도로 정렬하지 않는다. 순변화 원인까지 입증하지 못하면 집계 반영 사실로만 설명한다.

기본 이력은 R부터 R−27일까지 실제 28개 마감일이며 보고가 없는 날은 공백이다. 더 오래된 마지막 유효 보고도 날짜와 당시 범위가 있는 과거 참고로 보존한다. 활동 기간 28일, 추세 7일, 보고 탐색 28개 마감일은 서로 다른 역할이다. 기관 개칭·정정·승계로 새 과거 보고를 만들지 않는다.

**확인과 검증의 상태**

승인 추적 20개, 개발 확인 18개, 디자인 확인 10개, 검증 기대 묶음 36개를 구분했다. 실제 데이터 공급·저장 복원·화면·성능·밸런스는 미확인이다. 자동 게임 테스트, Godot 로드, 플레이, 세이브 전환/복원, UI/접근성·비공개 검사, Windows 빌드와 독립 제품 검수는 NOT_RUN이다.
