## 2. 도시·연결·사업 데이터 — PAR-01
ID와 이름은 가칭. P01 도 아래 C01 시, G01~G04 구. G01=D01,D02; G02=D03,D04; G03=D05,D06; G04=D07,D08. 도시 관할 C01.

연결은 위 좌표에서 맨해튼 거리1인 쌍만 허용. 모든 연속 역이 간선으로 연결되고 고유 역 수6~8이면 유효 후보 경로다. 8개 동에 최소1곳씩 배분, D05~D08은2곳씩.
- 슬롯 P-A: C01의 북부·동부 서비스. 정상 예시 S01→S02→S03→S04→S08→S12(6역).
- 슬롯 P-B: C01의 서부·남부 서비스. 정상 예시 S01→S05→S09→S10→S11→S12(6역).
- 8역 예시: S01→S02→S06→S05→S09→S10→S11→S12.
- 슬롯은 제안 시작 때 선택하고 제출 후 변경으로 심사 제한을 우회하지 않는다. 역 집합만 같은 계획은 다른 슬롯에서도 신규 사업으로 인정하지 않는 세칙 제안. 같은 슬롯의 다른 순서·역 교체는 동일 사업. 이 규칙의 자유도/인지 가능성은 Dev/Design 확인 필요.
- 입찰 B01=C01 시청/P-A 6역 예시, B02=C01 소재 정부/P-B 6역 예시. 둘 다 사전 허가. 외부시 B-X는 실제 목록에 비노출.
- 사업성 비교를 위해 두 경로의 수요/기간/노선 순서 결과를 실제 계산한다. 테스트 전용 외부 시·광역시·특별시 위계와 오류 데이터는 별도 제공 대상으로 포함한다.

## 5. 미지급·예약·취소 세칙 — SEM-01/02 Owner 채택 (MVP 쉬움·시철)
1. **운영비 E**는 발생 시 한 번 비용 인식하고 미지급 운영비 B를 기록한다. 운영비의 실제 지급 가능액은 `max(0,F−K)`; 지급할 때 실제 지급분만 C/B에서 차감하며 비용 재인식 금지. R=사업별 정부 제한액, K=회사 자체 미집행 공사 예약, F=C−ΣR, A=max(0,F−K). **공사 기성 미지급과 수리비를 운영비 B에 합산하지 않는다.**
2. B>0이면 **신규 승객 탑승/출발만** 제한한다. 기존 이동 중 승객은 도착·완료한다. **CLOSE-01 Owner 확정:** 신규 승차를 허용한 서비스 구간에 발생하는 운행비 100/게임분에는 해당 구간에 탑승한 승객의 잔여 도착을 포함한다. 영업시간 종료·운행 제한 뒤 **기존 승객 도착만으로 추가 운행비 0**. 원래 서비스 구간 운영비는 면제되지 않는다. 실제 원장·보고의 분할 재현 검산은 Development 인수 대상이다.
3. 완료 통행의 운임은 도착 시 자유현금으로 유입되며 **그 시각 즉시 미지급금 B 우선 자동 정산**한다. 정부 제한자금 R 또는 예약 K를 미지급 정산에 사용하지 않는다. B=0 및 다음 계산 구간 운행비 확보·영업시간 등 정상 조건을 충족하면 신규 탑승 재개.
4. **미지급 B>0 또는 미지급 6개월을 근거로 신규 사업 계약을 제한하는 기능은 모두 MVP에서 제외한다.** 기존 계약 자격, 업무시간, 회사부담 예약 K·신규 가용액 A 충당 검사는 유지한다. 정산 뒤 남은 자유현금으로만 새 K를 예약한다. 같은 시각 T의 계약에 T 후순위 도착 운임을 소급 사용하지 않는다.
5. 미지급이나 공정 중단만으로 정부 사업비 R을 자유자금으로 전용하거나 회사 공사 예약 K를 해제하지 않는다. 정상 자기 회사부담 기성 O 지급 시 Kᵢ를 O만큼 감소시키고 타 사업의 R/K 전용 금지.
6. 플레이어 직접 계약 취소/금액 변경 UI는 MVP 제외. 내부 개발 검증의 **유효 취소 사건**에서만 아직 집행되지 않은 K 해제 가능하며 이미 지출한 공사비는 되돌리지 않고 남은 R은 제한 상태를 유지한다. 실제 제품 취소/위약금/정부 반납은 MVP 이후 별도 승인.
7. C<0 경계에서도 신규 대출·무근거 지급 없음. MVP 장기 파산 실행 SHOULD, 기존 Gate 1 규칙 보존. **6개월 연체 신규 계약 제재와 기간 초기화 시계는 NOT_IN_MVP**이며 후속 Library에서 정책 재검토.
8. **UI 의미 인계:** 비용 발생과 현금 지급, 예상과 실적, 현재 C/R/F/K/A/B와 마감 과거 일일보고, 정상운행/신규탑승제한/기존승객이동중/미지급정산/재개가능·공정중단/검증실패는 서로 다른 상태·원인/허용행동을 노출한다. W05는 사업계약·공사계약·착공, 수행 공정·발생 기성·실지급·공사 미지급·수리 지급, 시간 일시정지·자금 중단·시험 실패, 요청·효력·완료를 각각 구분한다. 실제 공급 필드·전송 계약은 Development, 시각 표현은 Design 소관이다.
