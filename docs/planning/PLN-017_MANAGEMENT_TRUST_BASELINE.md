## 현재 승인과 원문

경영진 신뢰도는 직원과, 실제 주주가 있는 회사에서 주주가 경영진의 설명·약속·판단·책임 이행을 신뢰하는 정도다. 휴식은 일부 직원 약속 경험이며 전체 항목을 대표하지 않는다.

[영향 요인 원문](PLN-017_MANAGEMENT_TRUST_SCOPE.md)의 MGT-F01~06과 [평가·집계 원문](PLN-017_MANAGEMENT_TRUST_EVALUATION_PROPOSAL.md)의 MGT-A01~10, [실제 평가 기준표 원문](PLN-017_MANAGEMENT_TRUST_CRITERIA_PROPOSAL.md)의 MGT-B01~10 및 관련 세칙이 채택됐다. 원문의 권고·대안·결정 대기 표현은 제안 당시 이력이다. 채택된 것은 권고안이며 대안은 채택되지 않았다. 이 기준선이 현재 승인 상태를 나타낸다. 이번에 [적용·승계 원문](PLN-017_MANAGEMENT_TRUST_MIGRATION_PROPOSAL.md)의 MGT-M01~08과 [정보 표시 원문](PLN-017_MANAGEMENT_TRUST_INFORMATION_PROPOSAL.md)의 MGT-I01~06 및 관련 세칙도 모두 채택됐다. 원문별 승인 대기·향후 결정 표현은 해당 제안 당시의 이력이며, 이 문서와 각 원문의 최신 채택 기록으로 현재 상태를 확인한다. 상세 계산·예외·기대 사례는 연결된 채택 원문을 함께 사용한다.

F03 목표 분모는 평가 전에 고정하고 같은 목표 분할·실패 목표 삭제·사후 기준 완화를 금지한다. 실제 목표와 기한·권리·시정 조건 등 첫 콘텐츠 기준표는 후속 B01~10 채택으로 아래에 확정했다. 콘텐츠별 실제 직무·인원·권한 등 입력의 공급 완료를 뜻하지 않는다.

10일에 확정된 결과는 10~37일 마감에 포함하고 38일에 이탈한다. 28일에 확정된 F03 결과가 55일까지 포함되고 다음 기간 결과는 56일에 이어지도록 한다. 현재 미해소 위반은 오래됐어도 유지한다. 정당한 종료로 아직 발생하지 않은 의무가 사라진 것은 성공/시정 사례가 아니다.

중대사건은 실제 시정조건을 완료한 다음 정상 마감에서 상한을 해제할 수 있다. 이미 낮은 값을 3으로 올리지 않으며, 상한은 대내적 평판 부모로 확대하지 않는다. 정상 기한 전의 새 사례는 미리 실패로 만들지 않고, 이미 충분한 같은 요인의 결과를 자동 무효화하지 않는다.

## 보존하는 기존 승인

- 기존 재정·서비스·세 리스크·대외적 평판·직원 만족도와 원장 C/R/F/K/A/B, 실제 사건 순서는 유지한다.
- 모든 정식 노드는 0~10 소수, 말단 기본 5와 미관측 구분, 부모는 직접 자식 보유값 산술평균을 유지한다.

- 정확한 점수·중간값·가중·기여도는 플레이어에게 비공개다. 실제 업무 사실·기한·결과는 필요한 행동 정보로 다룬다.
- 과거 휴식 단일안 8개는 미채택 이력이다. 현재 승인 숫자는 A01~10의 새 채택에 근거하며 과거 휴식안을 되살리지 않는다.
- 직원·주주 포함을 승인한 것과 전체 인사·주식시장·이사회·배당·감사·퇴사/의결 효과의 구현 승인은 다르다. [아이디어 004~009](idea-library/README.md)는 별도 콘텐츠 후보 상태를 유지한다.

## 실제 기준의 통합 해설

### 대상과 여섯 요인

직원 관점은 실제 직접 고용된 직원(고용된 관리자 포함), 주주 관점은 실제 지분 관계가 있는 주주를 대상으로 한다. 플레이어·외주 업체를 자동 포함하거나 실제 주주가 없는 회사에 가상의 주주를 만들지 않는다. 첫 표는 실제 개통 영업과 양수의 유효 정상 계획이 있는 **안정운영 회사**다. 회사 단계는 시나리오의 실제 상태로 판별한다. 첫 주주 표는 같은 권리의 보통지분이며 특수지분·간접 보유·자기주식·공공 소유의 대응은 후속 콘텐츠다.

|---|---|---|
| F01 약속·방침 | 확정 근무조건·배치·개선 약속 이행. 휴식은 그 일부 | 확정 사업·자금 운용 약속 이행 |
| F02 정보·투명성 | 실제 운영·인력·근무조건·약속·문제의 정확한 보고 | 실제 운임·발생 비용·손익·자금 제한·사업위험·자원 집행의 정확한 보고 |
| F03 성과·지속가능성 | 계획 영업과 필수 직무를 실제 충족했는가 | 실제 운영 손익과 다음 운영을 위한 가용자금을 확보했는가 |
| F04 위기·책임 | 실제 영향받은 직원에 대한 위기 해소와 필요한 보호 | 실제 영향받은 주주의 사업·자본 관련 위기 해소 |
| F05 공정·존중 | 사전 직무·자격·조건의 일관 적용, 설명·의견·이의 기회 | 같은 권리의 대상에게 설명·참여 기회 제공, 실제 지분·권리 존중 |
| F06 자원·방향 | 필수 인력·안전·운영 기반 보호와 실제 자원 배분 | 유효한 사업 목적·예산·권한에 맞는 집행과 미래 부담 관리 |

첫 표에 없는 급여·승진·배당·산업재해·주총 제도를 가정해 사례를 만들지 않는다. 불리한 사실을 정확히 보고한 것은 불성실 보고와 다르며, 불만·적자·배당 규모 자체가 불공정이나 중대사건을 뜻하지 않는다.

### 실제 판정·집계 순서

1. 당시 실제 의무·영향 대상·기한·목표·근거와 원래 사건 동일성을 확인한다. 같은 판단을 여러 요인/지급/보고로 복제하지 않는다.
2. 원래 사례 안에서 직원은 영향받은 사람별 동일 가중, 주주는 영향받은 당시 지분끼리 가중한다. 비대상자를 성공으로 추가하지 않는다. 같은 사람이 직원과 주주 역할로 각각 실제 영향받는 경우 두 관점의 독립 근거는 인정한다.
3. 동일 요인의 원래 사례끼리는 동일 가중한다. 사례를 합칠 때 인원·지분·금액 가중을 다시 곱하지 않는다.
4. 전수 근거와 관측 조건을 충족한 관점에서 유효 요인을 동일 가중한다. 최소 4개 실제 요인과 F02·F03 필수, 여섯 요인의 콘텐츠/관측 준비를 모두 확인한다.
5. 유효한 적용 관점에 중대 상한을 적용하고, 양쪽 적용 시 50:50으로 합친 뒤 최종 말단에도 해당 상한을 적용한다. 다른 회사 상태값으로 대체하거나 부모에 새 상한을 두지 않는다.

행동 5요인은 기한 내 유효 이행 10, 확인된 위반의 실제 시정 5, 확인된 미해소 위반 0이다. 기한 전·기준 미준비·자료 부족은 0이 아니다. 성과는 기간 시작에 고정한 목표 충족 수로 판정한다. 중간 반올림으로 경계 판정을 바꾸지 않는다. 이 단락의 점수·가중은 내부 기획/검증용이다.

사례의 대상 경계는 F01 의무 효력, F02 보고기간 종료(중요 사건은 실제 영향 시점), F03 기간 시작, F04 사건 시작, F05 원래 결정 대상, F06 자원 행위 효력이다. 퇴사·매도·기간 중 인원 변화로 과거 분모를 다시 쓰지 않는다.

### 첫 성과표의 실제 조건

### 기한·시정·중대사건

- 정기 보고는 완전한 7게임일 단위, 종료 후 1게임일 내 실제 대상에게 전달한다. 중요한 변화와 발견한 오류는 확인 후 1일 내 알림/정정한다. 자동 재무 화면이 있다는 사실만으로 보고 이행을 만들지 않는다.
- 운영자금 위기의 신뢰 의무는 원래 위험 시작부터 7일 내 실제 회복이다. 기존 미지급 해소·재무상 승차 조건·사례 중 최고 정상 하루 운영비의 3일분을 1일간 유지하는 확인 기간을 포함한다.
- 공사 중단/지급 차질은 원래 중단부터 1일 내 지급 정상화와 실제 재개, 이미 공정 100%라면 미지급 최종 기성까지 지급한다. 계약 완공 기한을 새로 만드는 것이 아니다.
- 개통 전 안전 결함은 확정부터 1일 내 실제 수리와 유효 재시험 통과다. 기존 안전/재무/사업위험 사례의 점수·시계는 보존한다. 안전 300분 복구의 기존 역량 5와 신뢰 이행 10은 함께 성립할 수 있다.
- 실제 이의에는 접수 후 7일 내 근거 있는 답변과 후속 조치를 제시한다. 답변만으로 박탈된 권리의 시정이 끝나지 않는다.
- 통상 미래 변경은 효력 1일 전 통지, 정당한 권한과 필요한 실제 동의를 요구한다. 확정 권리 축소에는 실제 영향 대상 동의가 필요하다. 긴급 보호는 기존 권한에 따라 먼저 시행하고 1일 내 설명한다.
- 시정은 남은 의무·권리·자원과 필요한 구제의 실제 복구다. 사과·예산의 소급 변경·퇴사·매도·이름 변경으로 책임을 지우지 않는다. 복구 불능이면 사전 대체 구제 조건이 필요하며, 아직 없다면 임의 시정 완료로 처리하지 않는다.
- 중대 상한의 대상은 확인된 고의 중요 허위/은폐, 실제 핵심 권리 박탈, 제한 자원 목적 외 사용/사익 제공이다. 단순 지연·일반 오류·추정 의도는 구분한다. 자료 부족이면 보류와 확인된 현재 사실을 함께 보존한다.

### 최초 시작과 원래 주기 보존

준비 시점 τ는 초기화/핵심 복구·검증과 기존 시각 처리 뒤, 실제 직원/주주 관계·여섯 요인의 콘텐츠·현재 기준표·목표/직무/권한 등 입력이 준비된 첫 게임 시점이다. 이미 평가 표본이 충분해야 τ가 되는 것은 아니다. 문서 승인 날짜·업데이트 날짜도 τ를 대신하지 않는다.

최초 적용 E는 **τ+24게임시간 이상인 첫 게임일 시작 경계**이며 기존 경계 처리를 마친 뒤 연다. 최소 1게임일 예고를 보장하고 정지 중 현실 시간은 포함하지 않는다. 첫 보고 종료 E+7일/전달 기한 E+8일, 첫 성과 종료 E+28일, 다음 성과 종료 E+56일이다. 목표·분모·E_ref·대상은 원래 기간 시작에 고정한다.

τ=10일 12:00이면 E=12일 00:00, 첫 보고 종료=19일/기한=20일, 첫 성과 종료=40일, 다음 성과 종료=68일이다. 최초 종합은 빠르면 E+28일이며 충분성 조건을 별도로 모두 충족해야 한다. 그때 네 번째 보고의 기한은 E+29일이므로 기한 전이라는 이유로 충분한 기존 F02 실적을 무효화하지 않는다.

E의 고정 목표를 장애로 확보하지 못했으면 원래 E/주기와 해당 기간 보류를 보존한다. 원래 고정 근거를 복구하거나 다음 원래 28일 시작에서 새 목표를 고정한다. 결과를 보고 과거 목표를 새로 쓰지 않는다.

### 처음 도입·호환·자료 부족의 구분

처음 도입 전 이미 끝난 사례를 새 신뢰 성적으로 소급하지 않는다. 당시 실제 존재했고 새 기준과 의미가 같은 진행 의무는 원래 대상·기한으로 연결한다. 현재 미해소인 확인된 옛 책임은 지우지 않는다. 당시 없던 보고/알림/공사 대응 기한을 소급하거나 E부터 새 기한으로 다시 세지 않는다. 의미가 다른 옛 진행 사건은 원래 책임을 보존한 채 승계 판정을 보류하며, 책임 해소와 정당한 제외 근거 또는 별도 명시적 전환 결정이 필요하다.

같은 제도를 사용하던 세이브는 실제 의미·원래 τ/E·대상/지분·고정 목표·주기·전수 기록·발행 이력이 호환되는지 확인해 이어받는다. 20일째의 성과기간은 원래 경계까지 8일이 남는다. 원천자료만 충분한 경우 다음 정상 마감의 현재 평가를 판단하되 과거 성적표를 만들거나 원래 사례 종료일을 오늘로 바꾸지 않는다. 점수만 있거나 원래 적용 이력이 불명하면 새 도입으로 초기화하지 않는다.

핵심 상태가 정상이고 평가 자료만 부족하면 플레이와 기록 수집을 계속하며 해당 평가를 보류한다. 실제 근거 복구·입증 가능한 종료 사례의 창 이탈·현재 책임 해소 등을 확인한 뒤 정상 마감에서 충분성을 다시 판단한다. 28일 경과는 자동 정상화나 미해소 책임 삭제 조건이 아니다.

### 관점·회사 단계 변화와 이력

같은 관점 안의 입퇴사·지분 변동은 원래 기간과 사례를 유지한다. 구조적으로 새 관점이 생기면 그 관점만 준비/최소 1일 예고를 거쳐 연결한다. 새 관점의 첫 보고/성과는 해당 적용 시작 이상인 기존 회사의 다음 7일/28일 시작 경계부터 완전한 한 기간을 사용한다. 그 사이 새 중요 사건의 의무는 미루지 않는다. 실제 새 관점이 적용 대상이 된 때부터 회사 현재 종합에는 두 관점 모두 유효해야 한다.

현재 인원이 0이라는 사실만으로 옛 경험·책임을 삭제하지 않는다. 구조적 미적용은 실제 관계·남은 책임·기억 범위까지 입증한다. 안정운영에서 지원하지 않는 단계로 바뀌면 해당 성과와 현재 종합을 보류하고 원래 기록·의무를 보존한다. 성장투자 등 새 기준표와 의미가 달라지는 전환은 별도 기획/Owner 결정 대상이다.

실제 발행된 과거 성적은 당시 날짜·기준·범위와 함께 남긴다. 사실 정정은 원래 기록과 정정 근거/확인 시점을 연결하며 과거 보고를 조용히 덮어쓰지 않는다. 28일 기억 창은 원천·발행 이력의 삭제 기한이 아니다.

세이브 원본은 보존하고 사본 변환/검증 뒤 사용한다. 원장·현재 권리/관계·진행 사건·시각의 핵심 복구 실패는 전환 실패로 구분한다. 반복 로드로 지급·사례·보고·마감·기간을 복제/초기화하지 않는다. 과거 저장 분기는 해당 분기의 실제 상태만 사용하며 미래 분기의 평가를 가져오지 않는다.

### 단계·관점·시각과 비공개 경계

최신 도래 마감 R의 실제 유효한 최종/직원/주주 평가에 공통 5단계(취약·미흡·보통·양호·우수), 날짜와 평가 범위를 붙인다. 단계 경계는 내부적으로 [0,2), [2,4), [4,6), [6,8), [8,10]이며 관점/최종 중대 상한을 반영한 값으로 판단한다. 기본 5·미관측을 보통으로 표시하지 않는다. 여섯 요인은 실제 사실/상태로 설명하고 별도 요인 점수표나 정식 하위 노드를 만들지 않는다.

오늘 새 문제가 생겼다면 R의 성적과 현재 문제를 함께 표시한다. 오늘 정보만 부족하면 유효한 R을 유지하되 부족 안내를 붙이고, R의 근거 자체가 무효이거나 현재 적용 범위와 호환되지 않으면 현재 성적으로 쓰지 않는다. 한 관점만 유효하면 해당 관점만 날짜와 함께 표시하고 최종은 보류한다. 서로 다른 날짜의 좋은 관점을 조합하지 않는다. 직원 관점의 경영진 신뢰도와 별도 직원 만족도를 명확하게 구분한다.

정확한 점수·산식·가중·정밀 기여도·상한 숫자·요인 수를 통한 점수 진행률·다음 단계까지 필요한 시간/금액 계산기는 공개하지 않는다. 같은 단계 안의 값 차이를 막대 길이·좌표·색 농도·툴팁·접근성 숫자·플레이어용 내보내기로 드러내지 않는다. 실제 계약·운영·자금 목표와 기한·지분·업무 결과 등 필요한 사실은 제공할 수 있으나 이를 평가용 공략표로 재구성하지 않는다.

### 추세·이유·과거값

추세는 R과 정확히 R−7게임일에 실제 발행된 호환 단계만 비교해 개선/비슷한 수준/악화로 표현한다. 같은 단계의 내부 증감은 숨긴다. 회사/저장 분기·규칙 의미·회사 표·적용 관점 및 각 관점의 실제 평가 요인 구성이 같아야 한다. 보통의 인원/지분 변화나 새 28일 주기, 같은 규칙의 중대 상한 발동만으로 비교 불가를 만들지는 않는다. 정확한 날짜가 없으면 가까운 날로 대체하지 않는다. 최종과 각 관점의 추세는 각각 유효성을 확인한다.

회사 요약 이유는 최대 2개, 각 관점의 펼친 설명도 그 관점 최대 2개다. 해당 R에 연결된 확인 근거를 쓰며 정밀 점수 기여 순위로 정렬하지 않는다. 고정 의미 순서는 R에 반영된 미해소 사항, 실제 시정/새 결과, 기억 창 변화이며 같은 종류에서는 실제 최근 시각을 사용한다. 순변화 원인으로 단정할 근거가 없으면 ‘이번 평가에 반영된 사실’로 전달한다. 현재 중대사건·미해소 의무·자료 부족/적용 상태는 이유 2개 제한과 별도로 필수 표시한다.

기본 과거 탐색 범위는 최근 28개 마감일 R~R−27의 실제 단계와 공백/범위 변경이다. 없는 날을 보간하거나 마지막 값을 복사하지 않는다. 더 오래된 마지막 유효 성적도 원래 날짜로 보존한다. 현재 집계의 28일 기억, 28일 성과기간, 28일 화면 탐색은 서로 다른 목적이며 데이터 삭제 기한이 아니다.

### 자료 상태와 다음 행동

기능/기준 미준비, 구조적 관점 미적용, 적용 대상 자체 불명, 예고, 첫 보고/성과 대기, 실제 사례 없음, 충분한 경험 부족, 과거/현재 근거 부족, 적용 이력 불명, 복구 후 다음 마감 대기, 오늘 정보만 불명, 관점/회사 단계 전환, 실제 낮은 평가, 핵심 세이브 전환 실패를 구분한다. 복수 상태가 있으면 함께 전달한다.

확인할 실제 기록·이행할 의무·실제 업무 기한/예정 종료일을 안내한다. ‘28일 뒤 자동 정상’, ‘시정하면 바로 우수’, ‘새로 불러오면 평가 재시작’처럼 승인되지 않은 회복을 약속하지 않는다. 색상만으로 상태를 전달하지 않으며 실제 화면·문구·접근성 구현은 후속 Design 확인과 검증 대상이다.
