## 1. 기존 승인과 이번 선택

관계·교류의 범위/활성화를 나타내는 규모형 의미, 세 자식의 계층과 보유값 평균, 지방의 첫 두 활동·중복 판정·기관 수 환산·최근 28게임일·전수 관측을 유지한다. 최소 1게임일 예고, 같은 의미의 과거 활동 승계, 온전한 28일 자료와 최초 마감, 원래 진행 업무·호환/불명 세이브·보고 정정·분기 보존도 이미 승인됐다.

현재 지방 값이 유효하더라도 중앙·안전/감독까지 유효하지 않으면 현재 상위 종합은 대기한다. 정확한 내부값·산식·가중·점수 경계·정밀 변화는 모든 플레이어 경로에서 비공개다. 이 원칙을 다시 선택하는 목록이 아니다.

이번에는 규모형 단계의 이름/공개 수준, 추세 비교 간격과 말뜻, 요약 사유 수, 이력 탐색 범위와 자료 상태의 설명을 새로 선택한다. 단계는 우호·신뢰·규제 지지·성공률·계약의 현재 유효성을 보증하지 않는다.

## 3. I01 중립 단계와 현재성

### 3.1 내부 판정과 플레이어 표현

아래 경계는 OWNER·제작팀의 표시 검증용이며 플레이어에게 제공하지 않는다. 내부 평가식은 바꾸지 않고 유효한 값에 단계만 대응한다. 경계 검산용 가상 소수값을 지방의 새 실제 값으로 추가하지 않으며 지방 환산은 기존 0/5/7.5/10을 유지한다.

| 내부 유효값 | 플레이어 단계 | 뜻 |
|---|---|---|
| 0 이상 4 미만 | 제한적 | 최근에 확인된 교류 범위가 제한적임 |
| 4 이상 7 미만 | 형성됨 | 최근 교류 범위가 형성되어 있음 |
| 7 이상 10 이하 | 폭넓음 | 최근 교류 범위가 폭넓게 확인됨 |

기관 연계의 공통 표현으로 제안한다. 지방은 현재 승인된 실제 값에 적용하고, 상위는 세 자식이 모두 현재 유효할 때 기존 보유값 평균에 적용한다. 표시 단계들을 평균해 상위 단계를 만들지 않는다. 중앙·안전/감독도 각자의 평가/승계 기준이 별도 확정되고 실제 현재 유효할 때 사용할 수 있으며 이번 표가 그 개별 기준이나 평가 개시를 대신하지 않는다.

지방의 내부 0/5/7.5/10은 각각 제한적/형성됨/폭넓음/폭넓음으로 표시된다. 한 시청만 있는 C01에서는 제한적 또는 형성됨이 가능하며 폭넓음을 얻기 위해 새 기관을 만들거나 외부 관할을 개방하지 않는다. 제한적을 위험·실패로, 폭넓음을 우수·우호·정부 지지로 설명하지 않는다.

‘형성됨’은 매일 교류하거나 현재 유효 계약이 있다는 보증이 아니다. ‘폭넓음’도 모든 기관과 접촉했다는 뜻이 아니다. 범위 설명과 실제 사실을 함께 제공한다. 실제 0임이 확인되면 ‘최근 집계 기간에 인정된 교류가 없습니다’라는 사실 설명을 덧붙일 수 있지만 내부 숫자 0을 공개하지 않는다.

같은 단계 안에서 값이 달라도 막대 길이·위치·색 농도·별점·점수용 진행률·아이콘 세부·접근성 숫자·내보내기로 구분하지 않는다. 특히 7.5와 10은 같은 단계다. 실제 기관/업무 사실이 다르면 그 사실은 다르게 설명할 수 있으나 점수 대응표나 다음 단계까지 필요한 기관 수를 제공하지 않는다.

### 3.2 마감 평가와 지금의 업무

R은 가장 최근 도래한 정상 일일 마감의 실제 시각이다. 평가 대상 업무일 이름과 마감 시각을 구분한다. R의 실제 유효한 평가가 현재 범위와도 맞을 때만 현재 대표 단계로 제시한다. R의 평가가 없거나 무효이면 오래된 값을 현재처럼 대신하지 않고 현재 평가 대기와 마지막 과거 평가를 구분한다.

대표 표현은 ‘지방행정기관 연계 수준 — 최근 교류 범위 기준’이며 해당 마감 시각을 붙인다. 최근 28게임일이라는 관측 기간은 설명할 수 있다. 오늘 확정된 판정은 실제 새 업무 결과로 알려도 다음 마감 전 대표 단계/추세가 이미 바뀌었다고 표현하지 않는다.

오늘 업무의 일부 자료만 부족하고 R의 근거가 유효하면 R 단계와 오늘 상태 확인 필요를 병기한다. R의 평가창·기관 동일성·중복·승계 근거가 훼손되면 현재 단계의 유효성을 보류한다. 유효 보고의 호환 복원은 M05대로 인정하고 로드 시각을 새 마감으로 만들지 않는다.

지방만 유효하면 지방 단계는 제시하되 상위는 ‘종합 확인 대기’로 구분하고 어느 분야가 미확인인지 알린다. 부모 보유값에 포함된 기본 5를 관측된 교류처럼 설명하지 않는다. 자식의 평가 주기를 이 표시안만으로 바꾸지 않으며 중앙/감독의 현재성 세칙은 별도 기획을 따른다.

## 4. I02 중립적인 7일 추세

최신 정상 마감 R과 정확히 7게임일 전 정상 마감 R−7일에 실제 발행된 유효 단계를 비교한다. 단계가 높아지면 ‘범위 확대’, 같으면 ‘비슷한 범위’, 낮아지면 ‘범위 축소’로 표현하고 비교 날짜를 붙인다.

확대는 성공·개선·호감 상승을, 축소는 실패·악화·불신을 뜻하지 않는다. ‘비슷한 범위’는 같은 공개 단계라는 뜻이며 내부값·기관 구성·모든 업무가 같다는 뜻이 아니다. 같은 단계 안 변화의 방향·크기·속도를 별도 화살표나 퍼센트로 알려주지 않는다.

비교 조건은 다음과 같다.

1. 두 날짜에 실제 발행된 보고가 있고 각 보고의 근거와 현재성/당시 유효성이 확인된다.
2. 같은 회사·저장 분기이며 평가 의미·환산·기간·완전성·표시 단계의 기준이 호환된다.
3. 실제 집계 대상의 종류/관할 범위와 상위의 구성 자식 의미가 호환된다. 새 기관 유형·관할 콘텐츠의 범위 개정은 같은 조건으로 자동 연결하지 않는다.
4. 정정·승계·누락이 두 비교점의 신뢰성을 깨지 않는다. 현재 R이 무효하면 오래된 두 점으로 현재 추세를 만들지 않는다.

같은 정의 안에서 교류하는 기관이 실제로 추가·교체되거나 기간 밖으로 나가는 것은 정상적인 변화다. 기관 목록이 달라졌다는 이유만으로 추세를 막지 않는다. 제도나 집계 대상 범위 자체가 바뀐 경우와 구분한다.

정확히 7일 전 보고가 없으면 6일/8일 전으로 대체하거나 원천자료로 가상 보고를 만들지 않는다. M02의 과거 활동을 승계해 첫 평가를 냈더라도 과거 평가 보고가 없었다면 추세는 아직 비교 보류다.

중간 날짜에 보고 공백이 있어도 양 끝 보고의 전수 근거와 호환성이 확인되면 두 점 비교는 가능하다. 공백을 채우거나 7일 내내 연속 확대됐다고 설명하지 않는다. 공백이 실제 원천자료 누락이라면 두 점의 유효성부터 다시 확인한다.

OWNER용 예: 내부 5→7.5는 형성됨→폭넓음으로 범위 확대, 7.5→10은 폭넓음→폭넓음으로 비슷한 범위다. 기관 수는 그대로이고 상대만 바뀌어도 같은 단계면 비슷한 범위다. 오래된 활동의 기간 이탈로 축소된 경우에는 I03에서 그 사실을 설명하고 기관이 회사를 싫어하게 됐다고 단정하지 않는다.

| 실제 인정 교류 | ‘시청의 사업 제안 심사 처리 이력이 이번 집계에 반영되었습니다.’ | 승인/거부 모두 실제 접점이며 우호도 해석 없음 |

| 과거 활동 승계 | ‘확인된 이전 교류 기록을 원래 날짜 기준으로 이어받았습니다.’ | 오늘 새 교류한 것으로 표시하지 않음 |
| 사실 정정/자료 복구 | ‘확인된 기록 정정이 이번 집계에 반영되었습니다.’ | 정정일 새 접점 또는 실제 관계 변화가 아님 |

사유 후보는 실제로 그 마감에 사용된 활동 또는 기관의 마지막 유효 활동 이탈·확인된 정정/승계에서 고른다. 실제 새 활동은 원래 효력 시각, 기간 이탈은 해당 이탈 마감, 정정/승계는 현재 보고에 반영된 마감으로 정렬하되 종류를 명시한다. 시각이 최신인 순서, 동률은 고정된 원래 기관/업무 순서로 선택한다. 같은 기관의 같은 사실을 둘로 쪼개 강조하지 않는다. 이 정렬 시각은 원래 활동 시각을 변경하지 않는다.

전체 단계 변화의 원인임이 입증되지 않으면 ‘이번 집계에 반영된 사실’이라고 표현한다. ‘이 심사 덕분에 단계가 올랐다’고 추정하지 않는다. 반영된 사실을 찾을 수 없으면 꾸며내지 않고 설명 자료 확인 필요로 안내한다.

같은 기관의 다른 유효 활동이 아직 기간 안에 있으면 한 옛 활동의 만료만으로 그 기관이 집계에서 빠졌다고 말하지 않는다. 같은 근거의 반복 제출은 새 활동 사유로 사용하지 않는다. 실제 업무 화면에는 그 처리가 있었다는 사실을 남길 수 있지만 새 교류 인정과 구분한다.

### 요약 한도와 별개로 전달할 상태

진행 중인 제안/입찰과 실제 결과, 현재 남은 지급·보고·시정 의무와 원래 기한, 관측/승계 확인 필요, 현재 보고를 바꾸는 정정은 사유 2개에 들지 않았다는 이유로 숨기지 않는다. 해당 업무를 확인할 수 있게 하되 기관 연계 화면이 새로운 제재 점수나 다른 분야의 평가를 만들지는 않는다.

실제 심사 거부·입찰 탈락은 업무 결과로 명확히 알려주되 ‘기관 신뢰 하락’으로 번역하지 않는다. 안내는 실제 원래 업무·기한·필요 자료를 가리킨다. 점수 상승을 위해 같은 서류를 다시 내거나 불필요한 새 사업을 만들도록 권하지 않고, 새 기관 접촉만으로 승인/보조금 혜택을 보장하지 않는다.

## 6. I04 과거 단계·공백·정정

기본 이력 탐색은 R부터 R−27일까지 최근 28개 정상 마감일이다. 각 날짜의 실제 보고에 해당하는 단계·범위·자료 상태를 보여준다. 활동의 28일 창, 7일 추세 간격, 화면의 28개 마감일 이력은 역할이 다르다.

- 실제 평가가 있는 날만 단계를 표시하고, 같은 단계가 이어진 날과 보고가 없는 날을 구분한다.
- 이전 값을 다음 날로 복사하거나 빈 날짜를 보간하지 않는다. 단계 안의 소수점 위치·연속 점수 그래프는 제공하지 않는다.
- 최초 미도입·첫 평가 대기·보고 없음·보고 유실 여부 불명을 근거에 따라 구분한다.
- 과거 활동을 현재 계산에 승계했어도 과거 날짜의 평가 단계를 새로 만들지 않는다.
- 범위/기준이 바뀐 구간과 정정 사실을 표시하고 비교 불가 구간을 같은 조건의 추세로 연결하지 않는다.
- 마지막 유효 평가가 28일 밖이어도 원래 날짜·당시 범위를 가진 과거 참고로 보존한다. 기본 보기 밖이라는 이유로 보고나 중복 판정 이력을 삭제하지 않는다.
- 현재 R이 유효하지 않으면 오래된 좋은 단계를 현재 대표값처럼 제시하지 않는다.

실제 원래 보고와 연결된 검증된 사실 정정 결과는 정정된 과거 단계로 설명할 수 있으며 원본과 정정 사실도 확인할 수 있어야 한다. 정정된 날짜에 새 보고가 발행됐거나 정정일에 새 교류가 생겼다는 뜻은 아니다. 실제 원래 보고가 없으면 정정 자료만으로 그날의 보고를 신설하지 않는다.

정정이 현재 R의 근거를 깨면 M07대로 현재 유효 표시를 보류하고 다음 정상 마감의 현재 평가를 기다린다. 과거 비교점의 검증된 정정 결과는 사용할 수 있지만 실제 원래 보고의 존재와 양 끝의 비교 조건이 충족되어야 한다. 평가 의미의 실질 개정은 사실 정정으로 처리하지 않는다.

복수 상태가 동시에 존재할 수 있다. ‘첫 관측 기간 수집 중’과 ‘과거 중복 이력 확인 필요’를 함께 알리고 시간이 지나면 두 문제가 모두 자동 해소된다고 말하지 않는다. 28일 확보 여부만으로 성공/정상화를 보장하지 않는다.

확정된 최초 도입에서 연속 관측이 유지된다면 가장 이른 정상 마감 일시를 안내할 수 있다. 반드시 ‘필요한 기록이 모두 확인되면’이라는 조건을 구분한다. 데이터 완전성 자체가 불명하면 확정 완료일을 약속하지 않는다. 다음 단계까지 남은 점수·기관 수·예상 점수 진행률은 제공하지 않는다.

심사 결과 대기와 자료 누락은 다르다. 진행 업무가 사실로 확인되고 전체 기록이 충분하면 진행 중인 건이 있어도 유효한 단계가 나올 수 있다. 반대로 결과가 났는지 기록이 없어 알 수 없는 경우를 ‘아직 활동 없음’으로 처리하지 않는다.

오늘 상태만 불명인지 최신 마감의 근거가 훼손됐는지 구분한다. 후자면 현재 평가 대기와 날짜가 있는 마지막 과거 평가를 제공한다. 실제 낮은 유효 단계는 낮은 단계대로 설명하고 자료 부족이라는 표현으로 가리지 않는다. 미관측 기본값 5는 형성됨으로 표시하지 않는다.

### 7.2 모든 플레이어 접근 경로

공개 가능한 정보는 단계 이름, 마감/비교 날짜, 실제 관측 범위·기간, 실제 기관명·업무·결과·기한, 보고 공백·정정·자료 상태다. 기존 업무에서 알 수 있는 실제 사실을 숨길 필요는 없다.

정확한 평가값·소수 변화·수치 경계·기관 수 환산표·가중·정밀 기여도·점수 순위, 다음 단계까지 필요한 기관 수/활동 수, 예상 단계 계산기는 제공하지 않는다. 공개 기관 목록이나 업무 결과를 점수 대응표와 결합하는 별도 안내를 만들지 않는다.

단계 안의 차이는 막대·색 농도·아이콘·애니메이션·툴팁·접근성 설명·평가 내보내기·플레이어용 진단/로그에서도 노출하지 않는다. 실제 업무 사실과 자료 상태의 차이는 별도로 설명할 수 있다. 플레이어에게 기본 제공하지 않는 내부 제작용 검증 자료와 플레이어 경로를 구분한다.

색상만으로 단계를 구별하지 않고 텍스트로 같은 의미를 제공한다. 범위 확대를 무조건 녹색 성공, 축소를 적색 실패로만 전달하지 않는다. 자료 부족 안내에 클래스·필드·DB 오류 같은 구현 용어를 넣지 않는다. 구체적인 화면·접근성 구현은 후속 디자인/개발 확인 대상이다.

## 8. OWNER용 전달 예시

아래는 의미 예시이며 화면 배치나 최종 문안 검수를 대신하지 않는다.

> 지방행정기관 연계 수준: 형성됨 — 최근 교류 범위 기준, 40업무일 마감.

> 지방행정기관 연계 수준: 제한적 — 최근 교류 범위 기준, 40업무일 마감.

> 이번 집계에 반영된 사실: 시청과의 마지막 교류가 최근 집계 기간 밖으로 나갔습니다.
> 기존 계약의 보고 의무는 원래 기한대로 남아 있습니다.

기간 이탈은 기관과의 갈등이나 실제 의무 면제를 뜻하지 않는다.

> 현재 평가 대기 — 첫 관측 기간을 수집 중이며, 일부 과거 업무의 중복 이력을 확인해야 합니다.
> 마지막 유효 평가: 없음.
> 추세 비교 보류 — 비교할 실제 평가 기록이 아직 없습니다.

적용 이력이 불명한 세이브에는 ‘첫 관측’이라고 단정하지 않고 ‘적용/승계 확인 필요’로 설명한다.

> 지방행정기관 현황은 확인되었습니다.
> 유관기관 연계 종합 확인 대기 — 중앙행정기관·안전/감독기관의 현재 현황이 아직 확인되지 않았습니다.
