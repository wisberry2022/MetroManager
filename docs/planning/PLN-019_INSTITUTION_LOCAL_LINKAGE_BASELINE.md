### 5.1 단계와 현재 마감

OWNER·제작팀용 내부 단계 경계는 0 이상 4 미만 제한적, 4 이상 7 미만 형성됨, 7 이상 10 이하 폭넓음이다. 이 수치 경계는 플레이어 비공개다. 지방의 실제 0/5/7.5/10은 제한적/형성됨/폭넓음/폭넓음으로 대응한다. 평가식이나 실제 가능한 값을 바꾸지 않고 같은 단계 안 차이를 막대·색 농도·별점·아이콘·접근성 숫자 등으로 구별하지 않는다.

기관 연계 공통 표현이며 각 노드는 자신의 평가/승계 기준이 별도 확정되고 실제 현재 유효할 때 사용한다. 상위는 세 자식 모두 현재 유효할 때 보유값 평균에 단계를 적용한다. 표시 단계 평균이나 현재 유효 자식만의 새 평균을 만들지 않는다. 중앙/감독의 개별 평가를 이번 표시 정책으로 개시하지 않는다.

R은 가장 최근 도래한 정상 일일 마감의 실제 시각이다. R의 보고가 실제 유효하고 현재 범위에도 맞을 때만 현재 대표 단계로 쓴다. 오늘 새 판정·진행 업무는 R 단계와 구분한다. 오늘의 자료만 부족하고 R 근거가 유효하면 병기하고, R의 평가창/승계/중복 근거가 훼손되면 현재 단계는 보류한다. 오래된 보고는 날짜가 있는 과거로 남긴다.

C01의 실제 시청 하나에서는 제한적/형성됨이 가능하다. 폭넓음에 도달하지 못한다고 실패로 설명하거나 새 관할을 열지 않는다. 실제 활동 0이 완전히 확인되면 제한적과 ‘최근 집계 기간에 인정된 교류 없음’을 함께 설명한다. 미관측 기본 5는 형성됨이 아니다. 단계는 우호·신뢰·정부 지지·심사 성공·현재 계약의 보증이 아니다.

### 5.2 추세와 사유

R과 정확히 R−7게임일의 실제 보고가 유효하고 같은 회사/분기·평가/단계 기준·집계 범위 의미가 호환될 때만 두 공개 단계를 비교한다. 같은 정의 안의 교류 기관 추가/교체/기간 이탈은 정상 변화이며 범위 개정과 구분한다. 비교점이 없으면 가까운 날짜나 소급 계산으로 대체하지 않는다. 과거 활동을 승계한 첫 보고가 있어도 과거 평가 보고를 새로 만들지 않는다.

같은 단계면 비슷한 범위다. 예를 들어 내부 7.5→10은 폭넓음→폭넓음이므로 상승 방향·강도·정밀 변화가 추가로 드러나지 않는다. 양 끝의 전수 근거가 유효하면 중간 보고 공백이 있어도 두 점 비교는 가능하지만 공백을 채우거나 연속 확대라고 설명하지 않는다.

사유는 실제 사용된 활동·기관의 마지막 유효 활동 이탈·확인된 승계/정정에서 최대 2개를 고른다. 새 활동은 원래 효력 시각, 기간 이탈은 해당 마감, 승계/정정은 반영 마감 순으로 최신 것을 우선하고 동률은 고정된 원래 기관/업무 순서를 쓴다. 종류를 명시하며 이 정렬이 실제 활동 시각을 바꾸지 않는다. 같은 기관의 같은 사실을 쪼개 중복 강조하거나 점수 기여도 순으로 정렬하지 않는다.

순변화의 원인까지 입증되지 않으면 ‘집계에 반영된 사실’로만 설명한다. 반영 근거가 없으면 꾸미지 않는다. 같은 기관의 새 활동이 남아 있으면 한 옛 활동 만료만으로 기관 전체가 빠졌다고 말하지 않는다. 원래 진행 업무·현재 의무/기한·자료 확인·현재 보고를 바꾸는 정정은 요약 2개 밖에서도 확인할 수 있게 한다. 심사 거부/입찰 탈락을 기관 불신으로 번역하거나 반복 제출·불필요한 사업·점수용 기관 접촉을 유도하지 않는다.

### 5.3 과거 단계와 자료 상태

기본 탐색은 R부터 R−27일까지 최근 28개 마감일이다. 보고가 실제 있는 날만 단계를 제공하고 없던 날을 복사/보간하지 않는다. 관측 창 28일·추세 7일·이력 보기 28개 마감일은 역할이 다르다. 기본 보기 밖의 보고·창 밖 중복 근거를 삭제하지 않는다. 검증된 정정은 실제 원래 보고에 연결하되 새 보고나 새 접점으로 만들지 않는다.

준비 전, 최초 예고, 첫 관측 기간 수집, 기록/기관/중복 확인 필요, 적용/승계 확인, 정정, 다음 마감 대기, 지방만 유효, 핵심 전환 실패를 구분하고 복수 사유를 함께 안내한다. 진행 업무의 결과 대기는 기록 누락과 다르며 그것만으로 전체 현재 평가를 보류하지 않는다. 완전한 자료에서 실제 활동 없음은 자료 부족이 아니다.

연속 관측과 필요한 근거가 확인된다는 조건으로 가장 이른 재판단 마감을 안내할 수 있다. 28일 경과만으로 평가 재개나 특정 단계를 보장하지 않는다. 적용 이력 불명인 세이브를 새 최초 관측이라고 단정하지 않는다. 실제 기관·업무·기한·범위·마감/비교 날짜·자료 상태는 설명하되 정확한 내부값·산식·경계·기여도·단계 안 변화·다음 단계까지 필요한 기관 수는 모든 플레이어 경로에서 비공개다. 색상만으로 의미를 전달하거나 범위 확대/축소를 성공/실패로만 표현하지 않는다.

## 9. 검증 항목과 실행 상태

기대 사례는 [측정 원문](PLN-019_INSTITUTION_LOCAL_LINKAGE_PROPOSAL.md)의 ILK-V01~40, [승계 원문](PLN-019_INSTITUTION_LOCAL_LINKAGE_MIGRATION_PROPOSAL.md)의 ILK-MV01~40, [표시 원문](PLN-019_INSTITUTION_LOCAL_LINKAGE_INFORMATION_PROPOSAL.md)의 ILK-IV01~40, 총 120개다. 각 원문의 당시 ‘권고 채택 시’는 현재 모두 채택된 정책의 기대 결과로 읽는다. 실제 게임 시험은 NOT_RUN이다.

|---|---|---|

| 정보 전달 | 중립 단계/경계, 정확한 7일 비교, 같은 단계 안 비공개, 사유/업무, 28개 이력·공백·정정, 복수 자료 상태/접근성 | ILK-IV01~40 / 40개 |

| 검증 종류 | 현재 상태 |
|---|---|
| 문서 보존·승인 추적·링크/표·표현/계산 예시·저장소 정책 | 이번 통합의 실제 명령/결과는 [결과 기록](tasks/PLN-019_RESULT.md)에 기록 |

문서 계산 예시 통과가 실제 시스템의 120개 시험 통과를 뜻하지 않는다. 기존 시청/정부 판정·입찰·재제출·자금/의무와 다른 회사 상태값이 바뀌지 않는지도 해당 통합 실행 검증에서 확인할 사항이며 새 정책을 추가하지 않는다.
