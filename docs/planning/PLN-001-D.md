## 2. 핵심 결론 (5문장)

1. MetroManager는 가상 도시철도 회사의 경영자가 교통수요를 분석하고 공공입찰 또는 회사 제안으로 사업을 확보하여 시공·개통·시민 반응·재투자를 반복하는 샌드박스 게임이다.
2. 단순하지만 까다로운 행정 프로세스를 정체성으로 보존하며 대중형 경험을 우선한다.
3. 난이도 모드(쉬움/중간/어려움/극한)와 인피니트는 배타적인 시작 모드이며 쉬움 시철은 소속 시 소재 사업의 두 취득 경로에 접근한다.
4. QD-01~10과 P1~P6으로 소유권·운임·심사·파산 등의 콘셉트 규칙을 구체화했고 Owner는 2026-10-31 Gate 1을 공식 승인했다.
5. MVP 범위·개별 상세 규칙·개발 일정·기술 구현 방식은 이번 승인에 포함되지 않으며 HQ 접수·검수는 별도 확인이 필요하다.
