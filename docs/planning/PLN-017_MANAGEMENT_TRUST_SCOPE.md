경영진 신뢰도는 **직원과, 주주가 존재하는 회사에서는 주주가 경영진의 설명·약속·판단·책임 이행을 신뢰하는 정도**로 다룬다. 휴식은 직원에게 한 약속의 한 사례다. 전체 경영진 신뢰도를 휴식 약속 이행으로 대체하지 않는다.

### 약속과 방침의 이행

휴식 이외에도 확정된 보상 지급, 근무조건 변경, 문제 개선, 사업 추진, 자금 운용 방침이 후보가 된다. 모든 계획·전망·희망을 확정 약속으로 바꾸지 않는다. 확정된 의무, 조건부 계획, 불확실한 예측을 구분해야 한다.

경영진이 임의로 약속을 바꾸거나 반복 발표해 책임을 없애는지와, 실제 사정 변화에 따라 설명·협의·정해진 절차를 거쳐 바꾸는지는 분리해 설계한다. 이전 안의 모든 취소·기한 전 퇴사 일괄 0은 채택하지 않는다. 휴식은 이 요인의 한 경험으로 남으며 별도 전체 평가의 대리값으로 쓰지 않는다.

### 정보의 정확성과 투명성

사실과 다른 설명, 중요한 문제의 미고지, 설명과 실제 집행의 불일치가 확인되면 부정적 경험 후보가 된다. 정확한 설명·필요한 변경 고지·오류 정정은 긍정적 경험 후보다. 불리한 소식 자체와 그 소식을 숨기는 행동을 구분한다.

게임이 자동으로 정확한 재무 화면을 제공한다고 해서 경영진이 성실하게 보고했다는 실적을 만들지 않는다. 플레이어의 실제 선택 또는 정해진 보고 의무와 이행 기록이 필요하다. 원인·의도·고의가 입증되지 않았는데 경영진이 거짓말했다고 단정하지 않는다.

### 경영 성과와 지속가능성

실제 운영자금 여력, 지속적인 수익·손실, 사업의 완수, 운영의 지속성은 경영 능력을 판단할 입력 후보다. 기존 재정 점수나 서비스 점수를 신뢰도로 그대로 대입하지 않고 원천 사실·기간·약속 또는 계획과의 관계를 따로 해석한다.

한 번의 적자나 주가 하락을 곧바로 불신으로 바꾸지 않는다. 투자 단계·확정된 계획·확인 가능한 외부 변화와 경영 선택의 관계를 검토한다. 비교할 계획이나 원인이 없으면 그 부분은 알 수 없다고 남긴다. 사후에 목표를 낮춰 실패를 성공으로 만드는 방식도 방지해야 한다.

큰 수익이 정보 은폐나 불공정한 처우를 자동 상쇄한다는 규칙은 두지 않는다. 반대로 정보가 정확하다는 이유로 장기 손실을 좋은 경영 성과로 만들지 않는다. 여러 요인의 상쇄·하한·기억 방식은 아직 결정하지 않는다.

### 위기 대응과 책임 이행

재무위기·공사 이행 문제·안전 결함 등에 대한 실제 대응과 회복, 재발 여부를 관측 후보로 삼는다. 위기가 있었다는 사실과 대응을 잘못했다는 사실을 구분한다. 위기가 없다는 이유만으로 대응 신뢰를 만점으로 만들지 않는다.

기존 리스크 평가의 기한·집계·면제·최저 사례 규칙을 변경하지 않는다. 신뢰 평가에서 어떤 원천 사실이 직원 또는 주주의 경험이 되는지를 따로 정한다. 사건을 여러 보고로 나누어 반복 가점·감점하지 않는다. 사과만 하고 조치가 없는 상태와 실제 조치를 이행한 상태를 구별한다.

연결 아이디어: [경영계획과 보고](idea-library/PLN-IDEA-005.md), [내부통제와 감사](idea-library/PLN-IDEA-008.md).

### 공정성과 이해관계자 존중

직원의 보상·승진·고용·의견 처리와 주주의 정보 접근·권리 행사·이익 배분에서 어떤 기준과 절차를 적용했는지를 다룬다. 단순히 모두에게 같은 결과를 줬는지, 아무도 항의하지 않았는지를 공정성으로 대체하지 않는다. 역할·기여·사전 기준에 따른 정당한 차등과 자의적인 차별은 구분해야 한다.

소수 주주의 이해와 주요 주주의 이해가 다르거나, 직원의 안정과 주주의 단기 이익이 충돌할 수 있다. 한쪽의 만족을 다른 쪽의 신뢰로 복사하지 않는다. 아직 존재하지 않는 주주 권리나 인사 절차를 법적 의무처럼 확정하는 문서가 아니며 게임의 제도로 별도 설계한다.

### 책임 있는 자원 운용과 장기 방향

인력·안전·운영 기반과 자금을 실제로 어디에 쓰고, 그 선택이 사전에 설명한 방향과 일치하는지를 다룬다. 모든 배당을 좋게 보거나 모든 재투자를 좋게 보는 고정 규칙은 두지 않는다. 회사 상황·유효한 제약·계획·대상자의 역할을 함께 정해야 한다.

정부 제한자금 R이나 사업 예약금 K를 주주에게 자유롭게 배분할 수 있는 자금으로 해석하지 않는다. 기존 원장과 용도 제한을 그대로 유지한다. 또한 현재 시스템이 금지한 집행을 실제 선택 가능한 기능이라고 가정하지 않는다. 선택·통제 경험이 없다는 이유로 청렴 실적을 생성하지 않는다.

확인된 이해상충·특혜·자금 목적 외 사용의 대응·감사 등은 별도 내부통제 콘텐츠 후보다. 실제 위반이나 고의가 없는 사람에게 비윤리 의도를 부여하지 않는다.

연결 아이디어: [자본배분](idea-library/PLN-IDEA-007.md), [내부통제와 감사](idea-library/PLN-IDEA-008.md).

## 직원 관점과 주주 관점을 다루는 방법

**권고:** 원천 경험은 직원 관점과 주주 관점을 구분해 기록한다. 현재 7개 상위·기존 계층에 주주 신뢰도라는 새 정식 노드를 자동 추가하지 않는다. 두 관점을 한 내부값으로 합치는 방식은 후속 기획에서 비교·승인한다.

- 직원은 근무 지속성·설명·공정한 대우를, 주주는 경영 성과·정보·권리·자본 운용을 서로 다르게 경험할 수 있다. 동일한 이익 증가를 모든 대상의 신뢰 상승으로 만들지 않는다.
- 게임에서 주주가 있는 회사라면 주주 관점을 적용 대상에 포함한다. 다만 주주가 실제 존재하는 회사 형태·구성과 게임 데이터가 아직 정해지지 않았다면 가상의 반응을 만들어 채우지 않는다.
- 실제 적용 대상이 없는 경우와, 적용 대상은 있으나 관측 자료가 없는 경우를 구분한다. 주주 자료가 부족한 상태를 기본 5 또는 직원 경험으로 덮어 종합 완료처럼 표시하지 않는 방향을 권고한다. 현재 평가의 충분성·보류 조건은 다음 상세안에서 결정한다.
- 운영주체 명칭만으로 주주 존재 여부를 추측하지 않는다. 공공 운영주체의 출자자·감독기관을 주주와 같은 대상으로 취급할지는 별도 회사 형태 설계가 필요하다.
- 직원이 동시에 주주라면 역할별 경험을 구분하되 동일 사실의 단순 중복 가점을 막는다. 인원수·지분율·관점별 동일 가중 가운데 무엇을 쓸지는 미결이다.
- 주주가 존재하는 회사의 설계와 주식시장·상장·주가 시뮬레이션은 별개다. 주주 신뢰도를 다루기 위해 주식시장을 먼저 필수 구현할 필요는 없다. 주가를 신뢰의 대리 점수로 쓰지 않는다.

정확한 내부값·가중·기여도를 플레이어에게 공개하지 않는 기존 원칙은 계속 적용한다. 최종 화면·추세·과거 이력의 세부는 별도 정보 전달 기획이다.

## 현재 상세화와 아이디어 저장소의 경계

| 구분 | 이번 처리 | 의미 |
|---|---|---|
| 대상 정의 정정 | Owner 지시로 기록 | 직원과 주주를 포함. 재승인 질문 없음 |
| 영향 요인 선정 | 위 6개 모두 Owner 채택 | 휴식 단일안 대체. 수치·가중·구체 기능의 승인 아님 |
| 기존 규칙·원천 연결 | 재정·사업·운행·세 리스크와 중복/경계 검토 | 승인된 의미에 연결할 수 있다는 뜻이며 데이터 공급 완료가 아님 |
| 추가 콘텐츠 | PLN-IDEA-004~009에 BACKLOG 등록 | 구체 기능·산식·범위·도입 시점 승인 전. 주주를 정의에서 미루는 조치가 아님 |
| 실제 구현·검토 | 미착수·미요청 | 코드·UI·세이브·개발/디자인 확인을 대신 완료하지 않음 |

[기존 C v0.7](PLN-001-C.md)은 MVP/쉬움/시철 고정 범위를 명시한다. 회사 상태값은 POST-MVP 기획이다. 따라서 “현재 게임에 구현돼 있지 않다”는 이유만으로 모든 POST-MVP 기획을 아이디어로 제외하지 않는다. **이 상태값의 의미·입력·평가 경계는 현재 기획**, 그 입력을 만드는 독립적인 인사·보고·지배구조·자본 제도의 기능 전체는 별도 콘텐츠 아이디어로 나눈다.

기존 직원 만족도를 위해 이미 필요한 실제 직원·근무·휴식 콘텐츠의 최소 공급 과제를 선택적 아이디어로 낮추지 않는다. PLN-IDEA-004는 그 위에 더할 급여·인사·고용 약속과 공정절차 확장이다.

## 다음 상세 기획 권고 순서

1. 기존 원천과 연결 가능한 경영 성과·지속가능성, 위기 대응부터 직원/주주 관점별 유효 근거와 책임 경계를 정한다.
2. 약속 이행·정보 투명성의 의미와 필요한 최소 계획/보고 경험을 정한다. 발표 횟수·자동 화면 제공으로 가점을 만들지 않는다.
3. 공정성·자원 운용의 현재 평가 가능한 범위와 별도 콘텐츠가 필요한 범위를 확정한다.
4. 실제 적용 요인·관점별 집계, 중복 방지, 자료 부족, 내부 기준점·기간·회복을 권고안/대안으로 제시한다.
5. 적용 시작·기존 세이브·과거 실적 승계와 플레이어 정보 전달을 이어서 설계한다.

**아직 결정하지 않은 사항:** 여섯 요인의 실제 첫 적용 범위, 관점·요인별 집계와 가중, 결과와 의도·외부 원인의 구별, 표본과 기간·회복/상쇄, 회사 형태별 적용, 자료 부족·종합 유효성, 신규 콘텐츠의 도입 우선순위. 여섯 요인의 채택은 완료했으며 이전 휴식안의 숫자로 임시 채우지 않는다. 평가·집계의 신규 결정안은 후속 제안서에서 구분한다.

## 정의 정정 결정과 반영 기록

- RFC: RFC-PLN-017-01 / 상태 ANSWERED_SCOPE_ONLY / 요청 부서 Planning / 결정권자 Owner / 연관 작업 PLN-017.
- 현황: 회사 설계서 v0.16 §74.1은 직원 관점으로 설명했고, 미승인 후속 제안은 휴식 약속 이행으로 더 좁혔다.
- Owner 정정: 경영진 신뢰도에는 직원의 신뢰와 주식회사 형태에서 주주의 신뢰도 포함되며, 휴식 외의 영향 요인을 선정하고 범위 밖 기능은 아이디어 저장소에 보존하도록 지시했다.
- DEC: DEC-PLN-017-01 / 상태 APPROVED_SCOPE_CLARIFICATION / 2026-11-21. 범위 정의와 선정·등록 작업 지시만 기록한다. 여섯 요인·집계·수치·신규 기능의 상세 승인으로 확대하지 않는다.
- 향후 반영 대상: 회사 문서 §74.1의 공통 소개·경영진 신뢰도 행, §7/§78의 후속 범위 안내와 이후 경영진 신뢰도 상세 절. 회사 문서 원격 개정은 아직 하지 않았다.
- 보존 대상: 직원 만족도 승인 19개와 실제 평가·승계·표시, 다른 회사 상태값, 0~10·기본값/미관측·직접 자식 평균·정확한 점수 비공개.
- 영향: 향후 주주 자료·관점 구별과 추가 콘텐츠 검토가 필요하다. 새 계층·임의 가중·MVP 확대·즉시 게임 효과는 승인하지 않는다. 세이브/화면/일정 영향은 미확인이다.
- 후속 결정: DEC-PLN-017-02 / 2026-11-21 / OWNER_ADOPTED_SIX_FACTORS. Owner가 제안한 영향 요인 6개를 모두 채택하고 직원·주주별 평가·집계의 상세 기획을 지시했다. 구체 평가 수치·산식·기능 승인은 별도다.
- 현재 반영: 이 로컬 기준선과 [평가·집계 제안서](PLN-017_MANAGEMENT_TRUST_EVALUATION_PROPOSAL.md), 아이디어 저장소. 원격 게시·부서 메시지·검토 요청·main 병합 없음.
