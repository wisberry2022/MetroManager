## 2. 기존 승인 유지

조직 결속도는 동료·부서 사이의 실제 협력과 상호 지원 경험이다. 직원 만족도의 근무·휴식 경험, 직원·실제 주주의 경영진 신뢰도와 구분한다. 만족·신뢰 점수, 단체행동 유무, 불만·의견 차이에서 결속도를 추정하지 않는다.

재정·서비스 수준·리스크 관리·대외적 평판·대내적 평판 공통·직원 만족도·경영진 신뢰도 승인 사항은 유지한다. [회사 상태값 설계서](PLN-004_POST_MVP_COMPANY_STATE_V0_7.md)와 OWNER가 채택한 [경영진 신뢰도 기준선](https://github.com/wisberry2022/MetroManager/blob/81fbf67ca9b2b5555a84cbd2dc178e4e327ee6fd/docs/planning/PLN-017_MANAGEMENT_TRUST_BASELINE.md)을 따른다.

정식 상태값은 0~10이며 기본 보유값 5와 미관측을 구분한다. 부모는 직접 자식 보유값 평균을 유지한다. 대내적 평판의 현재 종합 단계는 직원 만족도·경영진 신뢰도·조직 결속도 세 자식 모두 현재 유효할 때만 제공한다. 결속도 관측 부족을 이유로 자식을 제외하지 않는다.

정확한 내부 점수·산식·가중·정밀 기여도는 모든 플레이어 접근 경로에서 비공개다. 이 문서의 수치는 OWNER·제작팀용 설계 정보다. 플레이어 단계·추세·사유·이력·자료 부족은 채택된 I01~05와 아래 §7을 따른다.

## 4. 집계와 상태의 필수 세칙

공동업무 사례 10과 0의 영역 평균은 5, 인수인계 사례 10의 영역 평균은 10이다. 상호 지원이 전수 관측상 기회 없음이며 다른 충분성 조건을 충족하면 조직 결속도는 `(5+10)/2=7.5`다. 지원 자료가 없거나 지원이 아직 진행 중이면 같은 방식으로 제외해 현재 평가를 내지 않는다.

정상 완료 10일의 경험은 10~37일 마감에 포함하고 38일 마감부터 제외한다. 1일에 확인된 미해결 문제는 40일에도 남는다. 40일에 실제 시정하면 같은 원래 사례의 5를 40~67일에 반영하고 68일에 제외한다. 0과 5를 두 사례로 더하지 않는다.

두 영역에 2사례·1사례가 있고 나머지 영역이 확인된 기회 없음이면 현재 평가가 가능하다. 한 영역에만 3사례, 두 영역에 각 1사례, 세 번째 영역의 미구현/자료 부족/진행 중만 존재는 현재 평가 조건을 충족하지 않는다. 이미 평가가 있는 영역에 새 기한 전 업무가 생긴 것만으로 기존 평가를 무효화하지 않는다.

평가해야 할 일부 사례의 자료가 누락되면 좋은 사례만 선택해 평균하지 않는다. 직원 0명·협력 없는 1인 회사·전 영역 기회 없음은 높은 결속이나 실제 보통 성적 5의 증거가 아니다. 기본/마지막 보유값과 현재 유효성은 구분한다.

정당한 휴식·자격·권한·다른 유효 의무를 무시한 지원 요청은 수락 버튼만으로 정당한 협력 책임이 되지 않는다. 미이행은 기록 부재만으로 추정하지 않는다. 유효 변경·종료는 이미 발생한 문제를 소급 삭제하지 않는다. 세부 조건은 아래 채택된 C01~08과 원문을 따른다.

다섯 인계 조건은 필요한 내용·접근·책임을 뜻한다. 실제 진행 책임이 있고 미해결 없음이 확인되면 정상 인계가 될 수 있지만 빈 인계를 반복해 표본을 늘릴 수 없다. 협력 결과가 제때 완성된 뒤 새 문제나 운영 변경이 생긴 것을 과거 누락으로 소급하지 않는다.

유효 종료는 성공·시정·실패 값이나 평가 표본을 만들지 않는다. 해당 기간에 실제 기회가 있었던 사실도 지우지 않으므로 무채점 종료만 있는 영역을 기회 없음으로 제외하지 않는다. 원래 업무 필요가 소멸했더라도 이미 발생한 협력 문제는 실제 또는 대체 시정을 확인해야 한다. 별도 손실 보상·징계·안전 조치·운행 효과의 의무는 기존 해당 시스템대로 유지한다.

### 7.1 단계·최신 마감·오늘의 문제

아래 구간은 OWNER·제작팀용이며 플레이어에게 공개하지 않는다.

| 내부 구간 | 플레이어 단계 |
|---|---|
| 0 이상 2 미만 | 취약 |
| 2 이상 4 미만 | 미흡 |
| 4 이상 6 미만 | 보통 |
| 6 이상 8 미만 | 양호 |
| 8 이상 10 이하 | 우수 |

R은 현재 시점에 도래한 가장 최근 정상 마감의 실제 게임 시각이다. 그 마감에 평가가 없거나 무효이면 더 오래된 좋은 보고를 현재 단계로 대신하지 않는다. 업무일 이름과 실제 마감 시각을 혼동하지 않는다. 호환 세이브의 최신 보고는 현재성이 여전히 유효할 때만 같은 보고로 복원한다.

R의 전수 근거가 유효한 채 오늘 새 문제·시정·오늘 자료 부족이 생기면 R 단계와 현재 상태를 함께 안내한다. 오늘 행동으로 마감 전 단계·추세를 즉시 바꾸지 않는다. 누락이나 사실 정정이 R의 평가 근거까지 훼손하면 현재 평가를 보류하고 원래 보고와 검증된 정정 결과를 구분해 보존한다. 다음 정상 마감에 현재 평가를 다시 판단한다. 대내적 평판 종합은 세 정식 자식 모두 현재 유효한 경우만 제공한다.

### 7.2 추세·사유·실제 이력

R/R−7은 단계 기준·영역 비중·기억 기간·판정 의미 및 실제 포함 영역이 같아야 한다. 지원 기회 없음에서 실제 지원 포함으로 바뀌면 영역 구성 차이로 추세를 보류한다. 같은 영역 안의 사례 수·인원·정상 완료와 시정의 구성 변화 자체는 비교 금지 사유가 아니다. R−6이나 R−8로 빈 비교점을 대체하지 않는다.

두 끝점의 전수 근거가 유효하면 중간 화면 이력의 공백만으로 두 시점 비교를 금지하지 않지만, 공백을 채우거나 연속 개선이라 설명하지 않는다. 공백이 두 평가 근거의 누락과 관련되면 유효성을 재확인한다. 같은 양호 단계 안의 내부 변화는 ‘비슷한 수준’이며 화살표·퍼센트·속도로 전달하지 않는다.

요약 사유는 반영된 확인 미해결 → 실제 시정/정상 완료 → 기억 범위 변화/사실 정정의 의미 순서다. 같은 종류는 실제 사건이 최근인 순서, 동률은 안정된 원래 사례 순서로 고른다. 정확한 점수 기여도 순위를 사용하지 않으며 한 사례를 두 사유로 반복하지 않는다. 순변화의 인과를 증명하지 못하면 ‘평가에 반영된 사실’로 설명한다. 오래된 완료 경험의 기간 이탈을 새 협력 성과로 소개하지 않는다.

필수 현재 안내는 요약 2개 한도에 넣어 숨기지 않는다. 확인된 각 문제와 잔여 의무에 접근할 수 있어야 하며, 양호한 단계와 미해결 문제가 함께 존재할 수 있다. 승계 여부 불명인 문제는 ‘평가 포함 여부 확인 중’으로 구분한다. 실제 기한·담당 책임·문제 수는 안내할 수 있지만 행동 뒤의 단계 상승을 보장하지 않는다.

최근 28개 마감일 보기와 경험을 기억하는 28게임일은 용도가 다르다. 보기 범위를 벗어났다고 과거 보고를 삭제하거나 현재 미해결을 지우지 않는다. 도입 전·평가 미발행·기록 누락을 구분하고, 실제 같은 단계가 유지된 날과 공백을 같은 것으로 그리지 않는다. 실제 과거 보고와 연결된 검증된 정정은 당시 원본과 구분해 제시할 수 있으나 보고가 없던 날을 새로 만들지 않는다. 비교점의 정정도 현재 R의 유효성·비교 호환성을 충족해야 한다.
